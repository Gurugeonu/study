# Ch14 부동소수점 수 정리 노트

> 범위: A p1–29 · 출처 약어: A = chap14. Floating Point Numbers.pdf

## 1. 핵심 개념
- **William Kahan**: "부동소수점의 아버지", IEEE 754 수석 설계자, 1989 튜링상 [A p1]
- **IEEE 754 표준**: 1985년 이전엔 제조사(IBM, DEC, Cray 등)마다 형식이 달라 같은 프로그램도 기계마다 결과 상이 → 1977 IEEE p754 작업 그룹, Intel 8087 팀과 Kahan의 K-C-S 초안(Kahan, Coonen, Stone)이 기반, 1985 승인(IEEE 754-1985), 2008·2019 개정. 목표: 프로그램 이식성, 정교한 수치 프로그램 개발 장려 [A p5]
- **정규화(normalization)**: 가수(significand)가 1로 시작하도록 이진 소수점 조정 → 표현이 하나뿐, 앞자리 0으로 가수 비트 낭비 없음 [A p3]
- **숨은 비트(hidden bit)**: 정규수의 맨 앞 1은 항상 있으므로 저장 안 함 [A p3, p6]
- **부호 비트 s**: 워드의 첫 비트, 0 = 양수, 1 = 음수 [A p6]
- **바이어스 지수(biased exponent) E**: 실제 지수 + 127(단정밀도) [A p6]
- **비정규수(subnormal)**: 크기가 $2^{-126}$보다 작은 0 아닌 수, 암묵적 선행 1 없음. 비트 패턴 `s 00000000 (0 아닌 가수)` [A p14]
- **NaN(Not a Number)**: 무효 연산 결과(0/0, $\infty-\infty$, $\sqrt{-1}$) [A p8]
- **ULP(Unit in the Last Place)**: x 근처 float 사이 간격. $[2^{24},2^{25})$에서 1 ULP = 2 [A p24]
- **엡실론(epsilon)**: 1.0과 그다음 표현 가능한 값의 간격 [A p18]

### 비트 배치 [A p4]
| 형식 | 부호 | 지수 | 가수 |
|---|---|---|---|
| 단정밀도(float, 32비트) | 비트 31 (1) | 30–23 (8비트) | 22–0 (23비트) |
| 배정밀도(double, 64비트) | 비트 63 (1) | 62–52 (11비트) | 51–0 (52비트) |

### 다섯 그룹(단정밀도) [A p8, p28]
| 그룹 | 지수 E | 가수 m | 값 |
|---|---|---|---|
| 0 | 0 | 0 | $\pm0$ |
| 비정규수 | 0 | $\ne0$ | $(-1)^s\times0.m\times2^{-126}$ |
| 정규수 | 1 ~ 254 | 아무 값 | $(-1)^s\times1.m\times2^{E-127}$ |
| 무한대 | 255 | 0 | $\pm\infty$ |
| NaN | 255 | $\ne0$ | Not a Number |

## 2. 공식
| 공식 | 기호·의미 | 사용 조건 |
|---|---|---|
| $(-1)^s\times1.m\times2^{E-127}$ | 단정밀도 정규수 값 | $1\le E\le254$ (실제 지수 −126 ~ +127) [A p6] |
| $(-1)^s\times1.m\times2^{E-1023}$ | 배정밀도 정규수 값 | $1\le E\le2046$ [A p17] |
| $(-1)^s\times0.m\times2^{-126}$ | 단정밀도 비정규수 값 | $E=0,\ m\ne0$. 지수는 $-127$이 아니라 $-126$ 고정 [A p14] |
| $2-2^{-23}=1+\tfrac12+\cdots+\tfrac1{2^{23}}=1.11\ldots1_2$ | 소수점 아래 1이 23개 | 최대 정규수의 가수 [A p9] |
| 간격 $=2^{e-23}$ | float $=1.m\times2^e$ | 같은 $e$ 안에서 $2^{23}$개 값이 등간격 [A p13] |

### 단정밀도 한계와 비트 패턴 [A p9, p11, p15]
| 값 | 수 | 비트 (s / E / m) | 십진 근삿값 |
|---|---|---|---|
| $\pm\infty$ | — | s / 11111111 / 모두 0 | — |
| 최대 정규수 | $\pm(2-2^{-23})\times2^{127}$ | s / 11111110 (254) / 모두 1 | $\approx\pm3.40\times10^{38}$ |
| 최소 정규수 | $\pm2^{-126}$ | s / 00000001 (1) / 모두 0 | $\approx\pm1.18\times10^{-38}$ |
| 최대 비정규수 | $(1-2^{-23})\times2^{-126}$ | 0 / 00000000 / 모두 1 | $\approx1.18\times10^{-38}$ |
| 최소 비정규수 | $2^{-23}\times2^{-126}=2^{-149}$ | 0 / 00000000 / 0…01 | $\approx1.40\times10^{-45}$ |
| $\pm0$ | — | 0 또는 1 / 00000000 / 모두 0 | 0 |

### 단정밀도 vs 배정밀도 [A p17]
| 항목 | float | double |
|---|---|---|
| 지수 / 가수 비트 | 8 / 23 (+1 숨은) | 11 / 52 (+1 숨은) |
| 바이어스 | 127 | 1023 |
| 실제 지수 | −126 ~ +127 | −1022 ~ +1023 |
| 최대값 | $\approx3.4\times10^{38}$ ($1.1\ldots1_2\times2^{127}$) | $\approx1.8\times10^{308}$ ($1.1\ldots1_2\times2^{1023}$) |
| 최소 정규수 | $\approx1.2\times10^{-38}$ ($1.0_2\times2^{-126}$) | $\approx2.2\times10^{-308}$ ($1.0_2\times2^{-1022}$) |
| 최소 비정규수 | $\approx1.4\times10^{-45}$ ($0.0\ldots01_2\times2^{-126}$) | $\approx4.9\times10^{-324}$ ($0.0\ldots01_2\times2^{-1022}$) |
| 십진 유효숫자 | 약 7 | 약 15–16 |

### `<float.h>` 상수 [A p18]
| 의미 | float | double |
|---|---|---|
| 최대값 | `FLT_MAX` 3.402823e+38 $=(2-2^{-23})\times2^{127}$ | `DBL_MAX` 1.797693e+308 $=(2-2^{-52})\times2^{1023}$ |
| 최소 정규수 | `FLT_MIN` 1.175494e-38 $=2^{-126}$ | `DBL_MIN` 2.225074e-308 $=2^{-1022}$ |
| 최소 비정규수 | `FLT_TRUE_MIN` 1.401298e-45 $=2^{-149}$ | `DBL_TRUE_MIN` 4.940656e-324 $=2^{-1074}$ |
| 엡실론 | `FLT_EPSILON` 1.192093e-07 $=2^{-23}$ | `DBL_EPSILON` 2.220446e-16 $=2^{-52}$ |
| 정확히 유지되는 십진 자릿수 | `FLT_DIG` 6 | `DBL_DIG` 15 |
- `#include <float.h>` 필요, `*_TRUE_MIN`은 C11부터. 표 값은 `printf("%e")`로 7자리 반올림

### float 간격 [A p13]
| 구간 | e | 간격 $2^{e-23}$ | 저장 가능한 값 |
|---|---|---|---|
| $[1,2)$ | 0 | $2^{-23}\approx1.19\times10^{-7}$ | 기계 엡실론(`FLT_EPSILON`) |
| $[2^{23},2^{24})$ | 23 | 1 | 모든 정수 |
| $[2^{24},2^{25})$ | 24 | 2 | 짝수만 |
| $[2^{25},2^{26})$ | 25 | 4 | 4의 배수만 |

## 3. 원리·결론
- 0.1은 유한 이진 표현이 없음(순환 소수 $0.000110011\ldots_2$) → 가장 가까운 값으로 저장. 패트리엇 미사일 사고(1991, 24비트 고정소수점, 100시간 누적 오차 0.34 s)의 근본 원인 [A p2, p23]
- 정규수는 로그 간격: 2의 거듭제곱 구간마다 똑같이 $2^{23}$개 → 간격이 구간마다 2배 [A p12]
- 그림(가수 2비트 장난감 형식): 구간당 4개, 최소 정규수 1/4, 간격 1/16 → 1/8 → 1/4 → 1/2, 0~1/4는 빈 틈 → 비정규수가 1/16 간격으로 채움 [A p12, p14]
- $2^{24}$ 다음 float는 $(1+2^{-23})\times2^{24}=2^{24}+2$ → $2^{24}+1$ 저장 불가 [A p13]
- 32비트 정수(2의 보수)는 $-2^{31}\sim2^{31}-1$ 한 구간. 정규 float는 양·음 두 구간, 바깥은 오버플로, 0 근처 $\pm2^{-126}$ 안쪽은 언더플로 [A p10]
- 0은 특수값으로 정확히 저장. 비정규수가 언더플로 틈의 일부를 $\pm2^{-149}$까지 채움 [A p10]
- 비정규수의 의의: 점진적 언더플로(0으로 뚝 떨어지지 않음), 아주 작은 값의 부호·대략적 크기 유지. 간격 $2^{-149}$ = 첫 정규 구간 간격 [A p12, p14]
- 32비트 정수로 읽으면: 최대 정규 패턴 + 1 = $+\infty$ 패턴, 최대 비정규 패턴 + 1 = 최소 정규 패턴(차이 $2^{-149}$, 경계에 틈 없음) [A p11, p15]
- 산술에서 최대값 + 1은 최대값으로 반올림(∞ 안 됨), $\infty-1$은 $\infty$. 비트로는 `0x7F800000` − 1 = `0x7F7FFFFF` = `FLT_MAX` [A p11, p19]
- 비정규수 비용: 선행 0이 비트를 차지해 유효 비트가 24 → 1로 감소($2^{-149}$ 근처). x86에서 비정규 피연산자 명령은 최대 ~100 추가 클럭, 소프트웨어 트랩 시 100배 이상 감속 [A p16]
- FTZ/DAZ 모드: 비정규수를 0으로 처리, 빠르지만 IEEE 754 비준수. `-ffast-math`가 켬 → 플랫폼별 결과 차이 [A p16]
- 부호 있는 0: $+0=-0$ 비교는 참, 그러나 $1/(+0)=+\infty$, $1/(-0)=-\infty$. $1/(-\infty)=-0$(크기가 0이 돼도 부호 유지) [A p8, p21, p22]
- NaN은 자기 자신을 포함한 모든 값과 같지 않음 → `NAN == NAN`은 0 [A p20, p22]
- NaN 생성: `0.0/0.0`, `inf/inf`, `0.0*inf`, `-inf+inf`, `sqrt(-1.0)`, `log(-1.0)`. `1.0/0.0`은 inf, `atan(inf)` = π/2 [A p20, p21]
- 기본 연산(+, −, ×, ÷, sqrt): 정확한 결과를 구한 뒤 표현 가능한 수로 반올림. 0.1 같은 십진 상수도 반올림 [A p24]
- 기본 반올림: 최근접, 동률이면 짝수(`FE_TONEAREST`) → 오차 최대 0.5 ULP(오버플로 제외), 동률이면 마지막 가수 비트가 0인 쪽 [A p24]
- 다른 모드(`fesetround()`, `<fenv.h>`, 오차 1 ULP 미만): `FE_TOWARDZERO`(0 쪽), `FE_UPWARD`(+∞ 쪽), `FE_DOWNWARD`(−∞ 쪽) [A p24]
- 덧셈은 결합법칙 불성립: $(a+b)+c\ne a+(b+c)$ 가능. 작은 수가 큰 수 ULP의 절반 이하면 사라짐 [A p25]
- 이진수로 정확한 값(0.5 = $0.1_2$ 등)만 적은 그대로 저장 [A p26]

## 4. 문제 유형별 접근
- 인코딩: 부호 s → 절댓값 이진 변환 → $1.xxx\times2^{k}$로 정규화 → $E=k+127$ (8비트) → 선행 1 빼고 가수 23비트(뒤를 0으로) → 4비트씩 묶어 16진 [A p7]
- 디코딩: 16진 → 32비트 → s / E / m 분리 → E로 그룹 판별(0, 255는 특수) → 공식 적용 [A p8]
- 실수 비교: `==` 대신 허용 오차, `fabs(a-b) < 1e-9` [A p23]
- NaN 판정은 `isnan()`, 무한대 판정은 `isinf()` [A p20]
- 반복문: float 카운터 대신 정수 카운터로 돌고 매번 x 계산 — `for (int i = 0; i < 10; i++) { double x = i / 10.0; ... }` (오차 누적 없음) [A p26]
- 크기 차이 큰 수 합산: 작은 수끼리 먼저 더해 키운 뒤 큰 수에 더함 [A p25]
- 비트로 무한대 판정(`isInfinity`): `(bits & 0x7F800000) >> 23 == 255` → `bits & 0x007FFFFF == 0` → `bits >> 31`이면 −1(−∞), 아니면 1(+∞), 조건 불충족 시 0 [A p28]
- 비트 보기: `memcpy`로 `uint32_t`에 복사(`<string.h>`, `<stdint.h>`) [A p19, p28]

## 5. 실수 포인트
- `float x = 0.1; x == 0.1` → false (`0.1f`와 `0.1`은 다르게 반올림). `float y = 0.5; y == 0.5` → true [A p26]
- `for (float x = 0; x != 1.0; x += 0.1)` → 무한 루프(합이 1.0000001이 되어 1.0을 건너뜀) [A p26]
- `int n = 16777217; float f = n;` → 16777216 ($2^{24}$ 위는 간격 2) [A p26]
- $(2^{24}+1)+1$ → 16,777,216, $2^{24}+(1+1)$ → 16,777,218 (float 약 7자리, 16,777,217은 8자리 필요) [A p25]
- 비정규수 지수는 $0-127$이 아니라 $-126$ [A p14]
- `float`를 `int *`로 읽기는 정의되지 않은 동작(undefined behavior) [A p19, p28]
- `NAN`은 C99 `<math.h>` 매크로, NaN은 IEEE 754 값. NaN은 `nan` 또는 `-nan`으로 출력 가능 [A p20]
- MSVC는 상수식 `1.0/0.0`을 거부 → 변수 `zero` 사용 [A p20]
- 패트리엇은 IEEE 754가 아닌 24비트 고정소수점이었지만 원인은 같음 [A p2]
