# Part 1. C 표준 입출력(stdio)

## 1. 핵심 개념
- **"Unix에서는 모든 것이 파일"**: 디스크·터미널·장치를 같은 파일 인터페이스로 읽고 씀 [A p4]
- **파일 입출력 목적**: 지속성(종료 후에도 데이터 유지), 공유(프로그램 간·실행 간 전달). 흐름 `fopen` → 읽기/쓰기 → `fclose` [A p4]
- **파일 포인터**: `FILE` 구조체를 가리키는 포인터 `FILE *fp` [A p6]
- **스트림(stream)**: 바이트 열의 추상 표현 → 장치·OS 독립, 입출력 공통 인터페이스. 파일·장치·파이프·소켓·메모리 버퍼에 연결 [A p11]
- **파일 스트림**: `FILE *`로 관리하는 C의 스트림. **표준 스트림** stdin, stdout, stderr = 미리 열린 콘솔용 파일 스트림 [A p11]
- **fopen의 일**: 파일 열기 → 메모리에 파일 스트림(버퍼) 생성·실제 파일과 연결 → 파일 포인터 반환. 같은 `FILE *`가 장치(`/dev/…`), 파이프(`popen`), 소켓(`fdopen`), 메모리(`fmemopen`)에도 쓰임 [A p12]
- **FILE 구조체**: 파일 디스크립터, 버퍼(버퍼 입출력용 임시 메모리), 오류 표시자, 현재 위치 표시자 등. 정확한 구성은 표준이 정하지 않음 [A p13]
- **EOF**: 기호 상수, 표준상 음의 정수, 보통 `#define EOF (-1)` [A p15]
- **플러시(flush)**: 버퍼에 대기 중인 데이터를 실제 목적지로 보냄 [A p23]
- **종료 상태**: `0`/`EXIT_SUCCESS` 정상, 0 아님/`EXIT_FAILURE` 오류 [A p23]

| 항목 [A p5] | 텍스트 파일 | 바이너리 파일 |
|---|---|---|
| 인코딩·구조 | ASCII/UTF-8, 개행으로 나뉜 줄 | 이진 형식, 응용별 구조, 표준 줄 끝 없음 |
| 가독성·이식성 | 편집기로 읽힘, 이식성 높음 | 전용 프로그램 필요, 시스템 의존 가능 |
| 용도 | 문서, 소스코드, 설정 | 실행 파일, 이미지, 오디오/비디오, DB |
- `xxd`: 텍스트는 출력 가능 문자와 `0a`(`\n`)뿐, Windows 개행은 `0d 0a`. PNG는 시그니처 `89 50 4e 47 0d 0a 1a 0a` → `IHDR` 헤더 → 크기(480×320) [A p5]

## 2. 함수 원형·핵심 사실
| 원형 | 핵심 |
|---|---|
| `FILE *fopen(const char *name, const char *mode);` | 실패 시 `NULL` [A p6–7] |
| `fclose(fp);` | 플러시 후 닫음, 실패 시 `EOF` [A p16] |
| `perror("msg");` | stderr에 `msg: 원인`(`No such file or directory` 등) [A p7, p30] |
| `getc(fp)` / `fgetc(fp)` | 한 문자 읽기, 끝·오류 시 `EOF`. getc 매크로 가능, fgetc 함수 [A p14] |
| `putc(c,fp)` / `fputc(c,fp)` | 한 문자 쓰기(putc 매크로 가능) [A p14] |
| `int ungetc(int c, FILE *fp);` | `c`를 스트림에 되돌림 [A p14] |
| `feof(fp)` / `ferror(fp)` | EOF면 / 오류면 0 아님 [A p14] |
| `int fscanf(FILE *fp, const char *format, ...)` / `fprintf` | 서식 입출력 [A p17] |
| `#define getchar() getc(stdin)` / `#define putchar(c) putc((c), stdout)` | 표준 스트림 매크로 [A p18] |
| `void exit(int status);` | 종료·OS에 제어 반환, 출력 스트림 플러시 + 모든 스트림 닫기 [A p23] |
| `fflush(fp);` | 종료 없이 플러시 → 커널 페이지 캐시까지(디스크 아님) [A p23] |
| `char *fgets(char *s, int n, FILE *iop);` | 최대 n−1자, 개행은 **저장**하고 멈춤, 항상 `'\0'` 종료. 오류 또는 아무것도 못 읽은 EOF면 `NULL` [A p24–25] |
| `char *gets(char *str);` | stdin 한 줄, 개행 저장 안 함, 경계 검사 없음 → **C11에서 제거** [A p25] |
| `ssize_t getline(char **lineptr, size_t *n, FILE *stream);` | 반환 = 개행 포함·`'\0'` 제외 문자 수, EOF·오류 −1. POSIX(MSVC 없음) [A p27] |
| `int fputs(const char *s, FILE *iop);` | 개행 추가 안 함. 성공 시 음이 아닌 값, 오류 `EOF` [A p28–29] |
| `int puts(const char *str);` | stdout에 쓰고 개행 자동 추가 [A p29] |
| `int fseek(FILE *stream, long offset, int whence);` | 위치 이동. 성공 0, 오류 0 아님 [A p31] |
| `void rewind(FILE *stream);` | `fseek(stream, 0L, SEEK_SET)` + 오류 표시자 지움(이후 ferror 0). 반환값·오류 표시 없음. 처음부터 재처리용 [A p33] |

- **fopen 검색 위치**: 현재 작업 디렉터리(프로그램을 실행한 곳, 실행 파일 위치 아님). 그 밖은 경로 지정 `"C:/source/x.txt"`, `"C:\\source\\x.txt"` [A p8]
- **getline**: `*lineptr == NULL`이면 malloc 할당·크기를 `*n`에 저장, 줄이 길면 재할당 [A p27]
- **fseek**: `offset`은 바이너리면 바이트 수, 텍스트면 0 또는 `ftell` 값. `whence` = `SEEK_SET` 처음 / `SEEK_CUR` 현재 / `SEEK_END` 끝(예 `fseek(fp, -5, SEEK_END)`) [A p31]

| 모드 [A p9] | 설명 | 파일 있음 | 없음 |
|---|---|---|---|
| `"r"` | 읽기 전용 | 읽기로 열림 | 오류 |
| `"w"` | 쓰기 전용 | 덮어씀 | 생성 |
| `"a"` | 끝에 덧붙여 쓰기 | 덧붙임 | 생성 |
| `"r+"` | 읽기(쓰기 가능) | 자르지 않음 | 오류 |
| `"w+"` | 쓰기(읽기 가능) | 덮어씀 | 생성 |
| `"a+"` | 읽기·쓰기(덧붙임) | 덧붙임 | 생성 |
| `"wx"`, `"w+x"` | 배타적 생성(C11) | 오류 | 생성 |
| `"rb"`, `"wb"`, `"ab"`… | 바이너리 모드 | 대응 텍스트 모드와 같음 | 같음 |
- `r+`: 내용 보존, 위치 표시자 기준 어디서든 읽기/쓰기 → 기존 파일 수정용. `w+`: 열자마자 내용 삭제, 새 빈 파일처럼 읽기·쓰기 [A p10]

| 스트림 [A p18, p20] | 기본 연결 | 버퍼 | fd |
|---|---|---|---|
| stdin | 키보드 | 있음 | 0 |
| stdout | 화면 | 있음 | 1 |
| stderr | 화면 | **없음** | 2 |
- C 런타임이 시작 시 열고(`stdio.h`의 `FILE *` 매크로) 정상 종료 시 플러시·닫음 [A p18]
- 키보드 EOF: Windows는 줄 처음 `Ctrl+Z` 후 Enter, Unix는 줄 처음 `Ctrl+D`(문자가 아니라 터미널이 입력 종료) [A p19]

| 명령 [A p21] | stdout(fd 1) | stderr(fd 2) |
|---|---|---|
| `./a.out > out.txt` | out.txt | 화면 |
| `./a.out 2> err.txt` | 화면 | err.txt |
| `./a.out > out.txt 2> err.txt` | out.txt | err.txt |
| `./a.out > all.txt 2>&1` | all.txt | all.txt |
| `./a.out 2> /dev/null` | 화면 | 버림 |
| `./a.out 2>> err.txt` | 화면 | err.txt(덧붙임) |
- `n>`은 fd n을 리다이렉트, `>`는 `1>`의 줄임 [A p21]

## 3. 원리·결론
- 버퍼 없으면 getc/putc마다 시스템 호출 → 오버헤드로 느림 [A p13]
- 읽은 문자는 `int`에 저장(EOF가 음수) [A p14]
- 갱신 모드(r+ w+ a+)는 읽기·쓰기가 버퍼 하나·위치 하나를 공유 → 방향 전환 전 동기화 [A p10, p34]
- 오류는 stderr, 결과는 stdout → 리다이렉션으로 분리 가능. `ferror(stdout)`로 쓰기 오류(디스크 꽉 참, 끊긴 파이프) 확인 [A p22]
- fclose가 버퍼를 비우므로 출력 쓰기 오류는 `fclose` 반환 `EOF`에서 드러남 [A p16]
- `"rb"`는 오프셋을 정확한 바이트로 유지(Windows 텍스트 모드는 `\r\n`→`\n`) [A p32]

## 4. 문제 유형별 접근
- 파일 열기: `fopen` → `NULL`이면 `perror` + 종료 → 작업 → `fclose`. 두 번째 열기 실패 시 첫 파일 닫고 종료 [A p7, p16]
- 문자 복사: `while ((c = getc(in)) != EOF) putc(c, out);` → `ferror(in)` → `fclose(out) == EOF` 검사 [A p16]
- 서식 처리: `while (fscanf(in, "%99s %d", str, &num) == 2)` → 가공 → `fprintf` [A p17]
- fgets가 `NULL`: `ferror` 참 → 읽기 오류, 거짓 → EOF(빈 파일) [A p30]
- k번 바이트부터 읽기: `"rb"` → `fseek(fp, k, SEEK_SET)` → 읽기 [A p32]
- 갱신 모드 전환: 쓰기→읽기 전 `fflush`/`fseek`/`rewind`, 읽기→쓰기 전 `fseek`/`rewind`(EOF가 아니면) [A p34]
- 안전한 문자열 입력: `fgets(buf, size, stdin)`, `scanf("%79s", buf)`(크기 80), `getline(&p, &cap, stdin)` [A p26]
- 남은 입력 버리기(표준 함수 없음): `while ((ch = getchar()) != '\n' && ch != EOF);` [A p26]

## 5. 실수 포인트
- `"w"`, `"w+"`는 기존 내용을 즉시 지움 [A p10]
- 갱신 모드 전환 규칙 생략 → 미정의 동작(낡은 버퍼 데이터 읽기, 엉뚱한 위치 쓰기) [A p34]
- `scanf("%s", buf)`는 길이 제한 없음 → 버퍼 오버플로. 폭 제한 후 남은 문자는 다음 입력이 읽음 [A p26]
- `getline`이 −1이어도 버퍼가 할당됐을 수 있음 → 항상 `free` [A p27]
- `2>&1`은 그 순간 fd 1이 가리키는 곳으로: `2>&1 > all.txt`면 stderr는 화면 [A p21]
- `2 > err.txt`처럼 띄우면 `2`가 인자가 되고 stdout이 리다이렉트됨 [A p21]

# Part 2. 시스템 호출 입출력

## 1. 핵심 개념
- **시스템 호출(system call)**: 프로그램이 OS 커널에 서비스를 요청하는 것. `open`, `read`, `write`, `close`로 파일 직접 접근 [A p36]
- stdio 버퍼는 우회, 커널은 여전히 **페이지 캐시**에 캐시. 플래그·권한 제어가 많고 버퍼링은 직접 책임(없으면 작은 호출이 많아 느림) [A p36]
- 계층: 사용자 공간(응용, glibc) / 커널 공간(시스템 호출 인터페이스, 커널, 아키텍처 의존 코드) / 하드웨어 [A p36]
- **파일 디스크립터(fd)**: 열린 파일을 식별하는 음이 아닌 정수. 0 stdin, 1 stdout, 2 stderr [A p38]
- **ssize_t**: 부호 있는 size_t. **size_t**: "size type" [A p38]
- **errno**: `<errno.h>` 매크로, 스레드마다 하나(C11), 호출 실패 시 오류 종류 설정. **EINTR**: 시그널로 중단(SA_RESTART 없는 핸들러) → 재시도 [A p42]
- **BUFSIZ**: `<stdio.h>` 매크로, 스트림 입출력 버퍼 크기, 구현 의존(512, 1024, 2048, 4096 등) [A p43]

| 항목 [A p37] | stdio (`FILE *`) | 시스템 호출 (fd) |
|---|---|---|
| 예 | fopen, fclose, fread, fwrite, printf | open, close, read, write |
| 핸들 | `FILE *` | `int` fd |
| 버퍼링 | 사용자 공간 버퍼 | 없음(커널은 캐시) |
| 이식성 | ISO C | OS 의존(POSIX/Unix/Linux) |
| 편의성 | 서식·줄 입출력 | 원시 바이트만 |
| 성능 | 작은 입출력 다수에 유리 | 크고 제어된 입출력에 유리할 수 있음 |
| 오류 확인 | ferror, feof | −1 반환 + errno |
| 텍스트/바이너리 | Windows 텍스트 모드는 파일 `\r\n` ↔ 메모리 `\n` 변환 | 항상 원시 바이트 |
| 고급 입출력 | 미지원 | select, poll, epoll, O_NONBLOCK |

| 모델 [A p38] | int | long | 포인터 | size_t |
|---|---|---|---|---|
| ILP32(32비트 Linux) | 32 | 32 | 32 | unsigned int |
| LP64(64비트 Linux/macOS) | 32 | 64 | 64 | unsigned long |
| LLP64(64비트 Windows) | 32 | 32 | 64 | unsigned long long |

## 2. 함수 원형
| 원형 | 핵심 |
|---|---|
| `ssize_t read(int fd, void *buf, size_t n);` | `<unistd.h>`. 읽은 바이트 수(n보다 작을 수 있음), **EOF면 0**, 오류 −1 [A p38] |
| `ssize_t write(int fd, const void *buf, size_t n);` | `<unistd.h>`. 쓴 바이트 수(n보다 작을 수 있음), 오류 −1 [A p38] |
| `int open(const char *path, int oflag, ... /* mode_t mode */);` | `<fcntl.h>`. fd 반환, 실패 −1 [A p39] |
| `int creat(const char *path, mode_t mode);` | = `open(path, O_WRONLY\|O_CREAT\|O_TRUNC, mode)` [A p39] |
| `close(fd);` | fd 닫기 [A p40] |
| `int unlink(const char *pathname);` | `<unistd.h>`. 디렉터리 엔트리 제거, 0 / −1(errno) [A p45] |
| `int fsync(int fd);` | 데이터 + **모든** 메타데이터(크기, 타임스탬프)를 디스크에 [A p46] |
| `int fdatasync(int fd);` | 데이터 + 읽는 데 필요한 메타데이터만(예: 새 크기) [A p46] |
| `off_t lseek(int fd, off_t offset, int whence);` | `<unistd.h>`. 읽기·쓰기 없이 위치 이동. K&R 구형 `long lseek(int fd, long offset, int origin)` [A p48] |
- **open 플래그** [A p39]: `O_RDONLY` 읽기 · `O_WRONLY` 쓰기 · `O_RDWR` 읽기·쓰기 · `O_APPEND` 끝에 쓰기 · `O_CREAT` 없으면 생성 · `O_TRUNC` 길이 0으로 · `O_EXCL` O_CREAT와 함께, 있으면 실패
- mode는 O_CREAT 없으면 무시 → 0 또는 생략 [A p39]
- lseek whence: `SEEK_SET`(0) 처음, `SEEK_CUR`(1) 현재, `SEEK_END`(2) 끝. `lseek(fd, 0L, SEEK_END)` 끝으로, `lseek(fd, 0L, SEEK_SET)` 처음으로 [A p48]
- 실제 생성 권한 = `PERMS & ~umask` (0666, umask 022 → 0644) [A p43]
- 가변 인자(`<stdarg.h>`): `va_list` → `va_start(args, fmt)` → `vfprintf(stderr, fmt, args)` → `va_end(args)` [A p44]

## 3. 원리·결론
- unlink 후 데이터 블록은 다른 하드 링크도, 파일을 연 프로세스도 없을 때 해제 [A p45]
- `write` 반환 후에도 데이터는 페이지 캐시에만 있을 수 있음. fsync/fdatasync는 디스크 저장까지 기다림 → 정전·충돌 대비(DB, 로그) [A p46]
- fdatasync는 내용만 바뀌면 타임스탬프 갱신 생략 → 디스크 쓰기 1회 절약 [A p46]
- 데이터 경로: stdio 버퍼 →(fflush/fclose/exit)→ 페이지 캐시 →(fsync)→ 디스크 [A p23, p46]
- stdio `fgetc`도 버퍼가 비면 `read(fd, buf, BUFSIZ)`로 채워 한 바이트씩 꺼냄 [A p42]

## 4. 문제 유형별 접근
- fd로 읽어 출력: `open` → `-1`이면 perror → `read` → `> 0`이면 `write(1, buf, n)` → `close` [A p40]
- 입력→출력 복사: `while ((n = read(0, buf, BUFSIZ)) > 0) write(1, buf, n);` [A p41]
- 한 문자 읽기: 버퍼 없음 `read(0, &c, 1) == 1 ? (unsigned char)c : EOF` / 버퍼 있음 static 버퍼가 비면 read로 채움(EINTR 재시도, 오류·0바이트면 EOF) [A p41–42]
- 파일 복사(cp): `open(src, O_RDONLY, 0)` → `creat(dst, PERMS)` → read/write 루프, `write(...) != n`이면 오류 → close [A p43]
- 확실한 로그 저장: `open(…, O_WRONLY|O_CREAT|O_APPEND, 0644)` → `write` → `fsync(fd) == -1` 검사 [A p47]
- pos에서 n바이트 읽기: `lseek(fd, pos, SEEK_SET) >= 0`이면 `read`, 아니면 −1 [A p49]
- 오류 후 종료: `error(fmt, ...)` → stderr에 `"error: "` + 메시지 → `exit(1)` [A p44]

## 5. 실수 포인트
- read/write는 n보다 적게 전송할 수 있음. read 0(EOF)과 −1(오류) 구분 [A p38]
- `while ((n = read(...)) > 0)`는 −1에서도 조용히 끝남 → `n < 0` 검사 [A p43]
- `creat`는 기존 파일을 잘라냄. PERMS는 umask로 깎임 [A p39, p43]
- fsync/fdatasync는 stdio 버퍼를 비우지 않음 → `fflush(fp)` 후 `fsync(fileno(fp))` [A p46]
