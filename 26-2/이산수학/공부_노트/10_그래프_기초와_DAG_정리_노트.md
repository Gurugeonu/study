# 10 그래프 기초와 DAG 정리 노트

> 범위: A p2–39 (10.1~10.3절, DAG와 스케줄링) · 출처 약어: A = 10. Graphs 1.pdf

## 1. 핵심 개념

### 그래프의 종류
- **무방향 그래프(undirected graph)** $G=(V,E)$: 공집합 아닌 꼭짓점(vertex, node) 집합 $V$ + 변(edge) 집합 $E$. 변마다 끝점(endpoint) 1개 또는 2개, 변이 끝점을 연결 [A p4]
- **방향 그래프(directed graph, digraph)**: 방향 변(directed edge, arc)이 순서쌍 $(u,v)$. $u$에서 시작, $v$에서 끝 [A p4]
- **루프(loop)**: 꼭짓점을 자기 자신에 잇는 변 [A p5]
- **중복도(multiplicity)**: 같은 쌍 $\{u,v\}$(방향이면 $(u,v)$)를 잇는 변이 $m$개 → 중복도 $m$ [A p5–6]

| 종류 | 방향 | 다중 변 | 루프 |
|---|---|---|---|
| 단순 그래프(simple graph) | 없음 | X | X |
| 다중 그래프(multigraph) | 없음 | O | X |
| 의사 그래프(pseudograph) | 없음 | O | O |
| 단순 방향 그래프 | 있음 | X | X |
| 방향 다중 그래프 | 있음 | O | (그림 예시에 루프 포함) |

### 그래프 모델 [A p7–12]
| 상황 | 꼭짓점 / 변 | 그래프 종류 |
|---|---|---|
| 연결 여부만, 양방향 링크 | 데이터 센터 / 통신 링크 | 단순 그래프 |
| 링크 개수 중요 | 〃 | 다중 그래프 |
| 진단 링크(자기 자신) | 〃 | 의사 그래프 |
| 여러 단방향 링크 | 〃 | 방향 다중 그래프 (링크 1개 이상 여부만 → 다중 변 없는 방향 그래프) |
| 친구 그래프 / 협업 그래프 | 사람 / 친구·협업 관계 | 무방향 |
| 영향 그래프 | 사람 / 앞사람이 뒷사람에 영향 | 방향 |
| 모듈 의존 그래프 | 모듈 / 두 번째가 첫 번째에 의존하면 첫→두 번째 | 방향 (하향식 설계, 코딩 전 파악) |
| 선행 그래프(precedence graph) | 문장 / 두 번째가 첫 번째보다 먼저 실행될 수 없으면 첫→두 번째 | 방향 |
| 단백질 상호작용 그래프 | 단백질 / 상호작용 | 무방향, 10만+ 꼭짓점·100만+ 변, 기능별 모듈로 분할 |

- 그래프 모델: 응용의 중요한 특징을 담는 종류 선택 [A p7]

### 기본 용어 [A p14–15]
- **인접(adjacent, 이웃 neighbors)**: 변 $e=\{u,v\}\in E$ 존재. $e$는 $u,v$에 **접속(incident)**, $u,v$를 연결
- **이웃 집합(neighborhood)** $N(v)$: $v$의 모든 이웃. $N(A)=\bigcup_{v\in A}N(v)$
- **차수(degree)** $\deg(v)$: 접속한 변의 수, 루프는 **2**로 셈
- 방향 변 $(u,v)$: $u$ = 꼬리(tail)·시작점(initial vertex), $v$ = 머리(head)·끝점(terminal vertex). $u$는 $v$**에** 인접(adjacent to), $v$는 $u$**로부터** 인접(adjacent from). 자기 루프는 시작점 = 끝점
- **진입 차수** $\deg^-(v)$(indeg): $v$에서 끝나는 변 수. **진출 차수** $\deg^+(v)$(outdeg): $v$에서 시작하는 변 수. 루프는 각각 1씩

### 보행·경로·사이클 [A p18–20]
- **보행(walk)** $\mathbf{w}=v_0\{v_0,v_1\}v_1\cdots\{v_{k-1},v_k\}v_k$, $\{v_i,v_{i+1}\}\in E$ ($0\le i<k$). 시작 $v_0$, 끝 $v_k$, 길이 $|\mathbf{w}|=k$. 꼭짓점 수열 또는 변 수열만으로 결정
- **경로(path)**: 단순 보행, $v_0,\dots,v_k$ 모두 다름
- **투어(tour, 닫힌 보행)**: 시작 = 끝
- **사이클(cycle)**: 양의 길이 투어, 시작·끝 외 꼭짓점 모두 다름
- **병합(merge)** $\mathbf{w}\,\hat{}\,\mathbf{r}$ (또는 $\mathbf{wr}$): $\mathbf{w}$가 $v$에서 끝나고 $\mathbf{r}$이 $v$에서 시작할 때 이어 붙인 보행

| | 꼭짓점 반복 없음 | 변 반복 없음 | 시작 = 끝 |
|---|---|---|---|
| 보행 | | | |
| 경로 | O | O | |
| 투어 | | | O |
| 사이클 | O(시작·끝 제외) | O | O |

- **거리(distance)** $\mathrm{dist}(u,v)$: $u\to v$ 최단 경로의 길이

### 그래프 표현 [A p22–26]
- **인접 리스트(adjacency list)**: 다중 변 없는 그래프. 꼭짓점마다 인접 꼭짓점 나열(방향: 시작점마다 끝점 나열)
- **인접 행렬(adjacency matrix)** $\mathbf{A}_G=[a_{ij}]$: 단순 그래프, $|V|=n$, 꼭짓점 순서 $v_1,\dots,v_n$ 임의. $n\times n$ 0-1 행렬, $\{v_i,v_j\}\in E$이면 $a_{ij}=1$, 아니면 0
  - 루프: $(i,i)$ 자리에 1 / 다중 변·다중 루프: $a_{ij}$ = 변 개수
  - 방향 그래프: $v_i\to v_j$ 변이면 $(i,j)$ 자리 1, 대칭 아닐 수 있음 / 방향 다중 그래프: $a_{ij}$ = $v_i\to v_j$ 변 개수
- **접속 행렬(incidence matrix)** $\mathbf{M}=[m_{ij}]$: 무방향, 꼭짓점 $v_1..v_n$·변 $e_1..e_m$ 순서 기준 $n\times m$. $e_j$가 $v_i$에 접속하면 $m_{ij}=1$, 아니면 0
- **길이 $k$ 보행 계수 행렬(walk counting matrix)** $\mathbf{C}=[c_{ij}]$: $c_{ij}$ = $v_i\to v_j$ 길이 $k$ 보행 수. $\mathbf{A}_G$ = 길이 1, 단위행렬 = 길이 0(관례)

### 보행 관계 [A p29]
- $u\mathbf{A}^*v$ (보행 관계, walk relation): $u\to v$ 보행 존재
- $u\mathbf{A}^+v$ (양의 보행 관계): $u\to v$ 양의 길이 보행 존재
- $u\mathbf{A}^n v$: 길이 $n$ 보행 존재. $\mathbf{A}^n$ = 관계 $\mathbf{A}$를 $n$번 합성, $\mathbf{A}^0=\mathrm{Id}_V$

### DAG와 스케줄링 [A p31–38]
- **DAG(directed acyclic graph, 방향 비순환 그래프)**: 사이클 없는 방향 그래프
- 선수과목 그래프: $s\to t$ = $s$가 $t$의 직접 선수과목. $u$를 $v$ 전에 이수해야 함 ⇔ $u\,D^+\,v$
- **위상 정렬(topological sort)**: 모든 변 $u\to v$에 대해 $u$가 $v$보다 앞에 오는 꼭짓점 나열
- **최소원(minimum)**: 다른 모든 꼭짓점에 도달 가능 / **극소원(minimal)**: 다른 어떤 꼭짓점에서도 도달 불가
- **병렬 스케줄(parallel schedule)**: $V$를 $A_0,A_1,\dots$로 분할, $j<k$이면 $A_j$의 어떤 꼭짓점도 $A_k$의 꼭짓점에서 도달 불가. $A_k$ = $k$단계 작업, **시간** = 블록 수, **프로세서 수** = $\max_k|A_k|$
- **비교 가능(comparable)**: 한쪽에서 다른 쪽에 도달 가능
- **체인(chain)**: 어느 두 원소든 비교 가능한 꼭짓점 집합. **임계 경로(critical path)**: 가장 큰 체인
- **$u$까지의 임계 경로**: $u$에서 끝나는 가장 큰 체인. **깊이(depth)** $\mathrm{depth}(u)$: 그 체인에서 $u$보다 작은 원소 수(극소원은 0)
- **반사슬(antichain)**: 어느 두 원소도 비교 불가(서로 다른 두 꼭짓점 사이 보행 없음)

## 2. 공식
| 공식 | 기호 | 사용 조건 |
|---|---|---|
| $2\lvert E\rvert=\sum_{v\in V}\deg(v)$ (악수 정리) | $\lvert E\rvert$: 변 수 | 무방향 그래프 [A p16] |
| $\lvert E\rvert=\sum_{v\in V}\deg^-(v)=\sum_{v\in V}\deg^+(v)$ | $\deg^\mp$: 진입·진출 차수 | 방향 그래프 [A p17] |
| $\mathrm{dist}(u,w)\le\mathrm{dist}(u,v)+\mathrm{dist}(v,w)$ | 등호 ⇔ $v$가 $u\to w$ 최단 경로 위 | 모든 $u,v,w$ [A p20] |
| 길이 $k$ 보행 계수 행렬 $=(\mathbf{A}_G)^k$ | $k=0,1,2,\dots$ | [A p26] |
| $\mathbf{C}$(길이 $k$)$\cdot\mathbf{D}$(길이 $m$) = 길이 $k+m$ 보행 계수 행렬 | | 같은 그래프 [A p26] |
| $\mathbf{A}^*=\mathbf{A}^0\cup\mathbf{A}^1\cup\cdots\cup\mathbf{A}^{\lvert V\rvert-1}=(\mathbf{A}^0\cup\mathbf{A})^{\lvert V\rvert-1}$ | 경로 길이 $\le\lvert V\rvert-1$ | 방향 그래프 [A p29] |
| $A_k=\{u\in V:\mathrm{depth}(u)=k\}$ | 최소 시간 스케줄의 $k$단계 | 유한 DAG [A p37] |

## 3. 원리·결론
- 인터넷·뇌·지도·소셜 네트워크 등 복잡한 대상의 밑바탕 = 그래프(네트워크) 구조 [A p3]
- 홀수 차수 꼭짓점의 개수는 짝수 (악수 정리 따름정리) [A p16]
- 최단 보행(있다면)은 경로 [A p20]
- 한 꼭짓점을 지나는 가장 짧은 양의 길이 투어는 그 꼭짓점을 지나는 사이클 [A p20]
- 희소(sparse) 그래프 → 인접 리스트 유리, 조밀(dense) 그래프 → 인접 행렬 유리 [A p23]
- 보행 존재 ⇔ 경로 존재 → $\mathbf{A}^*$는 $\lvert V\rvert-1$제곱까지만 필요. 반복 제곱으로 $n-1$번 대신 $\log n$번 합성 [A p29]
- 에르되시 수(Erdős number): 수학 공동 저자 그래프에서 Paul Erdős까지 최단 경로 길이. Erdős 본인 0(1명), 1: 504명, 2: 6,593, 3: 33,605, 4: 83,642, 5: 87,760(최다), 6: 40,014, 7: 11,591, 8: 3,146, 9: 819, 10: 244, 11: 68, 12: 23, 13: 5 [A p28]
- 선수과목 그래프에 양의 길이 닫힌 보행이 있으면 졸업 불가 → 사이클 금지 = DAG [A p31]
- DAG: 작업 스케줄링·동시성 제어 분석의 핵심. 작업 = 꼭짓점, 직접 선행 제약 = 변 [A p32]
- 모든 유한 DAG는 위상 정렬을 가짐 ("아침에 옷을 입을 수 있다") [A p34]
- 병렬 스케줄 가정: 모든 작업 시간 동일, 프로세서 동일. 목표 = 총 시간 최소 [A p35]
- 최소 시간 스케줄 = 깊이별 분할, **병렬 시간 = 임계 경로 크기** [A p37]
- 최대 체인 크기 $t$ → $V$를 $t$개 반사슬로 분할 가능($A_k$ = 깊이 $k$ 집합) [A p38]
- **딜워스 보조정리(Dilworth's lemma)**: 모든 $t>0$에 대해 꼭짓점 $n$개 DAG는 크기 $t$ 초과 체인 또는 크기 $n/t$ 이상 반사슬을 가짐 [A p38–39]

## 4. 문제 유형별 접근
- 차수 조건으로 변 수 구하기: 차수 합 계산 → $\lvert E\rvert$ = 합/2
- 그래프 존재 여부 판정: 차수 합이 홀수 / 홀수 차수 꼭짓점이 홀수 개 → 불가능
- 보행·경로·투어·사이클 판별: 꼭짓점 반복 → 시작 = 끝 → 길이 > 0 순서로 확인
- 인접 행렬 작성: 꼭짓점 순서 고정 → 변(루프·다중 변은 개수)마다 성분 기록 → 무방향이면 대칭 확인
- 길이 $k$ 보행 수: $(\mathbf{A}_G)^k$의 $(i,j)$ 성분
- 최단 경로 길이: $\mathbf{A}_G,\mathbf{A}_G^2,\dots,\mathbf{A}_G^{n-1}$ 순서로 계산 → 각 성분이 처음 양수가 되는 지수 [A p27] (가중 그래프 최소 비용 경로로 확장 가능)
- 위상 정렬: 극소원 하나 선택 → 제거 → 새 극소원 중 선택 반복 → 고른 순서가 답 [A p34]
- 최소 병렬 시간·프로세서 수: 각 꼭짓점 깊이 계산 → 깊이별 묶음 $A_k$ → 시간 = 블록 수(= 임계 경로 크기), 프로세서 = $\max_k\lvert A_k\rvert$
- 딜워스 적용: 최대 체인 크기 $s$ 확인 → $s\le t$이면 깊이별 $s$개 반사슬 → 비둘기집 원리로 $n/s\ge n/t$ 이상인 반사슬

## 5. 실수 포인트
- 그래프 용어는 표준이 없음 → 자료마다 정의 확인 [A p5]
- 무방향 차수: 루프 **2**. 방향: 루프는 진입·진출 차수에 **1씩**. 인접 행렬: 루프는 $(i,i)$에 **1** [A p14–15, p24]
- 꼭짓점 하나 = 길이 0 경로이자 투어, 사이클은 **아님**(사이클은 양의 길이). 루프 허용 시 길이 1 사이클 가능 [A p18]
- 방향 그래프 인접 행렬은 대칭이 아닐 수 있음 [A p24]
- 접속 행렬은 $n\times m$(꼭짓점 × 변), 인접 행렬은 $n\times n$
- 길이 0 보행 계수 행렬 = 단위행렬, $\mathbf{A}^0=\mathrm{Id}_V$(관례)
- 최소원 ≠ 극소원. DAG에 최소원이 없어도 극소원은 여러 개일 수 있음 [A p34]
- 위상 정렬은 하나로 정해지지 않음(옷 입기 예시 (a), (b) 둘 다 정답) [A p33]
- 깊이는 0부터: 극소원 depth 0 → $A_0$. p36 그림은 $A_1$~$A_4$로 표기 [A p36–37]
- 체인 "크기" = 원소 수(변 수 아님). 깊이 = 그 체인에서 $u$보다 작은 원소 수
- p17 증명 문장은 첫 합을 outgoing으로 적었으나 $\sum\deg^-$는 들어오는 변의 합(원본 오기 의심, 결론은 동일)
