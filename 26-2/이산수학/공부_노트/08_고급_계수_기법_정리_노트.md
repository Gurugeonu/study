# 08 고급 계수 기법 정리 노트

> 범위: A p2–26 (8.1~8.3, 8.5~8.6절) · 출처 약어: A = 08. Advanced Counting Techniques.pdf
> p5 절 표지 제목(Discrete Probability)은 원본 오기, 실제 내용은 8.2절 선형 점화식 풀이

## 1. 핵심 개념
- **점화식(recurrence relation)**: $a_n$을 앞선 항 $a_0,\dots,a_{n-1}$ 중 하나 이상으로 나타낸 식, $n\ge n_0$ ($n_0$은 음이 아닌 정수) [A p2]
- **점화식의 해**: 항들이 점화식을 만족하는 수열 [A p2]
- **초기 조건(initial conditions)**: 점화식이 적용되기 시작하는 항보다 앞선 항들의 값 [A p2]
- **상수 계수 $k$차 선형 동차 점화식**: $a_n=c_1a_{n-1}+\dots+c_ka_{n-k}$, $c_i$ 실수, $c_k\ne0$ [A p6]

| 용어 | 뜻 [A p6] | 위반 예 [A p7] |
|---|---|---|
| 선형(linear) | 우변 = 앞 항들에 $n$의 함수를 곱한 합 | $a_n=a_{n-1}+a_{n-2}^2$ |
| 동차(homogeneous) | $a_j$의 배수가 아닌 항 없음 | $H_n=2H_{n-1}+1$ |
| 상수 계수 | 계수가 모두 상수 | $B_n=nB_{n-1}$ |
| 차수 $k$ | 앞의 $k$개 항으로 표현 | $P_n=1.11P_{n-1}$은 1차, $f_n=f_{n-1}+f_{n-2}$는 2차 |

- **특성방정식(characteristic equation)**: $r^k-c_1r^{k-1}-c_2r^{k-2}-\dots-c_{k-1}r-c_k=0$, 그 해 = **특성근(characteristic roots)** [A p8]
- **상수 계수 선형 비동차 점화식**: $a_n=c_1a_{n-1}+\dots+c_ka_{n-k}+F(n)$, $c_k\ne0$, $F(n)$은 $n$에만 의존하고 항등적으로 0이 아닌 함수. $F(n)$을 뺀 식 = **연관된 동차 점화식** [A p13]
  - 예: $a_n=a_{n-1}+2^n$, $a_n=a_{n-1}+a_{n-2}+n^2+n+1$, $a_n=3a_{n-1}+n3^n$
- **분할 정복 알고리즘(divide-and-conquer)**: 같은 문제의 더 작은 사례들로 나눈 뒤(분할), 그 해로 원래 문제를 해결(정복) [A p16]
  - 이진 탐색: 가운데 원소와 비교 → 알맞은 절반에서 재귀 탐색
  - 병합 정렬: 거의 같은 크기 두 리스트로 나눠 재귀 정렬 → 차례로 병합
- **교란(derangement)**: 어떤 원소도 원래 자리에 두지 않는 순열 (21453은 12345의 교란, 21543은 4가 제자리라 아님) [A p25]

## 2. 공식
| 공식 | 기호 | 사용 조건 |
|---|---|---|
| $f_n=f_{n-1}+f_{n-2}$ | $f_n$: $n$개월 뒤 토끼 쌍 수 | $n\ge3$, $f_1=f_2=1$ [A p3] |
| $H_n=2H_{n-1}+1$ | $H_n$: 원판 $n$개 하노이 탑 최소 이동 수 | $H_1=1$ [A p4] |
| $a_n=\alpha_1r_1^n+\alpha_2r_2^n$ | $\alpha_i$: 초기 조건으로 정하는 상수 | 2차, $c_2\ne0$, 서로 다른 두 근 [A p9] |
| $a_n=\alpha_1r_0^n+\alpha_2nr_0^n$ | $r_0$: 중근 | 2차, $c_2\ne0$, 중근 [A p9] |
| $a_n=\alpha_1r_1^n+\dots+\alpha_kr_k^n$ | | $k$차, 서로 다른 $k$개 근 [A p12] |
| $a_n=\sum_{i=1}^{t}\left(\alpha_{i,0}+\alpha_{i,1}n+\dots+\alpha_{i,m_i-1}n^{m_i-1}\right)r_i^n$ | $m_i$: $r_i$의 중복도, $m_i\ge1$, $\sum m_i=k$ | $k$차, 서로 다른 근 $t$개 [A p12] |
| $f_n=\frac{1}{\sqrt5}\left(\frac{1+\sqrt5}{2}\right)^n-\frac{1}{\sqrt5}\left(\frac{1-\sqrt5}{2}\right)^n$ | 피보나치 명시 공식 | $f_0=0$, $f_1=1$ [A p11] |
| $a_n=a_n^{(p)}+a_n^{(h)}$ | $(p)$: 특수해, $(h)$: 연관 동차 해 | 선형 비동차 [A p14] |
| $f(n)=af(n/b)+g(n)$ | $a$: 부분 문제 수, $n/b$: 크기, $g(n)$: 정복 단계 추가 연산 | 분할 정복 점화식 [A p17] |
| 이진 탐색 $f(n)=f(n/2)+1$ / 병합 정렬 $f(n)=2f(n/2)+n$ | | [A p17] |
| $f(2n)=3f(n)+Cn$ | $Cn$: 덧셈·뺄셈·시프트 비트 연산 수 | 빠른 정수 곱셈 [A p18] |
| $ab=(2^{2n}+2^n)a_1b_1-2^n(a_1-a_0)(b_1-b_0)+(2^n+1)a_0b_0$ | $a=2^na_1+a_0$, $b=2^nb_1+b_0$ | $2n$비트 정수 [A p18] |
| $f(n)=C_1n^{\log_ba}+C_2$ | $C_1=f(1)+\frac{c}{a-1}$, $C_2=-\frac{c}{a-1}$ | $f(n)=af(n/b)+c$, $n=b^k$, $a\ne1$ [A p19] |
| $\lvert A\cup B\rvert=\lvert A\rvert+\lvert B\rvert-\lvert A\cap B\rvert$ | | 유한집합 [A p22] |
| $\lvert A\cup B\cup C\rvert=\lvert A\rvert+\lvert B\rvert+\lvert C\rvert-\lvert A\cap B\rvert-\lvert B\cap C\rvert-\lvert C\cap A\rvert+\lvert A\cap B\cap C\rvert$ | | 유한집합 [A p22] |
| $\left\lvert\bigcup_{i=1}^n A_i\right\rvert=\sum_{i}\lvert A_i\rvert-\sum_{i<j}\lvert A_i\cap A_j\rvert+\dots+(-1)^{n-1}\lvert A_1\cap\dots\cap A_n\rvert$ | 포함·배제 원리 | 유한집합 [A p23] |
| $n^m-\binom n1(n-1)^m+\binom n2(n-2)^m-\dots+(-1)^{n-1}\binom n{n-1}1^m$ | $m$원소 → $n$원소 전사 함수 수 | $m\ge n$, 양의 정수 [A p24] |
| $D_n=n!\left[1-\frac1{1!}+\frac1{2!}-\dots+(-1)^n\frac1{n!}\right]$ | $D_n$: $n$원소 교란 수 | [A p25] |

## 3. 원리·결론
- 토끼 표(1~6개월): 번식 쌍 0,0,1,1,2,3 + 어린 쌍 1,1,1,2,3,5 = 전체 1,1,2,3,5,8 [A p3]
- 선형 동차 점화식 + 초기 조건 $k$개($a_0,\dots,a_{k-1}$) → 수열 유일 결정 (강한 귀납법) [A p6]
- $a_n=r^n$이 해 ⇔ $r^n=c_1r^{n-1}+\dots+c_kr^{n-k}$ ⇔ $r$이 특성근 [A p8]
- 특성근으로 모든 해의 명시적 공식 구성 [A p8]
- 비동차 점화식의 모든 해 = 특수해 하나 + 연관 동차 점화식의 해 [A p14]
- 정리: $f$ 증가, $f(n)=af(n/b)+c$ ($b\mid n$, $a\ge1$, 정수 $b>1$, $c>0$) → $a>1$: $O(n^{\log_ba})$, $a=1$: $O(\log n)$ [A p19]
- **마스터 정리**: $f$ 증가, $f(n)=af(n/b)+cn^d$ ($n=b^k$, $a\ge1$, 정수 $b>1$, $c>0$, $d\ge0$) [A p19]

| 조건 | $f(n)$ |
|---|---|
| $a<b^d$ | $O(n^d)$ |
| $a=b^d$ | $O(n^d\log n)$ |
| $a>b^d$ | $O(n^{\log_ba})$ |

- 병합 정렬 비교 횟수 $M(n)=2M(n/2)+n$ → $O(n\log n)$ [A p20]
- 빠른 곱셈 $f(n)=3f(n/2)+Cn$ → $O(n^{\log 3})$, $\log3\approx1.6$ → 기존 $O(n^2)$보다 크게 개선 [A p20]
- 포함·배제: 합집합의 각 원소를 정확히 1번만 세도록 더하고 빼는 원리 [A p22–23]
- 전사 함수 = "$b_i$가 치역에 없음"($P_i$)이 하나도 성립하지 않는 함수 [A p24]
- 모자 보관 문제: 아무도 자기 모자를 못 받을 확률 $=D_n/n!$ [A p26]
- $D_n/n!=1-\frac1{1!}+\frac1{2!}-\dots+(-1)^n\frac1{n!}\to e^{-1}$ ($n\to\infty$) [A p26]

## 4. 문제 유형별 접근
- 상황 → 점화식 세우기: 마지막 단계(마지막 달, 가장 큰 원판)를 기준으로 작은 경우와 연결 → 초기 조건 명시
- 점화식 분류: 선형? 동차? 계수 상수? 차수? 순서로 판정
- 선형 동차 풀이: 특성방정식 → 근 구하기(서로 다름/중근) → 일반해 → 초기 조건으로 $\alpha$ 연립
- 선형 비동차 풀이: 연관 동차 해 → $F(n)$ 꼴 따라 특수해 추측(예: $2n$이면 $cn+d$) → 대입해 계수 결정 → 합 → 초기 조건
- 분할 정복 복잡도: $a,b,c,d$ 읽기 → $a$와 $b^d$ 비교 → 마스터 정리 해당 경우
- "하나도 ~하지 않는" 개수: 나쁜 성질 $P_i$ 정의 → $N-\sum N(P_i)+\sum N(P_iP_j)-\dots$
- 교란·모자 문제: $D_n$ 공식 → 확률이면 $n!$로 나눔

## 5. 실수 포인트
- 특성방정식은 계수를 좌변으로 넘김 → $-c_i$ 부호
- 중근이면 두 번째 해에 $n$을 곱함($nr_0^n$)
- 초기 조건 첨자 확인: 토끼 $f_1=f_2=1$, 명시 공식은 $f_0=0,f_1=1$, 비동차 예제는 $a_1=3$
- 비동차 상수 $\alpha$는 특수해까지 더한 전체 식에 초기 조건 대입
- 마스터 정리 비교 대상은 $a$와 $b^d$, $g(n)=Cn$이면 $d=1$ (원본 p20은 빠른 곱셈에 $d=0$으로 적었으나 $d=1$이 맞음, 결론은 같음)
- 포함·배제 부호: 홀수 개 교집합 $+$, 짝수 개 교집합 $-$
