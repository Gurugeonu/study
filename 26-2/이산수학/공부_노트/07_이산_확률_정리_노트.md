# 07 이산 확률 정리 노트

> 범위: A p2–44 (7.1 이산 확률 입문, 7.2 확률론, 7.3 베이즈 정리, 7.4 확률변수·기댓값·분산) · 출처 약어: A = 07. Discrete Probability.pdf

## 1. 핵심 개념

| 용어 | 뜻 |
|---|---|
| **실험(experiment)** | 가능한 결과 집합 중 하나를 내는 절차 [A p3] |
| **표본공간(sample space)** $S$ | 가능한 결과 전체의 집합 [A p3] |
| **사건(event)** $E$ | 표본공간의 부분집합 [A p3] |
| **확률 분포(probability distribution)** | 각 결과 $s$에 $p(s)$를 주는 함수. $0\le p(s)\le1$, $\sum_{s\in S}p(s)=1$ [A p11] |
| **조건부 확률(conditional probability)** | $p(E\mid F)=\dfrac{p(E\cap F)}{p(F)}$, 단 $p(F)>0$ [A p13] |
| **독립(independent)** | $p(E\cap F)=p(E)p(F)$. 직관: $p(E\mid F)=p(E)$ [A p15] |
| **쌍별 독립(pairwise independent)** | 모든 쌍 $i<j$에 $p(E_i\cap E_j)=p(E_i)p(E_j)$ [A p16] |
| **상호 독립(mutually independent)** | $1\le i_1<\dots<i_m\le n$, $m\ge2$인 모든 모임에 $p(E_{i_1}\cap\dots\cap E_{i_m})=p(E_{i_1})\cdots p(E_{i_m})$ [A p16] |
| **베르누이 시행(Bernoulli trial)** | 결과가 성공·실패 둘뿐인 시행. 성공 $p$, 실패 $q$, $p+q=1$ [A p18] |
| **이항분포(binomial distribution)** | $b(k:n,p)$를 $k$의 함수로 본 것 [A p19] |
| **사전확률(prior)** $p(H)$ / **가능도(likelihood)** $p(E\mid H)$ / **사후확률(posterior)** $p(H\mid E)$ | $H$: 가설, $E$: 증거. 사후확률 = 증거를 본 뒤 가설에 대한 믿음 [A p21] |
| **확률변수(random variable)** | 함수 $X:S\to\mathbb{R}$. 각 결과에 실수 배정. 변수도 아니고 무작위도 아님 [A p35] |
| **확률변수의 분포** | 모든 $r\in X(S)$에 대한 쌍 $(r,\ p(X=r))$의 집합 [A p35] |
| **기댓값(expected value, 평균)** | $E(X)=\sum_{s\in S}p(s)X(s)$ [A p36] |
| **기하분포(geometric distribution)** | $p(X=k)=(1-p)^{k-1}p$, $k=1,2,\dots$, $0\le p\le1$ [A p39] |
| **독립 확률변수** | $p(X=r_1 \text{ 그리고 } Y=r_2)=p(X=r_1)\,p(Y=r_2)$ [A p40] |
| **편차(deviation)** | $X(s)-E(X)$ [A p41] |
| **분산(variance)** / **표준편차(standard deviation)** | $V(X)=\sum_{s\in S}(X(s)-E(X))^2p(s)$ (편차 제곱의 가중평균) / $\sigma(X)=\sqrt{V(X)}$ [A p41] |

## 2. 공식

| 공식 | 기호·뜻 | 사용 조건 |
|---|---|---|
| $p(E)=\dfrac{\lvert E\rvert}{\lvert S\rvert}$ (라플라스 정의) | $\lvert\cdot\rvert$: 원소 개수 | 유한 표본공간, 모든 결과가 동등하게 가능 [A p3] |
| $0\le p(E)\le1$ | | 모든 사건 [A p3] |
| $p(\overline{E})=1-p(E)$ | $\overline{E}=S-E$: 여사건 | 모든 사건 [A p7, p12] |
| $p(E_1\cup E_2)=p(E_1)+p(E_2)-p(E_1\cap E_2)$ | | 모든 두 사건 [A p8, p12] |
| $p\left(\bigcup_i E_i\right)=\sum_i p(E_i)$ | | $E_1,E_2,\dots$가 쌍마다 서로소 [A p12] |
| $C(n,k)\,p^k q^{n-k}=b(k:n,p)$ | 정확히 $k$번 성공 확률, $q=1-p$ | $n$번 **독립** 베르누이 시행 [A p19] |
| $p(E)=p(F)p(E\mid F)+p(\overline F)p(E\mid\overline F)$ | 보조정리(전확률) | [A p23] |
| $p(F\mid E)=\dfrac{p(E\mid F)p(F)}{p(E\mid F)p(F)+p(E\mid\overline F)p(\overline F)}$ | 베이즈 정리 | $p(E)\ne0,\ p(F)\ne0$ [A p22] |
| $p(F_j\mid E)=\dfrac{p(E\mid F_j)p(F_j)}{\sum_{i=1}^n p(E\mid F_i)p(F_i)}$ | 일반화된 베이즈 정리 | $F_i$ 서로 배타, $F_1\cup\dots\cup F_n=S$, $p(E)\ne0$, $p(F_i)\ne0$ [A p27] |
| $p(w)=\dfrac{n_B(w)}{\lvert B\rvert},\ q(w)=\dfrac{n_G(w)}{\lvert G\rvert}$ | $B$: 스팸 모음, $G$: 정상 모음, $n_B(w),n_G(w)$: 단어 $w$ 등장 수 | 경험적 추정 [A p28] |
| $r(w)=\dfrac{p(w)}{p(w)+q(w)}$ | 스팸일 확률 추정 | $p(S)=\tfrac12$ 가정 [A p29] |
| $r(w_1,\dots,w_k)=\dfrac{\prod p(w_i)}{\prod p(w_i)+\prod q(w_i)}$ | $k=2$이면 $\dfrac{p(w_1)p(w_2)}{p(w_1)p(w_2)+q(w_1)q(w_2)}$ | 단어 사건 독립 가정, $p(S)=\tfrac12$ [A p31, p33] |
| $p(X=r)=\sum_{s\in S,\,X(s)=r}p(s)$, $E(X)=\sum_{r\in X(S)}p(X=r)\,r$ | 값별로 묶은 기댓값 | [A p36] |
| $E(a_1X_1+\dots+a_nX_n+b)=a_1E(X_1)+\dots+a_nE(X_n)+b$ | 기댓값의 선형성 | $X_i$는 $S$ 위 확률변수, $a_i,b$ 실수 (독립 불필요) [A p37] |
| $E(X)=np$ | 베르누이 성공 횟수 기댓값 | $n$번 상호 독립 베르누이 시행 [A p36] |
| $E(X)=1/p$ | 기하분포 기댓값 | 모수 $p$인 기하분포 [A p39] |
| $E(XY)=E(X)E(Y)$ | | $X,Y$ 독립 [A p40] |
| $V(X)=E(X^2)-E(X)^2$ | | 모든 확률변수 [A p41] |
| $V(X_1+\dots+X_n)=V(X_1)+\dots+V(X_n)$ | 비에나메 공식(Bienaymé's formula) | $n=2$: 독립 / 일반: 쌍별 독립 [A p42] |
| $V(X)=npq$ | 베르누이 성공 횟수 분산, $V(X_i)=pq$ | $n$번 독립 베르누이 시행 [A p42] |
| $\Pr[R\ge x]\le\dfrac{E(R)}{x}$ ⇔ $\Pr[R\ge c\cdot E(R)]\le\dfrac1c$ | 마르코프 정리(Markov's theorem) | $R\ge0$, $x>0$ / $c\ge1$ [A p43] |
| $p(\lvert X(s)-E(X)\rvert\ge r)\le\dfrac{V(X)}{r^2}$ | 체비쇼프 부등식(Chebyshev's inequality) | $r>0$ 실수 [A p44] |

## 3. 원리·결론
- 라플라스 정의는 동등 가능할 때만 성립. 확률 분포 정의는 이 제한을 없앤 일반화. [A p11]
- 일반 확률 분포에서도 여사건·합사건 공식 그대로 성립. [A p12]
- 상호 독립 ⇒ 쌍별 독립. 역은 거짓(반례: 동전 2개 [A p17]). [A p16]
- 생일 역설: 1년 366일·모든 생일 동등 가정에서, 생일이 같은 사람이 있을 확률이 $\tfrac12$를 넘는 최소 인원 23명. "역설"은 모순이 아니라 직관에 어긋난다는 뜻. [A p9]
- 베이즈 정리 쓰임: 양성/음성 결과가 나왔을 때 실제 질병 확률 등. 의학·법·인공지능·공학. [A p21]
- 사전확률이 매우 작은 희귀 질병은 검사 양성이어도 실제 병일 확률이 작음(거짓 양성이 압도). 음성이면 병이 없을 확률은 거의 1. [A p25–26]
- 베이즈 정리 = 일반화된 베이즈 정리의 $F_1=F$, $F_2=\overline F$인 특수한 경우. [A p27]
- 스팸 필터: $r$이 임계값보다 크면 스팸으로 분류. 스팸 빈도 자료가 있으면 $p(S)$를 더 잘 추정 가능. [A p29]
- 고려하는 단어가 많을수록 정확. 단어 쌍을 한 덩어리로, 또는 특정 문자열을 고려해 추가 개선. [A p31, p33]
- 마르코프 정리: 확률변수가 평균보다 훨씬 큰 값을 가질 확률의 거친 상한. [A p43]

## 4. 문제 유형별 접근
- 라플라스 확률: 전체 경우의 수 $\lvert S\rvert$ → 목표 사건 경우의 수 $\lvert E\rvert$ (곱의 법칙, $C$, $P$) → 나눗셈 [A p4–6]
- "적어도 하나": 여사건("하나도 없음") 확률을 1에서 뺌 [A p7, p9]
- "A 또는 B": 합사건 공식, 교집합 빼기 [A p8]
- 조건부 확률: $E\cap F$와 $F$를 원소 나열로 셈 → 나눗셈 [A p13–14]
- 독립 판정: $p(E)$, $p(F)$, $p(E\cap F)$ 구한 뒤 곱과 비교 [A p15]
- 상호 독립 판정: 모든 쌍 + 셋 이상 모든 모임까지 확인 (표 활용) [A p17]
- 정확히 $k$번 성공: 독립 베르누이 확인 → $C(n,k)p^kq^{n-k}$ [A p18]
- 베이즈: 사건 $F$(원인), $E$(관찰) 정함 → $p(F)$, $p(E\mid F)$, $p(E\mid\overline F)$ 정리 → 공식 대입 [A p22, p25]
- 스팸: $p(w)$, $q(w)$ 계산 → $r$ 계산 → 임계값과 비교 [A p30, p32]
- 복잡한 개수의 기댓값: 지시 확률변수(맞으면 1, 아니면 0)의 합으로 분해 → 선형성 [A p37–38]
- 분산: $E(X)$, $E(X^2)$ 구해 $E(X^2)-E(X)^2$, 또는 독립 합이면 비에나메 공식 [A p41–42]
- 꼬리 확률 상한: 음수 아님+기댓값만 알면 마르코프, 분산까지 알면 체비쇼프 [A p43–44]

## 5. 실수 포인트
- 결과가 동등하게 가능하지 않으면 $\lvert E\rvert/\lvert S\rvert$ 사용 불가. [A p3, p11]
- 합사건에서 $p(E_1\cap E_2)$ 빼기 누락 주의. 서로소일 때만 단순 합. [A p8, p12]
- 조건부 확률 분모는 조건 사건 $F$의 확률. $p(E\mid F)\ne p(F\mid E)$. [A p13, p23]
- 두 자녀 문제: "적어도 한 명이 아들" 조건이면 $\tfrac13$ (½ 아님). [A p14]
- 쌍별 독립만 보고 상호 독립이라 결론 내지 않기. [A p16–17]
- 풀하우스: 세 장 등급·두 장 등급은 역할이 달라 $P(13,2)$ (순서 있음). [A p6]
- 이항 공식은 시행들이 독립일 때만. [A p19]
- 기댓값 선형성은 독립 불필요, $E(XY)=E(X)E(Y)$와 분산 덧셈은 독립 필요. [A p37, p40, p42]
- $V(X)=E(X^2)-E(X)^2$: $E(X^2)\ne E(X)^2$. [A p41]
- 마르코프는 음이 아닌 확률변수에만. [A p43]
- 원본 오타: p9 "$p_n$ = 적어도 둘이 다른 생일" → n명 모두 다른 생일 확률 / p16 $i\le j\le n$ → $1\le i<j\le n$ / p19 "$k-1$ failures" → $n-k$ / p30 ".0125" → 0.125 / p33 좌변 $p(w_1,\dots,w_k)$ → $r(w_1,\dots,w_k)$ / p42 "$X=X_2+X_3+\dots$" → $X_1+\dots+X_n$
