# 13 최단 경로·채색·최대 유량 정리 노트

> 범위: A p2–40 · 출처 약어: A = 13. Graphs 4.pdf (표지 표기 'Lecture 14')

## 1. 핵심 개념

### 최단 경로
- **가중 그래프(weighted graph)**: 각 간선에 수(가중치)가 배정된 그래프. 경로 길이 = 경로 위 간선 가중치의 합 [A p3]
- **최단 경로 문제**: 주어진 두 꼭짓점 사이 길이 최소 경로 찾기 [A p3]
- **외판원 문제(traveling salesperson problem)**: 완전 그래프의 모든 꼭짓점을 방문하는 총 길이 최소 회로 찾기 [A p3]
- **다익스트라 알고리즘(Dijkstra's algorithm)**: 1959년 Edsger Dijkstra. 무향 가중 그래프, **모든 가중치 양수** [A p4]
- **라벨** $L_k(v)$: $k$단계에서 $v$의 라벨 / **구별 집합(distinguished set)** $S_k$: $k$단계에서 확정된 꼭짓점 집합 [A p5]

### 평면 그래프
- **평면 그래프(planar graph)**: 간선 교차 없이 평면에 그릴 수 있는 그래프. 그 그림 = **평면 표현(planar representation)**. 교차 = 공통 끝점이 아닌 점에서 선·호가 만남 [A p11]
- **영역(region)**: 평면 표현이 평면을 나눈 부분(무한 영역 1개 포함). 어떤 평면 표현이든 영역 수 동일(Euler) [A p13]
- **기본 세분(elementary subdivision)**: 간선 $(u,v)$ 제거 + 새 꼭짓점 $w$와 간선 $(u,w),(w,v)$ 추가. 평면성 보존 [A p15]
- **위상동형(homeomorphic)**: 같은 그래프에서 기본 세분을 연속 적용해 얻을 수 있는 두 그래프 $G_1=(V_1,E_1)$, $G_2=(V_2,E_2)$ [A p15]

### 그래프 채색
- **채색(coloring)**: 단순 그래프의 각 꼭짓점에 색 배정, 인접 꼭짓점끼리 다른 색 [A p18]
- **채색수(chromatic number)** $\chi(G)$: 채색에 필요한 최소 색 수 [A p18]
- 지도 색칠 → 영역 = 꼭짓점, 경계 공유 = 간선인 그래프의 채색 [A p17]

### 최대 유량
- **유량 네트워크(flow network)** $G=(V,E)$: 방향 그래프. **소스(source)** $s$ = 흐름 시작, **싱크(sink)** $t$ = 흐름 끝, **용량(capacity)** $c(u,v)$ = 간선별 최대 한도 [A p25]
- **유량(flow)** $f$: $s$에서 $t$로 각 간선을 실제로 흐르는 양 [A p26]
- **최대 유량 문제**: $s$에서 나가는 총 유량이 최대가 되도록 $f(u,v)$ 배정 [A p28]
- **잔여 그래프(residual graph)** $G_f$: 네트워크에 남은 잠재력. 간선 가중치 = 바꿀 수 있는 용량(잔여량) [A p29]
  - **순방향 간선**: 남은 용량 $c-f$ / **역방향 간선**: 현재 유량 $f$(되돌리기, 유량 재배치) [A p29]
- **증가 경로(augmenting path)**: 잔여 그래프의 $s$–$t$ 경로. **병목(bottleneck)** = 경로 위 최소 잔여 용량 [A p31]
- **$(s,t)$-절단(cut)**: $V$를 $s\in S$, $t\in T$인 두 집합 $(S,T)$로 분할 [A p36]

## 2. 공식

| 공식 | 기호·의미 | 사용 조건 |
|---|---|---|
| $L_0(a)=0,\ L_0(v)=\infty\ (v\ne a),\ S_0=\emptyset$ | 다익스트라 초기화 | 시작점 $a$ [A p5] |
| $L_k(v)=\min\{L_{k-1}(v),\ L_{k-1}(u)+\mathrm{wt}(u,v)\}$ | $u$: $k$단계에 추가된 꼭짓점, $v\notin S_k$ | 간선 없으면 $w=\infty$ [A p5, p6] |
| $O(n^2)$ | 다익스트라 연산 수(덧셈·비교), $n$ = 꼭짓점 수 | 무향 가중 그래프 [A p8] |
| $v-e+r=2$ | $v$ 꼭짓점, $e$ 간선, $r$ 영역 수 | 연결 평면 단순 그래프 [A p13] |
| $e\le 3v-6$ | 따름정리 1 | 연결 평면 단순, $v\ge3$ [A p14] |
| $e\le 2v-4$ | 따름정리 3 | 연결 평면 단순, $v\ge3$, 길이 3 회로 없음 [A p14] |
| $\chi(C_{\text{even}})=2,\ \chi(C_{\text{odd}})=3,\ \chi(K_n)=n$ | 대표 채색수 | [A p19] |
| $0\le f(u,v)\le c(u,v)$ | 용량 제약 | 모든 간선 [A p26] |
| $\sum_{v\in V}f(u,v)=\sum_{v\in V}f(v,u)$ | 유량 보존(들어온 양 = 나간 양) | $u\in V-\{s,t\}$ [A p26] |
| $\lvert f\rvert=\sum_{v\in V}f(s,v)-\sum_{v\in V}f(v,s)$ | 순유량($s$에서 나가 $t$에 도착) | [A p26] |
| $c(S,T)=\sum_{u\in S,\,v\in T}c(u,v)$ | 절단 용량 | $S\to T$ 간선만, $T\to S$ 무시 [A p36] |
| $\lvert f\rvert\le c(S,T)$, $\max\lvert f\rvert\le\min c(S,T)$ | 약한 쌍대성(보조정리 1) | 임의의 유량·절단 [A p38] |

**최대 유량 알고리즘 복잡도** [A p32, p33]

| 방법 | 복잡도 | 비고 |
|---|---|---|
| 포드-풀커슨(Ford-Fulkerson, FF) | 반복당 $O(V)$, 반복 $O(\lvert f\rvert)$회 | 최대 유량 값 $\lvert f\rvert$에 의존 |
| Edmonds-Karp | $O(VE^2)$ | BFS로 최단 증가 경로, 다항 시간 보장 (정정: 원본 표기 'BFV'는 BFS의 오타로 보임) |
| Dinitz | $O(V^2E)$ | |
| Push-Relabel | $O(V^2E)$ 또는 $O(V^3)$ | |
| Orlin | $O(VE)$ | 이론상 가장 빠름 |

## 3. 원리·결론

### 최단 경로
- 다음으로 가까운 꼭짓점 = (확정 집합 안 꼭짓점까지 최단 경로) + (집합 안→밖 간선 하나) 중 최소 [A p4]
- $S_k=S_{k-1}\cup\{u\}$, $u$ = $S_{k-1}$ 밖 최소 라벨 꼭짓점. 추가 후 $S_k$ 밖 라벨 갱신 [A p5]
- $L_k(v)$ = $S_k$의 꼭짓점만 거치는 $a\to v$ 최단 경로 길이 [A p5]
- $z$가 구별 집합에 들어가는 순간 $L(z)$ = $a$–$z$ 최단 경로 길이 [A p5]
- **정확성 정리**: 연결 단순 무향 가중 그래프에서 두 꼭짓점 사이 최단 경로 길이를 찾음 [A p7]
- 다익스트라 연산 수 $O(n^2)$, 반복 $\le n-1$회 [A p8]

### 평면 그래프
- 세 집–세 공공시설(가스·수도·전기) 연결 문제 = $K_{3,3}$를 교차 없이 그릴 수 있는가 [A p10]
- 평면 그래프 응용: 전자 회로 설계, 도로망 설계 [A p11]
- $K_4$, $Q_3$: 평면 / $K_{3,3}$: 비평면 [A p12]
- 따름정리 2: 연결 평면 단순 그래프에는 차수 $\le5$인 꼭짓점 존재 [A p14]
- $K_5$, $K_{3,3}$: 비평면 [A p14]
- **쿠라토프스키 정리(Kuratowski's theorem)**: 비평면 ⇔ $K_{3,3}$ 또는 $K_5$와 위상동형인 부분그래프 포함. ⇐ 자명, ⇒ 증명은 복잡(생략) [A p16]

### 그래프 채색
- 각 꼭짓점에 다른 색 → 항상 채색 가능. 대부분 그보다 적은 색으로 가능 [A p18]
- 비어 있지 않은 $G$가 이분 그래프 ⇔ $\chi(G)=2$ [A p19]
- 최대 차수 $\le n$ → $(n+1)$-채색 가능(꼭짓점 수 귀납) [A p19]
- **5색 정리**: 모든 평면 그래프는 5-채색 가능(꼭짓점 수 강한 귀납) [A p20]
- **4색 정리**: 평면 그래프 채색수 $\le4$. 1850년대 추측, 1976년 Appel·Haken 증명, 약 2000가지 유형 컴퓨터 분석 → 논란 [A p21]
- 평면 그래프 채색수 = 평면 지도에서 인접 영역을 다른 색으로 칠하는 최소 색 수 [A p21]
- 채색 응용(일정 충돌): 시험 시간표, 서버 동시 업데이트, 라디오 주파수 배정, 레지스터 할당 [A p17, p22]
- 평면 그래프의 3-채색 가능 판정 = NP-완전(NPC) [A p22]

### 최대 유량
- 응용: 수도·송유관, 교통 시스템, 인터넷 데이터 전송 [A p24]
- 유량 보존: 물은 $s$에서만 생기고 $t$에서만 사라짐 [A p26]
- 탐욕적 경로 선택은 실패 가능: 한 선택이 더 좋은 미래 경로를 막음 → 잔여 그래프의 역방향 간선으로 되돌리기 [A p28, p29]
- FF 종료: 초기 용량이 모두 정수 → 잔여 용량 항상 정수 → 매 반복 최소 1 증가 → 종료 [A p32]
- 무리수 용량: 나쁜 증가 경로 선택 시 종료 안 할 수 있음, 순유량이 최대 유량으로 수렴하지 않을 수도 있음 [A p32]
- 무작위 경로 선택은 느릴 수 있음. 실제로는 FF로 대개 충분 [A p33]
- **최대 유량 최소 절단 정리(max-flow min-cut theorem)**: $s\to t$ 최대 유량 = $s,t$를 분리하는 최소 절단 용량 [A p37]
  - 의의: 최적성 증명, 유량 최대화 = 가장 좁은 병목 찾기. 쌍대성(duality)의 예 [A p37]
- 보조정리 2: $f$가 최대 유량 → $G_f$에 $s$–$t$ 경로 없음(있으면 병목 $b$만큼 $\lvert f'\rvert=\lvert f\rvert+b$) [A p38]
- 보조정리 3: $G_f$에 $s$–$t$ 경로 없음 → $S$ = $s$에서 도달 가능한 꼭짓점, $T=V-S$이면 $(S,T)$는 절단이고 $\lvert f\rvert=c(S,T)$ [A p38]
- 배정 문제: 유량 1단위 = 일 하나를 사람에게 배정 [A p39]
- 안정 매칭과 비교: 안정 매칭은 선호 반영 가능 / 최대 유량 배정은 배정 형태가 더 다양하지만 선호 반영 어려움 [A p39]

## 4. 문제 유형별 접근
- 다익스트라 손 계산: 라벨 초기화 → 밖에서 최소 라벨 $u$ 확정 → $u$의 이웃 $v$만 $\min$ 갱신(괄호에 경로 기록) → $z$ 확정 시 종료 [A p5, p6]
- 평면성 판정(평면 쪽): 교차 없는 그림을 직접 찾기($K_4$, $Q_3$) [A p12]
- 비평면 증명: ① $e>3v-6$ 확인 ② 삼각형 없으면 $e>2v-4$ 확인 ③ $K_5$·$K_{3,3}$와 위상동형인 부분그래프 찾기(차수 2 꼭짓점 지우고 간선 합치기) [A p14, p16]
- 채색수 구하기: 하한(삼각형 → $\ge3$, $K_n$ 포함 → $\ge n$) + 실제 채색(상한)으로 일치 확인 [A p19]
- 최대 유량(FF): 0 유량 → 잔여 그래프에서 증가 경로(DFS 등) → 병목 → 그만큼 증가 → 잔여 그래프 갱신 → 경로 없을 때까지 반복 [A p31]
- 최대임 확인: $G_f$에서 $s$로부터 도달 가능 집합 $S$ → $c(S,T)$ 계산 → $\lvert f\rvert$와 같으면 최대 [A p38]
- 배정 문제 모델링: 가짜 소스 → 사람(용량 = 최대 일 수) → 가능한 일(용량 1) → 가짜 타깃(용량 1) → 최대 유량 [A p40]

## 5. 실수 포인트
- 다익스트라: 가중치가 **양수**일 때만. 라벨 갱신은 **$S$ 밖** 꼭짓점만 [A p4, p6]
- 보통 교차 있게 그려진 그래프도 평면 그래프일 수 있음($K_4$) [A p11]
- 영역 수 $r$에 **바깥 무한 영역** 포함 [A p13]
- $e\le3v-6$은 필요조건: 만족해도 평면이라는 보장 없음($K_{3,3}$은 만족하지만 비평면 → $e\le2v-4$로 판정) [A p14]
- 쿠라토프스키: "부분그래프로 포함"이 아니라 "**위상동형인** 부분그래프 포함" [A p16]
- 절단 용량: $S\to T$ 간선 용량만 합산, $T\to S$ 간선 무시 [A p36]
- 잔여 그래프 역방향 간선 가중치 = 현재 유량 $f$ (용량 아님) [A p29]
- FF 반복 횟수는 $\lvert f\rvert$에 의존 → 입력 크기에 대한 다항 시간 아님 [A p32]
