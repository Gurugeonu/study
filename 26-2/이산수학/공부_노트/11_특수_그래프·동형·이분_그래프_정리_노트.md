# 11 특수 그래프·동형·이분 그래프 정리 노트

> 범위: A p2–21 (p2, p13은 절 표지) · 출처 약어: A = 11. Graphs 2.pdf

## 1. 핵심 개념

### 특수한 단순 그래프
| 이름 | 정의 | 출처 |
|---|---|---|
| **완전 그래프(complete graph)** $K_n$ | 서로 다른 두 꼭짓점 쌍마다 간선이 정확히 하나 | [A p3] |
| **순환(cycle)** $C_n$, $n\ge3$ | 꼭짓점 $v_1,\dots,v_n$, 간선 $\{v_1,v_2\},\{v_2,v_3\},\dots,\{v_{n-1},v_n\},\{v_n,v_1\}$ | [A p3] |
| **바퀴(wheel)** $W_n$, $n\ge3$ | $C_n$에 새 꼭짓점 하나 추가, 그 점을 $C_n$의 $n$개 꼭짓점 모두와 연결 | [A p3] |
| **$n$차원 하이퍼큐브(hypercube)** $Q_n$ | 길이 $n$ 비트열 $2^n$개가 꼭짓점, 정확히 한 비트만 다른 두 꼭짓점끼리 인접 | [A p4] |
| **메시(mesh) 네트워크** | 프로세서 $P(i,j)$를 격자로 배치해 상하좌우 이웃끼리 연결(그림: 16개, $4\times4$) | [A p4] |
| **완전 이분 그래프(complete bipartite graph)** $K_{m,n}$ | $\lvert V_1\rvert=m$, $\lvert V_2\rvert=n$, $V_1$의 모든 꼭짓점이 $V_2$의 모든 꼭짓점과 연결 | [A p16] |

- 네트워크 토폴로지 [A p5]: **스타(star)** = $K_{1,n}$(모든 장치가 중앙 제어 장치에 연결) · **링(ring)** = $C_n$(각 장치가 정확히 두 장치와 연결, 메시지가 고리를 따라 전달) · **$W_n$ 기반** = 스타 + 링 결합
- 특수 그래프는 병렬 처리·컴퓨터 네트워크 설계에 쓰임 [A p4–5]

### 동형
- **동형(isomorphic)**: 단순 그래프 $G_1=(V_1,E_1)$, $G_2=(V_2,E_2)$ 사이에 일대일 대응(전단사) $f:V_1\to V_2$가 있고, 모든 $a,b\in V_1$에 대해 $a,b$ 인접 $\iff f(a),f(b)$ 인접 [A p6]
- **동형사상(isomorphism)**: 위 조건의 $f$ · **비동형(nonisomorphic)**: 동형이 아닌 두 단순 그래프 [A p6]
- 의미: 꼭짓점 이름만 다를 뿐 같은 그림("up to relabeling") [A p6]
- **동형에서 보존되는 성질**: $G$가 가지면 $G$와 동형인 모든 그래프도 가지는 성질 = **그래프 불변량(graph invariant)** [A p7]
- **차수열(degree sequence)**: 꼭짓점 차수를 비증가 순으로 나열한 목록 [A p9]

### 이분 그래프와 매칭
- **이분 그래프(bipartite graph)**: $V$를 서로소 $V_1, V_2$로 분할, 모든 간선이 $V_1$의 꼭짓점과 $V_2$의 꼭짓점을 연결(같은 쪽끼리 간선 없음) [A p14]
- 동치 정의: 인접한 두 꼭짓점이 같은 색이 되지 않게 빨강·파랑으로 칠할 수 있는 그래프 [A p14]
- **매칭(matching)**(비형식): 각 남자에게 그가 좋아하는 여자를 배정, 서로 다른 남자에겐 서로 다른 여자 [A p18]
- **매칭**(형식): $M\subseteq E$, $M$의 어떤 두 간선도 같은 꼭짓점에 붙지 않는 간선 집합 [A p19]
- **덮임(covered)**: $M$의 간선에 붙은 꼭짓점 · **완전 매칭(perfect matching)**: $V$ 전체를 덮는 매칭 [A p19]
- **병목(bottleneck)**: $\lvert S\rvert > \lvert N(S)\rvert$인 꼭짓점 집합 $S\subseteq V$ ($N(S)$: $S$와 인접한 꼭짓점 집합) [A p19]
- **매칭 조건(matching condition)**: 남자의 모든 부분집합이 자기 크기 이상의 여자 집합을 좋아함 [A p19]
- **차수 제약(degree-constrained)** 이분 그래프: 어떤 정수 $d$가 있어 모든 $v_1\in V_1$, $v_2\in V_2$에 대해 $\deg v_1 \ge d \ge \deg v_2$ [A p21]

## 2. 공식
| 공식 | 기호·의미 | 조건 |
|---|---|---|
| $\lvert V(Q_n)\rvert = 2^n$ | 길이 $n$ 비트열 개수 | [A p4] |
| $\deg v = \deg f(v)$ | 동형사상 $f$는 차수 보존 | $f$가 동형사상 [A p7] |
| 대응 후보 수 $n!$ | 꼭짓점 $n$개끼리의 일대일 대응 수, $20!\approx2.4\times10^{18}$ | 무차별 대입 [A p9, p12] |
| $\lvert S\rvert > \lvert N(S)\rvert$ | 병목 | $S\subseteq V$ [A p19] |
| $\deg v_1 \ge d \ge \deg v_2$ | 차수 제약 | 모든 $v_1\in V_1$, $v_2\in V_2$ [A p21] |
| (보충) 간선 수: $K_n$ $\tfrac{n(n-1)}{2}$, $C_n$ $n$, $W_n$ $2n$, $Q_n$ $n2^{n-1}$, $K_{m,n}$ $mn$ | 간선 수 불변량 비교용 | 원본에 없음 |

## 3. 원리·결론
- 동형은 **동치 관계**: $f^{-1}$도 동형사상(대칭), 동형사상의 합성도 동형사상(추이) [A p7]
- 동형은 연결 구조만 보존, 꼭짓점 이름·재료·그림 속 위치는 무시 [A p7]
- 불변량 예: 꼭짓점 수, 간선 수, 차수열, 각 꼭짓점의 차수 [A p7, p9]
- 동형 판정 응용: 분자 그래프 데이터베이스 대조, 회로 레이아웃 검증·지식재산 판별 [A p8]
- 무차별 대입($n!$)은 비현실적, 불변량으로 비동형은 쉽게 판정하고 동형사상 탐색도 안내, 실제로는 대개 쉽게 판정 [A p9]
- 알려진 최선 알고리즘: 최악 **지수** 시간 / 평균 **선형** 시간 알고리즘 존재 / NAUTY: 꼭짓점 100개까지 1초 미만 [A p11]
- 그래프 동형 문제: 다루기 쉬운지(tractable)도, NP-완전인지도 알려지지 않은 몇 안 되는 NP 문제 [A p11]
- **색 정제(color refinement, Weisfeiler–Leman)** [A p12]
  1. 각 꼭짓점을 차수로 색칠 → 2. 이웃 색의 다중집합으로 재색칠 → 3. 색이 안 바뀔 때까지 반복
  - $G$, $H$의 최종 색 다중집합이 다르면 비동형 · 거의 모든 무작위 그래프는 이것만으로 판정
- 어려운 경우(정규·강정규 그래프): **표준 라벨링(canonical labeling)** = 결정적 "지문" 문자열, 동형 $\iff$ 같은 지문. NAUTY는 정제로 안내되는 백트래킹 탐색으로 계산 [A p12]
- 이분 그래프 응용: 업무 배정(직원–교육받은 업무, 처리 업무 수 최대화), 결혼(허용 가능한 배우자, 결혼 수 최대화) [A p17]
- 모두 짝지을 수 있다고 항상 보장되지는 않음 [A p18]
- 매칭 조건은 매칭 존재의 **필요조건**(자명) [A p19]
- **Hall 정리**: 이분 그래프 $G$에서 $V_1$을 덮는 매칭 존재 $\iff$ $V_1$의 어떤 부분집합도 병목이 아님 [A p20]
- 모든 부분집합 검사는 금방 감당 불가 → 차수만으로 매칭 존재를 보장하는 간단한 조건 존재 [A p21]
- **정리**: 차수 제약 이분 그래프면 $V_1$을 덮는 매칭 존재 [A p21]
- 예: 모든 꼭짓점 차수가 같은 정규 그래프(regular graph) [A p21]

## 4. 문제 유형별 접근
- 두 그래프 동형 판정: 꼭짓점 수 → 간선 수 → 차수열 → 같은 차수 꼭짓점의 이웃 차수 비교(색 정제) → 다르면 비동형 / 모두 같으면 차수 맞춰 $f$ 구성 후 모든 간선 대응 확인 [A p9–12]
- 이분 증명: $V_1,V_2$ 분할(또는 2색칠) 직접 제시 [A p15]
- 비이분 증명: 한 꼭짓점 색을 정하고 이웃 색을 강제 전파 → 인접한 두 점이 같은 색이 되는 모순 [A p14–15]
- 매칭 불가 증명: 병목 $S$ 하나 제시($\lvert S\rvert > \lvert N(S)\rvert$) [A p19–20]
- 매칭 존재 증명: 매칭 직접 제시, 또는 차수 제약($\deg v_1\ge d\ge\deg v_2$) 확인 [A p21]

## 5. 실수 포인트
- 불변량이 모두 같아도 동형 보장 없음 → 동형이면 $f$를 실제로 제시해 간선 대응 확인
- 동형 정의는 "인접 $\iff$ 인접"(양방향): 인접 보존만으로는 부족
- $C_n$, $W_n$은 $n\ge3$일 때만 정의
- $V_1$을 덮는 매칭 ≠ 완전 매칭($V_2$에 짝 없는 꼭짓점이 남을 수 있음, 예: [A p18]의 Martha)
- 병목은 $\lvert S\rvert$ **>** $\lvert N(S)\rvert$, Hall 조건은 $V_1$의 부분집합만 검사
- 차수 제약 정리는 충분조건일 뿐 필요조건 아님(만족 안 해도 매칭 있을 수 있음)
- (보충) 차수 제약 정리는 $d\ge1$ 가정 필요($d=0$이면 간선이 없음)
