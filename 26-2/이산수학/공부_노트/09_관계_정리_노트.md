# 09 관계 정리 노트

> 범위: A p2–24 (9.1, 9.3, 9.5, 9.6절) · 출처 약어: A = 09. Relations.pdf

## 1. 핵심 개념

### 관계와 연산 (9.1)
- **이항 관계(binary relation)** $R$ (A에서 B로): $R \subseteq A\times B$. $(a,b)\in R$을 $aRb$로도 표기 [A p3]
- **집합 A 위의 관계**: $A\times A$의 부분집합 (A에서 A로의 관계) [A p3]
- 표현 방법: 화살표 그림, 표(관계 있으면 ×) [A p3]
- **관계의 결합**: 관계도 집합 → $R_1\cup R_2,\ R_1\cap R_2,\ R_1-R_2,\ R_2-R_1$ [A p6]
- **합성(composition)** $R_2\circ R_1$: $R_1$ (A→B) 다음 $R_2$ (B→C)를 잇는 A→C 관계 [A p7]
- **거듭제곱(power)** $R^n$: $R$을 $n$번 합성한 관계 [A p8]

### 관계의 네 가지 성질 (집합 A 위의 관계 $R$) [A p5]
| 성질 | 기호 정의 |
|---|---|
| 반사(reflexive) | $\forall x\in A,\ (x,x)\in R$ |
| 대칭(symmetric) | $\forall x,y\in A,\ [(x,y)\in R \to (y,x)\in R]$ |
| 반대칭(antisymmetric) | $\forall x,y\in A,\ [(x,y)\in R \wedge (y,x)\in R \to x=y]$ |
| 추이(transitive) | $\forall x,y,z\in A,\ [(x,y)\in R \wedge (y,z)\in R \to (x,z)\in R]$ |

### 관계의 표현 (9.3)
- **0-1 행렬** $M_R=[m_{ij}]$: $A=\{a_1,\dots,a_m\}$, $B=\{b_1,\dots,b_n\}$에서 $(a_i,b_j)\in R$이면 $m_{ij}=1$, 아니면 0. 유한 집합에 사용. 원소 순서는 임의, $A=B$면 행·열에 같은 순서 [A p10]
- **유향 그래프(directed graph, digraph)**: 꼭짓점(vertex, node) 집합 $V$ + 변(edge, arc) = $V$ 원소의 순서쌍 집합 $E$ [A p12]
  - 변 $(a,b)$: $a$ = 시작점(initial vertex), $b$ = 끝점(terminal vertex)
  - 루프(loop): $(a,a)$ 꼴의 변

### 성질 판정표 [A p11, p13]
| 성질 | 행렬 $M_R$ | 유향 그래프 |
|---|---|---|
| 반사 | 주대각선 전부 1 | 모든 꼭짓점에 루프 |
| 대칭 | $m_{ji}=1$이면 $m_{ij}=1$ (대칭 행렬) | 변 $(x,y)$가 있으면 $(y,x)$도 있음 |
| 반대칭 | $i\ne j$이면 $m_{ij}=0$ 또는 $m_{ji}=0$ | $x\ne y$인 변 $(x,y)$가 있으면 $(y,x)$는 없음 |
| 추이 | — | $(x,y)$, $(y,z)$가 있으면 $(x,z)$도 있음 |

### 동치 관계 (9.5)
- **동치 관계(equivalence relation)**: 반사 + 대칭 + 추이. 관계된 두 원소는 동치(equivalent), $a\sim b$ [A p15]
- **동치류(equivalence class)** $[a]_R$: $a$와 관계된 원소 전체. 관계가 분명하면 $[a]$ [A p16]
- **대표원(representative)**: $b\in[a]_R$인 $b$. 류의 어떤 원소든 대표원 가능 [A p16]
- **합동류(congruence class modulo $m$)**: 법 $m$ 합동의 동치류 $[a]_m$ [A p16]
- **분할(partition)**: $S$의 공집합 아닌 서로소 부분집합들의 모임으로, 합집합이 $S$ [A p17]

### 부분 순서 (9.6)
- **부분 순서(partial ordering, partial order)**: 반사 + 반대칭 + 추이 [A p20]
- **부분 순서 집합(partially ordered set, poset)** $(S,R)$; 포셋의 관계는 기호 $\preccurlyeq$ [A p20]
- **비교 가능(comparable)**: $a\preccurlyeq b$ 또는 $b\preccurlyeq a$. 둘 다 아니면 **비교 불가능(incomparable)** [A p21]
- **전순서(total order) = 선형 순서(linear order)**: 모든 두 원소가 비교 가능. 그런 집합 = 전순서 집합 = 선형 순서 집합 = **사슬(chain)** [A p21]
- **정렬 집합(well-ordered set)**: $\preccurlyeq$가 전순서 + 공집합 아닌 모든 부분집합에 최소 원소 존재 [A p21]
- **사전식 순서(lexicographic ordering)**: 두 포셋의 곱 $A_1\times A_2$ 위의 순서. 문자열로 확장하면 사전 순서 [A p22]
- **하세 도표(Hasse diagram)**: 반사성·추이성 때문에 반드시 있는 변을 생략한 부분 순서 그림 [A p23]

## 2. 공식
| 공식 | 기호 | 사용 조건 |
|---|---|---|
| $R_2\circ R_1=\{(x,z)\in A\times C : \exists y\in B,\ [(x,y)\in R_1 \wedge (y,z)\in R_2]\}$ | $\circ$: 합성 | $R_1$: A→B, $R_2$: B→C [A p7] |
| $R^1=R,\quad R^{n+1}=R^n\circ R$ | 귀납적 정의 | $R$은 A 위의 관계 [A p8] |
| $m_{ij}=1$ if $(a_i,b_j)\in R$; $m_{ij}=0$ otherwise | $M_R$: 0-1 행렬 | 유한 집합 [A p10] |
| $[a]_R=\{b \mid (a,b)\in R\}$ | 동치류 | $R$이 동치 관계 [A p16] |
| $[a]_m=\{\dots,a-m,\ a,\ a+m,\ a+2m,\dots\}$ | 합동류 | 법 $m$ 합동 [A p16] |
| $A_i\ne\varnothing\ (i\in I)$, $A_i\cap A_j=\varnothing\ (i\ne j)$, $\bigcup_{i\in I}A_i=S$ | $I$: 첨자 집합 | 분할의 세 조건 [A p17] |
| $(a_1,a_2)\prec(b_1,b_2)$ ⇔ $a_1\prec_1 b_1$ 또는 ($a_1=b_1$ 이고 $a_2\prec_2 b_2$) | $\prec$: $\preccurlyeq$이면서 $\ne$ | 포셋 $(A_1,\preccurlyeq_1)$, $(A_2,\preccurlyeq_2)$ [A p22] |

## 3. 원리·결론
- $R$이 추이적 ⇔ 모든 $n=1,2,3,\dots$에 대해 $R^n\subseteq R$ (추이 관계의 거듭제곱은 자기 부분집합) [A p8]
- 동치 관계 $R$에서 다음 셋은 동치: $aRb$ ⇔ $[a]=[b]$ ⇔ $[a]\cap[b]\ne\varnothing$ [A p17]
- 동치 관계의 동치류들은 $S$의 분할. 역으로 분할 $\{A_i\}$마다 $A_i$를 동치류로 갖는 동치 관계 존재(같은 조각이면 관계) [A p18]
- 문자열 길이가 같다($l(a)=l(b)$): 동치 관계 [A p15]
- $a\equiv b \pmod m$ ($m>1$): 정수 위 동치 관계 [A p15]
- 양의 정수 위 나눔 관계: 동치 관계 아님(대칭 불성립) [A p15]
- $\ge$ (정수), $\mid$ (양의 정수 $\mathbb{Z}^+$), $\subseteq$ (멱집합): 모두 부분 순서 [A p20]
- 사전식 문자열 비교: 처음 다른 자리의 글자로 결정, 한쪽이 다른 쪽의 앞부분이면 짧은 쪽이 작음 [A p22]
- 하세 도표에서 $x\preccurlyeq y$ ⇔ $x$에서 위로 올라가는 길로 $y$에 도달 [A p23]
- 전순서의 하세 도표 = 한 줄(예: $(\{1,2,3,4\},\le)$는 1–2–3–4) [A p23]
- 하세 도표 예: 60의 약수(나눔, 1이 맨 아래·60이 맨 위), 4비트 문자열(같은 포셋을 여러 배치로) [A p24]

## 4. 문제 유형별 접근
- 성질 판정(정의): 네 정의에 대입 → 성립하면 모든 경우 확인, 불성립이면 반례 하나 [A p5]
- 성질 판정(행렬): 대각선(반사) → $M_R$과 전치 비교(대칭) → 대각선 밖 대칭 위치 1 쌍 확인(반대칭) [A p11]
- 성질 판정(그래프): 루프 → 양방향 변 → 두 단계 경로마다 직행 변 확인 [A p13]
- 합성 $R_2\circ R_1$: $R_1$의 $(x,y)$마다 $R_2$에서 $y$로 시작하는 $(y,z)$ 찾기 → $(x,z)$ 모으기 [A p7]
- 관계 → 행렬: 행=A 원소, 열=B 원소 순서 고정 → 관계 있는 칸에 1 [A p10]
- 동치 관계 증명: 반사·대칭·추이 각각 증명. 아님을 보이기: 깨지는 성질 하나의 반례 [A p15]
- 동치류 구하기: $a$와 관계된 원소 전부 모으기, 분할 조각 확인 [A p16–17]
- 부분 순서 증명: 반사·반대칭·추이 각각 증명 [A p20]
- 하세 도표 그리기(유한 포셋): 유향 그래프 → ① 루프 제거 → ② $x\prec z\prec y$인 $z$가 있는 변 $(x,y)$ 제거 → ③ 시작점을 아래에 배치하고 화살표 제거 [A p23]

## 5. 실수 포인트
- 슬라이드 제목의 "Asymmetric"과 달리 정의된 것은 **반대칭(antisymmetric)**. 대칭과 반대칭은 서로의 부정이 아님(둘 다 성립·둘 다 불성립 가능) [A p5]
- 반대칭은 "$(x,y)$와 $(y,x)$가 **둘 다** 있으면 $x=y$". 루프 $(x,x)$는 허용 [A p5, p13]
- $R_2\circ R_1$은 **$R_1$ 먼저**, 그다음 $R_2$ (오른쪽부터 적용) [A p7]
- 동치 관계는 대칭, 부분 순서는 **반대칭** — 반사·추이는 공통 [A p15, p20]
- 나눔 관계가 부분 순서인 집합은 **양의 정수** $\mathbb{Z}^+$ (정수 전체면 $1\mid -1$, $-1\mid 1$로 반대칭 깨짐) [A p20]
- 하세 도표에서 생략한 루프·추이 변을 다시 그리지 않기, 위아래 방향이 순서 방향 [A p23]
