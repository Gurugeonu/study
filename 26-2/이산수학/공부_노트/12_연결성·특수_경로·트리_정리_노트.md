# 12 연결성·특수 경로·트리 정리 노트

> 범위: A p2–42 (p2·p7·p22·p33은 절 표지) · 출처 약어: A = 12. Graphs 3.pdf

## 1. 핵심 개념

### 연결성
- **연결됨(connected)**: 두 꼭짓점 사이에 경로 존재. 모든 꼭짓점은 길이 0 경로로 자기 자신과 연결 [A p3]
- **연결 그래프**: 모든 꼭짓점 쌍이 연결. 아니면 **비연결(disconnected)**. 꼭짓점·간선 제거로 비연결 부분그래프를 만듦 = 그래프를 끊음 [A p3]
- **연결 성분(connected component)**: 더 큰 연결 부분그래프의 진부분그래프가 아닌(극대) 연결 부분그래프 [A p4]
- 방향 그래프 연결성 [A p5–6]

| 구분 | 조건 |
|---|---|
| **강연결(strongly connected)** | 모든 $a, b$에 대해 $a\to b$, $b\to a$ 방향 경로 모두 존재 |
| **약연결(weakly connected)** | 밑바탕 무향 그래프(방향 무시)에서 모든 두 꼭짓점 사이 경로 존재 |
| **강연결 성분(strong component)** | 극대 강연결 부분그래프 |

### 특수 보행
- **오일러 보행(Euler walk)**: 모든 간선을 정확히 한 번 지나는 보행 [A p10]
- **오일러 투어(Euler tour)**: 모든 간선을 정확히 한 번 지나는 닫힌 보행 [A p10]
- **해밀턴 사이클(Hamiltonian cycle)**: 모든 꼭짓점을 지나는 사이클. **해밀턴 경로**: 모든 꼭짓점을 지나는 경로 [A p16]

| | 오일러 | 해밀턴 |
|---|---|---|
| 한 번씩 지나는 대상 | 간선 | 꼭짓점 |
| 판정 | 차수만 보면 됨(필요충분조건) | 간단한 특징화 없음, SAT와 같은 부류(NPC) [A p18] |

### k-연결·절단 간선
- **k-간선 연결(k-edge connected)** 두 꼭짓점: 간선 $(k-1)$개 이하를 지운 모든 부분그래프에서 여전히 연결. 그래프(꼭짓점 ≥ 2)는 모든 서로 다른 쌍이 k-간선 연결일 때. 통신망·송유관·전력선의 고장 내성 척도 [A p20]
- **절단 간선(cut edge)**: 연결된 두 꼭짓점을 $e$ 제거 시 끊기게 하는 간선 $e$ [A p21]

### 트리
- **숲(forest)**: 사이클 없는 무향 그래프. **트리(tree)**: 연결 + 사이클 없음. 숲의 각 연결 성분 = 트리 [A p23]
- **잎(leaf)**: 숲에서 차수 ≤ 1인 꼭짓점. **고립점(isolated vertex)**: 차수 0 [A p24]
- **루트 트리(rooted tree)**: 한 꼭짓점을 루트로 지정, 모든 간선이 루트에서 멀어지는 방향 [A p28]
- 루트 트리 용어 [A p28]

| 용어 | 뜻 |
|---|---|
| 부모(parent) / 자식(child) | $u\to v$ 간선이 있으면 $u$가 $v$의 부모(유일), $v$는 $u$의 자식 |
| 형제(sibling) | 부모가 같은 꼭짓점 |
| 조상(ancestor) | 루트→그 꼭짓점 경로 위 꼭짓점(자신 제외, 루트 포함) |
| 자손(descendant) | $v$를 조상으로 갖는 꼭짓점 |
| 잎 / 내부 꼭짓점(internal) | 자식 없음 / 자식 있음 |
| $a$의 부분 트리(subtree) | $a$와 그 자손, 자손에 붙은 간선 |

- **m진 트리(m-ary)**: 모든 내부 꼭짓점의 자식 ≤ $m$. **완전 m진(full m-ary)**: 정확히 $m$. 2진 = **이진 트리(binary tree)** [A p30]
- **레벨(level)**: 루트에서 그 꼭짓점까지 유일 경로의 길이. **높이(height)**: 레벨의 최댓값 [A p30]
- **순서 루트 트리(ordered rooted tree)**: 각 내부 꼭짓점의 자식에 순서(왼→오) [A p30]
- **이진 트리(순서 정의)**: 각 내부 꼭짓점의 자식 ≤ 2인 순서 루트 트리. 첫째 = 왼쪽 자식, 둘째 = 오른쪽 자식 [A p30]
- **순회(traversal)**: 순서 트리의 모든 꼭짓점을 체계적으로 방문. 전위(preorder)·중위(inorder)·후위(postorder) [A p32]
- **전위 순회**: 루트 $r$만이면 $r$. 아니면 $r$ 방문 → $T_1, T_2, \dots, T_n$(왼→오 부분 트리)을 차례로 전위 순회 [A p32]

### 신장 트리
- **신장 부분그래프(spanning subgraph)**: 꼭짓점 집합이 $G$와 같은 부분그래프. 트리이면 **신장 트리** [A p34]
- **가중 그래프(weighted graph)**: 간선에 수치 가중치. 전체 무게 = 간선 가중치 합 [A p37]
- **최소 무게 신장 트리(MST)**: 무게가 최소인 신장 트리 [A p37]. 이후 논의의 가정: 모든 간선 가중치가 서로 다름 [A p38]
- **흑백 색칠(black-white coloring)**: $V$를 흑·백 두 블록으로 분할. **회색 간선(gray edge)**: 양 끝점 색이 다른 간선 [A p38]

## 2. 공식

| 공식 | 기호 | 사용 조건 |
|---|---|---|
| 트리 개수 $= \lvert V\rvert - \lvert E\rvert$ | $V$ 꼭짓점, $E$ 간선 집합 | 유한 숲 [A p26] |
| $\lvert V\rvert = \lvert E\rvert + 1$ | | 트리 [A p26] |
| $n = mi + 1$ | $n$ 꼭짓점 수, $i$ 내부 꼭짓점 수 | 완전 m진 트리 [A p31] |
| $n$ 주어짐: $i = \dfrac{n-1}{m}$, $l = \dfrac{(m-1)n+1}{m}$ | $l$ 잎 수 | 완전 m진 트리 [A p31] |
| $i$ 주어짐: $n = mi+1$, $l = (m-1)i + 1$ | | 완전 m진 트리 [A p31] |
| $l$ 주어짐: $n = \dfrac{ml-1}{m-1}$, $i = \dfrac{l-1}{m-1}$ | | 완전 m진 트리 [A p31] |
| 디랙: 모든 $v$에서 $\deg v \ge n/2$ → 해밀턴 사이클 | $n$ 꼭짓점 수 | 단순 그래프, $n \ge 3$ [A p18] |
| 오레: 인접하지 않은 모든 $u, v$에서 $\deg u + \deg v \ge n$ → 해밀턴 사이클 | | 단순 그래프, $n \ge 3$ [A p18] |

## 3. 원리·결론
- 비연결 그래프 = 서로소인 연결 성분 2개 이상의 합집합 [A p4]
- 강연결이면 약연결. 역은 성립 X(p6 예의 $H$: $a\to b$ 경로 없음, 약연결) [A p6]
- **홀수 사이클 정리**: 홀수 길이 사이클 포함 ⇔ 이분 그래프 아님 ⇔ 2-색칠 불가 ⇔ 홀수 길이 닫힌 보행 포함 [A p8]
- 쾨니히스베르크 다리 모델: 홀수 차수 꼭짓점 4개 → 오일러 투어 없음 [A p15]
- **오일러 정리**: 꼭짓점 ≥ 2인 연결 다중그래프에서 오일러 투어 ⇔ 모든 차수 짝수, 오일러 보행 ⇔ 홀수 차수 꼭짓점 정확히 2개(그 둘이 시작·끝) [A p11–15]
- 해밀턴 응용: 교차점·노드 한 번씩 방문 = 해밀턴 경로, TSP = 가중치 합 최소 해밀턴 사이클, 그레이 코드 = $Q_n$의 해밀턴 사이클 [A p19]
- 꼭짓점 > 1 그래프: 2-연결 ⇔ 연결 + 절단 간선 없음 [A p21]
- 간선이 절단 간선 ⇔ 사이클 위에 없음 [A p21]
- $k$개의 간선-서로소 경로로 이어짐 → $k$-연결. **멩거 정리(Menger)**: 역도 성립 [A p21]
- 꼭짓점 ≥ 2인 트리의 잎 = 차수 1 꼭짓점, 최소 2개(선 그래프가 최소) [A p24]
- **트리 동치(단순 무향)**: 연결+비순환 ⇔ 연결+모든 간선이 절단 간선(간선-극소 연결) ⇔ 모든 쌍 사이 경로 유일 ⇔ 비순환+인접 안 한 두 점에 간선 추가 시 사이클 생김(간선-극대 비순환) [A p25]
- **트리 ⇔ $\lvert V\rvert=\lvert E\rvert+1$인 숲 ⇔ 연결 + $\lvert V\rvert=\lvert E\rvert+1$** (단순 그래프) [A p26]
- 트리 응용: 케일리(1857) 포화 탄화수소 이성질체(부탄 2종), 파일 시스템, 조직도 [A p27]
- 단순 그래프: 연결 ⇔ 신장 트리 포함 [A p34]
- 연결 그래프의 모든 흑백 색칠에는 회색 간선 존재 [A p38]
- **회색 간선 보조정리**: 어떤 흑백 색칠이든 최소 무게 회색 간선은 모든 MST에 포함 [A p38]
- **회색 간선 교환 보조정리**: $e$ = 최소 무게 회색 간선, $C$ = $e$ 없는 연결 신장 부분그래프 → $\mathrm{wt}(e) < \mathrm{wt}(g)$이고 $C - g + e$가 연결인 $C$의 간선 $g$ 존재 → $C$는 최소 아님. 회색 간선 보조정리의 근거 [A p42]
- 최소 무게 회색 간선 절차는 MST로 끝남. **따름정리**: 같은 가중치 간선이 없는 연결 그래프의 MST는 유일 [A p39–40]

## 4. 문제 유형별 접근
- 오일러 판정: 연결 확인 → 각 꼭짓점 차수 → 홀수 차수 개수 0개면 투어, 2개면 그 둘 사이 보행, 그 외 없음 [A p15]
- 오일러 투어 구성(Euler): 임의 꼭짓점에서 투어 → 사용 간선 제거한 $H$ → 투어 위 꼭짓점에서 $H$의 부분 투어 → $H$에서 그 간선·고립점 제거 → 해당 꼭짓점에 끼워 넣기 → $H$에 간선 없을 때까지 [A p14]
- 해밀턴 판정: 디랙·오레 조건 확인(만족 시 존재) → 아니면 직접 탐색 [A p18]
- 트리 판정: 연결 + 사이클 없음, 또는 연결 + $\lvert V\rvert = \lvert E\rvert + 1$ [A p23, p26]
- 완전 m진 트리 개수: $n, i, l$ 중 주어진 값의 식 사용 [A p31]
- 전위 순회: 루트 → 왼쪽 부분 트리 전체 → 다음 부분 트리 … (재귀) [A p32]
- DFS 신장 트리: 루트 선택 → 마지막 꼭짓점에서 새 꼭짓점으로 경로를 최대한 연장 → 막히면 한 칸씩 되돌아가 새 경로 → 모든 꼭짓점 포함까지 [A p35]
- BFS 신장 트리: 루트 선택 → 루트의 모든 이웃 = 레벨 1 → 이전 레벨 각 꼭짓점에서 사이클 안 만드는 간선 추가 = 다음 레벨 → 반복 [A p36]
- 최소 무게 회색 간선 절차: 간선 없는 신장 숲 $S$ → $S$의 같은 성분은 같은 색인 흑백 색칠 → 최소 회색 간선 추가 → $S$ 연결까지($n-1$번) [A p39]
- **프림(Prim)**: 트리 $S$에 끝점이 정확히 하나 있는 간선 중 최소 추가(트리 = 백, 나머지 = 흑) [A p41]
- **크루스칼(Kruskal)**: $S$에 사이클을 만들지 않는(= 다른 성분을 잇는) 간선 중 최소 추가 [A p41]
- **알고리즘 3**: 아무 성분을 골라 그 성분에서 나가는 최소 간선 추가 → 병렬·분산 계산에 유리 [A p41]

## 5. 실수 포인트
- 오일러는 **간선**, 해밀턴은 **꼭짓점**을 한 번씩. 오일러 정리는 연결 + 꼭짓점 ≥ 2 조건 필요
- 쾨니히스베르크 모델 차수: A=5, B=C=D=3 → 홀수 차수 **4개**(원본 p15의 "두 개"는 오기로 보임). 결론(투어 없음)은 같음
- 디랙·오레는 **충분조건**(원본 p18은 "necessary"라 표현). 조건 불만족이어도 해밀턴 사이클이 있을 수 있음
- 강연결 → 약연결이지 역이 아님
- 잎 정의 차이: 숲에서는 차수 ≤ 1, 루트 트리에서는 자식 없는 꼭짓점(루트는 차수 1이어도 잎 아님)
- 조상에는 루트 포함, 자기 자신 제외
- $m$진 트리는 자식 "≤ $m$", 완전 $m$진은 "정확히 $m$" → 개수 공식은 완전 $m$진에만 적용
- MST 유일성은 "모든 간선 가중치가 다름" 가정에서만 보장
- BFS·DFS 신장 트리는 루트·방문 순서에 따라 달라짐
