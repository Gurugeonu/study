# 08 고급 계수 기법 설명

> 범위: A p2–26 (8.1~8.3, 8.5~8.6절) · A = 08. Advanced Counting Techniques.pdf

이 단원 전체를 한 사람의 이야기로 따라가 볼게요. 작은 섬에 관리인 **하나**가 살아요. 하나의 일은 섬에서 일어나는 것들을 "세는" 거예요. 토끼가 몇 쌍인지, 탑 퍼즐을 몇 번 만에 풀 수 있는지, 명부에서 이름을 찾는 데 몇 번 비교하는지, 축제 손님이 몇 명인지, 모자가 몇 개나 엉뚱한 주인에게 갔는지. 하나씩 손으로 세기에는 너무 많을 때, 하나는 세 가지 도구를 꺼내요. **점화식**, **분할 정복**, **포함·배제**예요.

## 1. 점화식: 오늘을 어제로 설명하기

### 왜 필요한가
섬에 토끼 한 쌍을 풀어 놓았어요. 1년 뒤 몇 쌍일지 알고 싶은데, 매달 직접 세러 다닐 수는 없어요. 대신 "이번 달 수는 지난달 수와 이런 관계가 있다"는 규칙만 알면 계산으로 따라갈 수 있어요.

### 직관: 도미노
이 단원 내내 쓸 비유는 **도미노**예요. 맨 앞 몇 개를 손으로 넘어뜨리고(초기 조건), "앞의 것이 넘어지면 다음 것이 넘어진다"는 규칙(점화식)이 있으면 줄 전체가 넘어가요.

### 정의 [A p2]
- **점화식(recurrence relation)**: 수열 $\{a_n\}$에서 $a_n$을 앞선 항 $a_0, a_1, \dots, a_{n-1}$ 중 하나 이상으로 나타낸 식이에요. $n_0$이 음이 아닌 정수일 때 $n \ge n_0$인 모든 정수 $n$에 대해 성립해요.
- **점화식의 해**: 항들이 그 점화식을 만족하는 수열이에요.
- **초기 조건(initial conditions)**: 점화식이 처음 적용되는 항보다 앞에 있는 항들의 값이에요. 도미노에서 손으로 미는 맨 앞 조각들이에요.

### 예 1: 토끼와 피보나치 [A p3]
13세기에 Leonardo Pisano(피보나치)가 다룬 원래 문제예요. 어린 토끼 한 쌍(암수 하나씩)을 섬에 풀어요. 토끼 쌍은 태어난 지 2개월이 되어야 번식을 시작하고, 그 뒤로는 매달 한 쌍씩 새로 낳아요. 토끼는 죽지 않아요.

$f_n$을 $n$개월 뒤 토끼 쌍의 수라고 해요. 점화식은 이렇게 세워요.
1. $n$개월째에 있는 쌍은 지난달에 있던 쌍 전부예요. 죽지 않으니까요. 그래서 $f_{n-1}$쌍이에요.
2. 여기에 이번 달 새로 태어난 쌍이 더해져요. 새끼를 낳는 쌍은 2개월 이상 된 쌍, 곧 두 달 전에 이미 있던 쌍이에요. 그래서 $f_{n-2}$쌍이 새로 태어나요.
3. 합치면 $f_n = f_{n-1} + f_{n-2}$ ($n \ge 3$)이고, 초기 조건은 $f_1 = f_2 = 1$이에요.

원본 표가 이걸 그대로 보여 줘요. 1~6개월의 번식 쌍은 0, 0, 1, 1, 2, 3이고 어린 쌍은 1, 1, 1, 2, 3, 5예요. 둘을 더한 전체는 1, 1, 2, 3, 5, 8이에요. 이번 달 번식 쌍 수가 두 달 전 전체 수와 같다는 점이 표에서 보여요.

### 예 2: 하노이 탑 [A p4]
섬의 사원에는 19세기 말 프랑스 수학자 Édouard Lucas가 만든 퍼즐이 있어요. 판 위에 말뚝 3개가 있고, 크기가 다른 원판들이 처음엔 모두 1번 말뚝에 큰 것이 아래로 가게 쌓여 있어요.
- 규칙: 원판은 한 번에 하나씩 옮기고, 큰 원판을 작은 원판 위에 놓으면 안 돼요.
- 목표: 모든 원판을 2번 말뚝에 같은 순서(큰 것이 아래)로 옮겨요.

$H_n$을 원판 $n$개일 때 필요한 이동 횟수라고 해요. 핵심은 **가장 큰 원판**이에요.
1. 가장 큰 원판을 움직이려면 그 위의 $n-1$개를 치워야 해요. 규칙을 지키며 3번 말뚝으로 옮기는 데 $H_{n-1}$번 걸려요. 원본 그림이 바로 이 상태예요. 1번 말뚝엔 가장 큰 원판만, 3번 말뚝엔 나머지가 쌓여 있어요.
2. 가장 큰 원판을 2번 말뚝으로 1번 옮겨요.
3. 3번 말뚝의 $n-1$개를 2번 말뚝으로 다시 $H_{n-1}$번에 옮겨요.

이보다 적은 횟수로는 할 수 없으므로 $H_n = 2H_{n-1} + 1$, 초기 조건은 $H_1 = 1$이에요.

> 보충: 차례로 넣으면 $H_2 = 3$, $H_3 = 7$, $H_4 = 15$예요.

그런데 $H_{64}$를 알려면 63번을 차례로 계산해야 할까요? 도미노를 하나하나 넘기지 않고 $n$번째 조각이 어떻게 될지 바로 알 수는 없을까요?

## 2. 선형 동차 점화식과 특성방정식 (8.2절)

> 원본 p5 절 표지 제목은 'An Introduction to Discrete Probability'로 되어 있지만, 실제 내용은 선형 점화식 풀이예요.

### 왜 필요한가
$n$을 넣으면 바로 답이 나오는 **명시적 공식**을 얻고 싶어요. 모든 점화식을 풀 수는 없지만, 모양이 단순한 종류는 정해진 방법으로 풀 수 있어요.

### 정의 [A p6]
**상수 계수 $k$차 선형 동차 점화식**은 다음 꼴이에요.
$$a_n = c_1a_{n-1} + c_2a_{n-2} + \dots + c_ka_{n-k},\quad c_1,\dots,c_k \text{는 실수},\ c_k \ne 0$$
- **선형(linear)**: 우변이 앞 항들에 각각 $n$의 함수를 곱해 더한 꼴이에요.
- **동차(homogeneous)**: $a_j$의 배수가 아닌 항이 없어요. 계수는 모두 상수예요.
- **차수 $k$**: $a_n$을 앞의 $k$개 항으로 나타내요.

원본의 판정 예 [A p7]
- $P_n = (1.11)P_{n-1}$: 1차 선형 동차
- $f_n = f_{n-1} + f_{n-2}$: 2차 선형 동차
- $a_n = a_{n-1} + a_{n-2}^2$: 제곱 때문에 선형이 아님
- $H_n = 2H_{n-1} + 1$: $+1$이 어느 $H_j$의 배수도 아니라서 동차가 아님
- $B_n = nB_{n-1}$: 계수 $n$이 상수가 아님

이런 점화식은 초기 조건 $k$개 $a_0, \dots, a_{k-1}$만 정하면 수열이 **유일하게** 정해져요. 강한 귀납법으로 보일 수 있어요. 도미노로 말하면, 앞의 $k$개를 넘어뜨리는 방식이 정해지면 그다음 조각은 앞 $k$개만 보고 넘어지니 줄 전체가 한 가지로 정해져요.

### 도출: $r^n$을 넣어 보기 [A p8]
1차인 $P_n = 1.11P_{n-1}$은 매번 1.11배가 되니 $P_n = 1.11^n P_0$처럼 거듭제곱 꼴이에요. 그래서 고차에서도 $a_n = r^n$ ($r$은 상수) 꼴의 해를 찾아봐요.
1. 점화식에 넣으면 $r^n = c_1r^{n-1} + \dots + c_kr^{n-k}$이에요. $a_n = r^n$이 해일 조건이 바로 이것이에요.
2. 양변을 $r^{n-k}$로 나누고 우변을 왼쪽으로 넘겨요. $n$이 사라져서 $r$만의 방정식이 남기 때문이에요.
$$r^k - c_1r^{k-1} - c_2r^{k-2} - \dots - c_{k-1}r - c_k = 0$$
이것이 **특성방정식(characteristic equation)**이고, 그 해가 **특성근(characteristic roots)**이에요. $\{a_n = r^n\}$이 해일 필요충분조건은 $r$이 특성근인 거예요. 특성근으로 모든 해의 명시적 공식을 만들어요. 계수를 왼쪽으로 넘겼으니 부호가 $-c_i$가 되는 점에 주의해요.

### 2차의 두 경우 [A p9]
$c_1, c_2$가 실수이고 $c_2 \ne 0$일 때 $r^2 - c_1r - c_2 = 0$을 풀어요.
- **경우 1, 서로 다른 두 근 $r_1, r_2$**: $\{a_n\}$이 $a_n = c_1a_{n-1} + c_2a_{n-2}$의 해일 필요충분조건은 상수 $\alpha_1, \alpha_2$가 있어 $a_n = \alpha_1r_1^n + \alpha_2r_2^n$ ($n = 0, 1, 2, \dots$)인 거예요.
- **경우 2, 중근 $r_0$**: 필요충분조건은 $a_n = \alpha_1r_0^n + \alpha_2nr_0^n$이에요.

> 보충: 식이 선형이라 해 두 개를 상수배해서 더해도 여전히 해예요. 그래서 $\alpha$ 두 개를 붙여 두고, 초기 조건 두 개로 값을 맞춰요. 중근일 때는 $r_0^n$ 하나뿐이라 독립인 해가 하나 부족한데, $nr_0^n$도 해가 되어서 그 자리를 채워요. $n$을 빠뜨리면 두 상수를 정할 수 없어요.

**예제 A, 서로 다른 근** [A p10]: $a_n = a_{n-1} + 2a_{n-2}$, $a_0 = 2$, $a_1 = 7$
1. 특성방정식 $r^2 - r - 2 = 0$, 곧 $(r-2)(r+1) = 0$이라 근은 $2, -1$이에요.
2. 일반해는 $a_n = \alpha_12^n + \alpha_2(-1)^n$이에요.
3. $n = 0$: $2 = \alpha_1 + \alpha_2$, $n = 1$: $7 = 2\alpha_1 - \alpha_2$예요. 두 식을 더하면 $9 = 3\alpha_1$이라 $\alpha_1 = 3$, $\alpha_2 = -1$이에요.
4. 답은 $a_n = 3\cdot2^n - (-1)^n$이에요.

**예제 B, 중근** [A p10]: $a_n = 6a_{n-1} - 9a_{n-2}$, $a_0 = 1$, $a_1 = 6$
1. $r^2 - 6r + 9 = (r-3)^2 = 0$이라 중근 $3$이에요.
2. 일반해는 $a_n = \alpha_13^n + \alpha_2n3^n$이에요.
3. $n = 0$: $1 = \alpha_1$, $n = 1$: $6 = 3\alpha_1 + 3\alpha_2$라 $\alpha_2 = 1$이에요.
4. 답은 $a_n = 3^n + n3^n$이에요.

**토끼로 돌아가기, 피보나치 명시 공식** [A p11]: 이번엔 초기 조건을 $f_0 = 0$, $f_1 = 1$로 잡아요. 토끼 문제의 $f_1 = f_2 = 1$과 첨자가 다르니 문제마다 확인해야 해요.
1. $r^2 - r - 1 = 0$의 근은 $r_1 = \frac{1+\sqrt5}{2}$, $r_2 = \frac{1-\sqrt5}{2}$예요.
2. $f_n = \alpha_1r_1^n + \alpha_2r_2^n$이에요.
3. $f_0 = 0$에서 $\alpha_1 + \alpha_2 = 0$이에요. $f_1 = 1$에서 $\alpha_1r_1 + \alpha_2r_2 = 1$이고, $\alpha_2 = -\alpha_1$을 넣으면 $\alpha_1(r_1 - r_2) = \alpha_1\sqrt5 = 1$이에요.
4. 그래서 $\alpha_1 = \frac{1}{\sqrt5}$, $\alpha_2 = -\frac{1}{\sqrt5}$이고
$$f_n = \frac{1}{\sqrt5}\left(\frac{1+\sqrt5}{2}\right)^n - \frac{1}{\sqrt5}\left(\frac{1-\sqrt5}{2}\right)^n$$

### $k$차로 넓히기 [A p12]
$c_1, \dots, c_k$가 실수일 때 특성방정식 $r^k - c_1r^{k-1} - \dots - c_k = 0$을 봐요.
- 서로 다른 근 $k$개 $r_1, \dots, r_k$이면: 해 ⇔ $a_n = \alpha_1r_1^n + \dots + \alpha_kr_k^n$
- 서로 다른 근이 $t$개이고 중복도가 $m_1, \dots, m_t$ ($m_i \ge 1$, $m_1 + \dots + m_t = k$)이면: 해 ⇔
$$a_n = \left(\alpha_{1,0} + \alpha_{1,1}n + \dots + \alpha_{1,m_1-1}n^{m_1-1}\right)r_1^n + \dots + \left(\alpha_{t,0} + \alpha_{t,1}n + \dots + \alpha_{t,m_t-1}n^{m_t-1}\right)r_t^n$$
여기서 $\alpha_{i,j}$는 상수이고 $1 \le i \le t$, $0 \le j < m_i$예요. 근이 $m$번 겹치면 $1, n, \dots, n^{m-1}$을 붙여 $m$개를 채운다고 기억하면 돼요. 2차 중근은 $m = 2$인 특수한 경우예요.

> 원본 p12에는 마지막 항이 $r_1^n$, 첨자 범위가 $i = 0, 1, \dots, t$로 적혀 있는데, 각각 $r_t^n$, $i = 1, \dots, t$의 오기로 보여요.

이 방법은 계수가 상수이고, 선형이고, 동차일 때만 써요. 그런데 하노이의 $H_n = 2H_{n-1} + 1$은 $+1$ 때문에 동차가 아니었어요. 이런 점화식은 어떻게 풀까요?

## 3. 선형 비동차 점화식

### 정의 [A p13]
$$a_n = c_1a_{n-1} + \dots + c_ka_{n-k} + F(n)$$
$c_1, \dots, c_k$는 실수이고 $c_k \ne 0$, $F(n)$은 $n$에만 의존하고 항등적으로 0이 아닌 함수예요. 여기서 $F(n)$을 뺀 $a_n = c_1a_{n-1} + \dots + c_ka_{n-k}$를 **연관된 동차 점화식**이라고 불러요. 예: $a_n = a_{n-1} + 2^n$, $a_n = a_{n-1} + a_{n-2} + n^2 + n + 1$, $a_n = 3a_{n-1} + n3^n$.

### 원리: 특수해 + 동차 해 [A p14]
$\{a_n^{(p)}\}$가 비동차 점화식의 **특수해(particular solution)** 하나라면, 모든 해는 $\{a_n^{(p)} + a_n^{(h)}\}$ 꼴이에요. $\{a_n^{(h)}\}$는 연관된 동차 점화식의 해예요.

도미노로 보면, 특수해는 "$F(n)$이라는 바람까지 맞으며 넘어지는 줄 하나"예요. 여기에 동차 해를 더해도 바람의 효과는 그대로예요.

> 보충: 해 두 개 $a_n, a_n^{(p)}$를 빼면 양쪽의 $F(n)$이 지워져서, 그 차이는 연관된 동차 점화식을 만족해요. 그래서 모든 해는 "특수해 + 동차 해"로 쓸 수 있어요.

### 예제 [A p14]: $a_n = 3a_{n-1} + 2n$, $a_1 = 3$인 해
1. 연관된 동차 점화식 $a_n = 3a_{n-1}$의 해는 $a_n^{(h)} = \alpha3^n$이에요.
2. $F(n) = 2n$이 1차식이니 특수해도 1차식 $a_n^{(p)} = cn + d$로 추측해요.
3. 대입하면 $cn + d = 3(c(n-1) + d) + 2n$이고, 정리하면 $0 = (2c + 2)n + (2d - 3c)$예요. 모든 $n$에서 성립해야 하니 $c = -1$, $d = -\frac32$예요.
4. 모든 해는 $a_n = -n - \frac32 + \alpha3^n$이에요.
5. 전체 식에 $n = 1$을 넣어요. $3 = -1 - \frac32 + 3\alpha$라 $\alpha = \frac{11}{6}$이에요. 초기 조건은 동차 해만이 아니라 특수해를 더한 전체 식에 넣어야 해요.

> 보충: 하노이도 같은 방법으로 풀려요. 동차 해 $\alpha2^n$, 상수 특수해 $d = 2d + 1$에서 $d = -1$, $H_1 = 2\alpha - 1 = 1$에서 $\alpha = 1$이라 $H_n = 2^n - 1$이에요.

하나는 이제 섬의 숫자를 계산할 수 있게 됐어요. 그런데 섬 사무실 컴퓨터가 토끼 명부를 다루는 데 걸리는 시간도 점화식으로 나타난다면 어떨까요?

## 4. 분할 정복과 점화식 (8.3절)

### 왜 필요한가와 직관
명부에서 이름 하나를 찾거나 명부 전체를 정렬하는 일은 명부가 길수록 오래 걸려요. 하나는 큰 일을 **같은 종류의 작은 일**로 쪼개 도우미들에게 나눠 주고, 돌아온 결과를 합쳐요. 도미노로 말하면 긴 줄을 짧은 줄 여러 개로 나눠 세우는 셈이에요.

### 정의 [A p16]
**분할 정복 알고리즘(divide-and-conquer algorithm)**은 문제를 같은 문제의 더 작은 사례 하나 이상으로 나누고(분할), 작은 문제의 해로 원래 문제의 해를 구해요(정복).
- **이진 탐색**: 찾는 원소를 가운데 원소와 비교한 뒤, 리스트를 둘로 나눠 알맞은 쪽에서 재귀적으로 계속 찾아요.
- **병합 정렬**: 리스트를 거의 같은 크기의 두 부분 리스트로 나눠 각각 병합 정렬로 재귀 정렬하고, 리스트 쌍을 차례로 병합해요.

### 분할 정복 점화식 [A p17]
크기 $n$인 문제를 크기 $n/b$인 부분 문제 $a$개로 나누고, 정복 단계에 추가 연산 $g(n)$이 든다면, 연산 횟수 $f(n)$은
$$f(n) = af(n/b) + g(n)$$
- 이진 탐색: 절반 하나만 보고 비교 1번이라 $f(n) = f(n/2) + 1$
- 병합 정렬: 절반 두 개를 정렬하고 병합에 $n$번이라 $f(n) = 2f(n/2) + n$

### 빠른 정수 곱셈 [A p18]
$n$이 짝수일 때 $2n$비트 정수 두 개를 곱해요. 각 수를 $n$비트 블록 두 개로 나눠 $a = 2^na_1 + a_0$, $b = 2^nb_1 + b_0$라 하면
$$ab = (2^{2n} + 2^n)a_1b_1 - 2^n(a_1 - a_0)(b_1 - b_0) + (2^n + 1)a_0b_0$$
전개해서 확인해 봐요.
1. 가운데 항은 $-2^n(a_1b_1 - a_1b_0 - a_0b_1 + a_0b_0)$예요.
2. $a_1b_1$ 항을 모으면 $2^{2n}a_1b_1$만 남아요. $+2^n$과 $-2^n$이 지워지기 때문이에요.
3. $a_0b_0$ 항을 모으면 $a_0b_0$만 남아요. 같은 이유예요.
4. 남은 $2^n(a_1b_0 + a_0b_1)$까지 더하면 $(2^na_1 + a_0)(2^nb_1 + b_0)$를 펼친 것과 같아요.

이 식에서 $n$비트 곱셈은 $a_1b_1$, $(a_1 - a_0)(b_1 - b_0)$, $a_0b_0$ **세 번**뿐이에요. 나머지는 덧셈·뺄셈·시프트예요. 그래서 $n$비트 정수 두 개를 곱하는 데 필요한 전체 연산 수를 $f(n)$이라 하면 $f(2n) = 3f(n) + Cn$이고, $Cn$은 덧셈·뺄셈·시프트의 비트 연산 수예요.

### 크기 추정 정리 [A p19]
$f$가 증가 함수이고, $n$이 $b$로 나누어떨어질 때 $f(n) = af(n/b) + c$를 만족한다고 해요. $a \ge 1$, $b$는 1보다 큰 정수, $c$는 양의 실수예요. 그러면
- $a > 1$이면 $f(n)$은 $O(n^{\log_ba})$
- $a = 1$이면 $f(n)$은 $O(\log n)$
- 또 $n = b^k$ ($k$는 양의 정수)이고 $a \ne 1$이면 $f(n) = C_1n^{\log_ba} + C_2$, $C_1 = f(1) + c/(a-1)$, $C_2 = -c/(a-1)$

> 보충: 이진 탐색 $f(n) = f(n/2) + 1$은 $a = 1$인 경우라 $O(\log n)$이에요.

### 마스터 정리 [A p19]
추가 연산이 상수가 아니라 $cn^d$일 때 쓰는 정리예요. $f$가 증가 함수이고 $n = b^k$ ($k$는 양의 정수)일 때 $f(n) = af(n/b) + cn^d$를 만족하며, $a \ge 1$, $b$는 1보다 큰 정수, $c > 0$, $d \ge 0$이면
$$f(n) = \begin{cases} O(n^d), & a < b^d \\ O(n^d\log n), & a = b^d \\ O(n^{\log_ba}), & a > b^d \end{cases}$$
비교하는 대상은 부분 문제 수 $a$와 $b^d$예요. 쪼갠 뒤 합치는 일($n^d$)이 무거운지, 부분 문제가 불어나는 속도가 빠른지를 겨루는 셈이에요.

**예제 1, 병합 정렬** [A p20]: $n$개 원소 정렬에 쓰는 비교 횟수는 $M(n) = 2M(n/2) + n$보다 적어요.
1. $a = 2$, $b = 2$, $d = 1$이에요.
2. $b^d = 2 = a$라 가운데 경우예요.
3. $M(n)$은 $O(n\log n)$이에요.

**예제 2, 빠른 곱셈** [A p20]: $n$이 짝수일 때 $f(n) = 3f(n/2) + Cn$이에요.
1. $a = 3$, $b = 2$, $c = C$예요. 원본은 $d = 0$이라 적었지만 $Cn = Cn^1$이니 $d = 1$이 맞아 보여요. 어느 쪽이든 $a = 3$이 $b^d$($1$ 또는 $2$)보다 커요.
2. 세 번째 경우라 $f(n)$은 $O(n^{\log 3})$이에요.
3. $\log 3 \approx 1.6$이라, $O(n^2)$ 비트 연산을 쓰는 기존 곱셈보다 크게 나아요.

계산 시간까지 셀 수 있게 된 하나는, 다음 날 섬 축제 손님 명단을 받아요. 그런데 여러 명단에 같은 토끼가 겹쳐 있어요. 전체 손님 수는 어떻게 셀까요?

## 5. 포함·배제 원리 (8.5절)

### 왜 필요한가
명단을 단순히 더하면 두 명단에 모두 있는 손님을 두 번 세요. 두 집합에서는 이미 배운 식이 있어요 [A p22].
$$|A \cup B| = |A| + |B| - |A \cap B|$$
이걸 유한집합 여러 개로 넓혀야 해요.

### 직관과 세 집합 [A p22]
도미노 대신 이번엔 하나가 손님에게 명단마다 **도장**을 찍는다고 생각해요. 목표는 모든 손님이 도장을 정확히 1개 갖게 하는 거예요.
$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$
원본 벤 다이어그램 세 장이 이 과정을 보여 줘요.
- (a) $|A| + |B| + |C|$만 더하면 한 집합에만 있는 영역은 1, 두 집합이 겹친 영역은 2, 셋 다 겹친 가운데는 3번 세어져요.
- (b) 두 집합 교집합 세 개를 빼면 두 집합 영역은 1이 되지만 가운데는 $3 - 3 = 0$이 돼요.
- (c) 세 집합 교집합을 더하면 가운데도 1이 되어 모든 영역이 정확히 1번이 돼요.

### 일반 정리 [A p23]
유한집합 $A_1, \dots, A_n$에 대해
$$|A_1 \cup \dots \cup A_n| = \sum_{1 \le i \le n}|A_i| - \sum_{1 \le i < j \le n}|A_i \cap A_j| + \dots + (-1)^{n-1}|A_1 \cap \dots \cap A_n|$$
홀수 개 교집합은 더하고 짝수 개 교집합은 빼요.

**증명 아이디어**: 합집합의 원소가 우변에서 정확히 1번 세어짐을 보여요. 원소 $a$가 $A_1, \dots, A_n$ 중 $r$개에 속한다고 해요 ($1 \le r \le n$).
1. $\sum|A_i|$에서는 자기가 속한 $r$개 집합에서 한 번씩, $\binom r1$번 세어져요.
2. $\sum|A_i \cap A_j|$에서는 속한 집합 중 2개를 고르는 방법 수만큼, $\binom r2$번이에요.
3. 일반적으로 $k$개 교집합의 합에서는 $\binom rk$번이에요.
4. 부호를 붙여 더하면 $\binom r1 - \binom r2 + \dots + (-1)^{r-1}\binom rr = 1$번이에요.

> 보충: $k > r$이면 $k$개 교집합의 합에서는 0번 세어져요. 마지막 등식은 $(1-1)^r = 0 = 1 - \binom r1 + \binom r2 - \dots$을 정리한 거예요.

### 전사 함수의 수 (8.6절) [A p24]
하나가 일 6개를 도우미 3명 $b_1, b_2, b_3$에게 나눠 주는데, 놀고 있는 도우미가 없어야 해요. 6원소 집합에서 3원소 집합으로 가는 **전사 함수(onto function)**의 수를 묻는 문제예요.
1. 성질 $P_i$를 "$b_i$가 함수의 치역에 없음"으로 정해요. 함수가 전사일 조건은 $P_1, P_2, P_3$ 중 어느 것도 성립하지 않는 거예요.
2. 포함·배제로 전사 함수 수는
$$N - [N(P_1) + N(P_2) + N(P_3)] + [N(P_1P_2) + N(P_1P_3) + N(P_2P_3)] - N(P_1P_2P_3)$$
여기서 $N$은 전체 함수 수, $N(P_iP_j)$는 두 성질을 모두 갖는 함수 수예요.

> 보충: 값을 넣으면 $N = 3^6$, $N(P_i) = 2^6$, $N(P_iP_j) = 1^6$, $N(P_1P_2P_3) = 0$이라 $729 - 3\cdot64 + 3\cdot1 - 0 = 540$이에요.

일반화한 정리예요. 양의 정수 $m \ge n$일 때 $m$원소 집합에서 $n$원소 집합으로 가는 전사 함수의 수는
$$n^m - \binom n1(n-1)^m + \binom n2(n-2)^m - \dots + (-1)^{n-1}\binom n{n-1}\cdot1^m$$
$\binom nk$는 빠질 도우미 $k$명을 고르는 수, $(n-k)^m$은 남은 도우미에게 일을 주는 수예요.

이번엔 "아무도 빠지지 않게"가 아니라 "아무도 제자리에 있지 않게"를 세어야 한다면 어떨까요?

## 6. 교란과 모자 보관 문제 (8.6절)

### 정의 [A p25]
**교란(derangement)**은 어떤 원소도 원래 자리에 두지 않는 순열이에요. 21453은 12345의 교란이에요. 어느 숫자도 제자리에 없으니까요. 21543은 4가 원래 자리에 있어서 교란이 아니에요.

### 공식 [A p25]
$n$원소 집합의 교란 수는
$$D_n = n!\left[1 - \frac{1}{1!} + \frac{1}{2!} - \dots + (-1)^n\frac{1}{n!}\right]$$

> 보충: 도장 비유 그대로 포함·배제를 써요. $P_i$를 "$i$가 제자리"로 두면, 특정 $k$개가 제자리인 순열은 나머지를 아무렇게나 놓는 $(n-k)!$개예요. 그런 $k$개를 고르는 방법이 $\binom nk$이고 $\binom nk(n-k)! = \frac{n!}{k!}$이라, 부호를 번갈아 더하면 위 식이 나와요. 확인: $D_3 = 6\left(1 - 1 + \frac12 - \frac16\right) = 2$ (231, 312).

### 모자 보관 문제 [A p26]
섬 식당의 새 직원이 손님 $n$명의 모자를 받으면서 보관 번호표를 깜빡했어요. 손님이 돌아오자 남은 모자 중 아무거나 골라 돌려줘요. 아무도 자기 모자를 받지 못할 확률은 얼마일까요?
1. 모자를 돌려주는 방법은 $n$개 모자의 순열이라 모두 $n!$가지예요.
2. 아무도 자기 모자를 못 받는 경우는 모자가 하나도 원래 자리에 가지 않는 배열, 곧 교란이라 $D_n$가지예요.
3. 확률은 $D_n/n!$이에요.

$n$이 한없이 커지면 이 확률은 $1/e$에 가까워져요.
$$\frac{1}{n!}D_n = 1 - \frac{1}{1!} + \frac{1}{2!} - \dots + (-1)^n\frac{1}{n!} \to e^{-1}$$

> 보충: $e^{-1} \approx 0.368$이라, 손님이 많아도 약 37% 확률로 아무도 자기 모자를 못 받아요.
