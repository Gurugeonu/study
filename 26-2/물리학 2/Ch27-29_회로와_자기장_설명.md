## Ch27 회로

### 1. 기전력: 큐를 들어 올리는 펌프

**왜 필요할까요?** 도선 안의 큐는 높은 전위에서 낮은 전위로 굴러 내려가요. 그런데 다 내려가면 멈춰 버려요. 전류가 계속 흐르게 하려면 큐를 다시 위로 올려 주는 장치가 있어야 해요.

**직관.** 이 단원 내내 쓸 비유는 **워터파크**예요. 전위는 "높이", 큐는 미끄럼틀을 타는 아이, 저항은 "미끄럼틀", 전지는 아이를 꼭대기로 올려 주는 "펌프(엘리베이터)"예요.

**정의.** 전하 운반자에 일을 해서 두 단자 사이의 전위차를 유지하는 장치를 **기전력 장치(emf device)**, 곧 "전하 펌프"라고 해요. 전지, 발전기, 태양전지가 그 예시예요 [A p37]. 장치 안에는 에너지원이 있어요. 전지는 화학 에너지, 발전기는 역학적 힘, 태양전지는 햇빛을 써요. 높은 쪽 단자를 + 단자, 낮은 쪽을 − 단자라고 해요 [A p38]. emf라는 이름은 옛 용어 electromotive force에서 왔지만, 실제로는 힘이 아니라 일에 관한 양이에요 [A p37].

양전하 $dq$를 − 단자에서 + 단자로 옮기는 데 장치가 한 일을 $dW$라 하면

$$\mathscr{E} = \frac{dW}{dq}\quad\text{(단위 전하당 일)} \qquad [A\ p39]$$

- **이상 기전력 장치**: 내부 저항이 없어요. 단자 전압이 언제나 $\mathscr{E}$예요.
- **실제 기전력 장치**: 내부 저항이 있어요. 전류가 0일 때만 단자 전압이 $\mathscr{E}$예요 [A p39].

그런데 펌프가 큐를 올려 주면, 큐는 한 바퀴 돌면서 얼마나 빨리 흐를까요?

### 2. 단일 고리 회로: 전류를 구하는 두 가지 길

이상 전지에 저항 $R$ 하나를 연결한 회로(그림 27.1.3)를 생각해요. 전류 $i$는 회로 어디서나 같아요.

**에너지 방법** [A p40–41]
1. 저항에서는 $dt$ 동안 $i^2R\,dt$만큼의 에너지가 열로 바뀌어요. 이것을 **소모(dissipation)**라고 해요. 도선 저항은 무시하니 도선에서는 열이 생기지 않아요.
2. 같은 시간에 전지를 통과한 전하는 $dq = i\,dt$이고, 전지가 한 일은 $dW = \mathscr{E}dq = \mathscr{E}i\,dt$예요.
3. 에너지 보존: 펌프가 준 에너지가 미끄럼틀에서 열로 다 나가야 해요. $\mathscr{E}i\,dt = i^2R\,dt$
4. 양변을 $i\,dt$로 나누면 $i = \mathscr{E}/R$예요.

**전위 방법** [A p42–43]
1. 전지의 낮은 쪽 점 $a$(전위 $V_a$)에서 출발해 시계 방향으로 걸어요.
2. 전지를 지나 높은 단자로 올라가면 $+\mathscr{E}$, 저항을 전류 방향으로 내려가면 $-iR$이에요.
3. 한 바퀴 돌아 $a$로 오면 다시 같은 높이여야 해요. $V_a + \mathscr{E} - iR = V_a$
4. $V_a$가 지워져 $\mathscr{E} - iR = 0$, 곧 $i = \mathscr{E}/R$예요. 반대 방향으로 돌아도 $V_a + iR - \mathscr{E} = V_a$로 같은 답이 나와요.

워터파크에서 한 바퀴 돌아 제자리로 오면 높이 변화의 합이 0인 것과 같아요. 여기서 세 규칙이 나와요 [A p44].

- **고리 규칙(loop rule)**: 닫힌 고리를 한 바퀴 돌 때 전위 변화의 대수합은 0이에요.
- **저항 규칙**: 저항을 전류 방향으로 지나면 $-iR$, 반대로 지나면 $+iR$예요.
- **기전력 규칙**: 이상 기전력 장치를 기전력 화살표 방향(−에서 +)으로 지나면 $+\mathscr{E}$, 반대면 $-\mathscr{E}$예요.

부호는 내가 **걸어가는 방향**으로 정해요. 전류 방향과 같은 쪽으로 저항을 지날 때만 $-iR$이에요.

그런데 진짜 전지는 펌프 안에도 작은 미끄럼틀이 숨어 있어요. 그러면 어떻게 될까요?

### 3. 실제 전지: 내부 저항과 단자 전압

**왜 필요할까요?** 실제 전지는 재료 자체에 전기 저항이 있어요. 이것을 **내부 저항** $r$이라 하고, 없앨 수 없는 성질이에요 [A p45]. 그래서 실제 전지는 이상 전지 하나에 저항 $r$을 직렬로 붙인 것으로 바꿔 그려요.

점 $a$에서 시계 방향으로 고리 규칙을 쓰면

$$\mathscr{E} - ir - iR = 0 \;\Rightarrow\; i = \frac{\mathscr{E}}{R+r}\qquad [A\ p45]$$

그림 27.1.4(b)의 전위 그래프로 보면, $V_a$에서 전지를 지나며 $\mathscr{E}$만큼 올라가고, $r$에서 $ir$만큼, 외부 $R$에서 $iR$만큼 내려와 다시 $V_a$가 돼요.

**두 점 사이 전위차 구하기** [A p46]: 한 점에서 출발해 **아무 경로나** 따라 다른 점까지 가며 만나는 전위 변화를 대수적으로 더해요. 경로가 달라도 답은 같아요.

**예제(그림 27.1.6)** [A p47]: $\mathscr{E} = 12\ \mathrm{V}$, $r = 2.0\ \Omega$, $R = 4.0\ \Omega$일 때 전지 두 단자 사이 전위차 $V_b - V_a$는?
1. $a$에서 전지 안을 지나 $b$로 가요: $+\mathscr{E}$, 그리고 $r$을 전류 방향으로 지나 $-ir$. 그래서 $V_b - V_a = \mathscr{E} - ir$
2. 전류가 필요해요: $i = \mathscr{E}/(R+r)$
3. 대입: $V_b - V_a = \mathscr{E} - \dfrac{\mathscr{E}}{R+r}r = \dfrac{\mathscr{E}}{R+r}R = \dfrac{12}{6.0}\times4.0 = 8.0\ \mathrm{V}$

내부 저항 때문에 단자 전압이 12 V보다 작아졌어요. 바깥 $R$ 쪽 경로로 가도 $+iR$ 하나만 만나서 똑같이 8.0 V가 나와요.

> 보충: 다른 전원이 전류를 기전력 반대 방향으로 밀어 넣으면(전지를 충전할 때) $r$을 지나는 방향이 바뀌어 단자 전압은 $\mathscr{E} + ir$이 돼요 [A p35 LO12].

이번엔 미끄럼틀을 여러 개 줄줄이 이어 놓으면 어떻게 될까요?

### 4. 직렬 저항

저항 세 개를 한 줄로 이어 이상 전지에 연결해요(그림 27.1.5). 길이 하나뿐이니 모든 저항에 **같은 전류** $i$가 흘러요 [A p48].

**도출** [A p49]
1. 실제 회로에서 $a$부터 시계 방향: $\mathscr{E} - iR_1 - iR_2 - iR_3 = 0$, 곧 $i = \dfrac{\mathscr{E}}{R_1+R_2+R_3}$
2. 하나의 등가 저항으로 바꾼 회로: $\mathscr{E} - iR_{eq} = 0$, 곧 $i = \mathscr{E}/R_{eq}$
3. 두 회로의 $i$가 같아야 하니 비교하면

$$R_{eq} = \sum_{j=1}^{n} R_j \quad (\text{직렬}),\qquad \mathscr{E} = i\sum R_n = iR_{eq}\qquad [A\ p49,\ B\ p2]$$

각 저항의 전위차를 모두 더하면 걸린 전위차 $V$가 돼요. 등가 저항은 같은 전류, 같은 총 전위차를 갖는 하나의 저항이에요 [A p50].

**체크포인트 2** [A p51]: $R_1 > R_2 > R_3$일 때 (a) 전류는 세 저항 모두 같아요(전하 보존). (b) 전위차는 $V = iR$이니 저항이 클수록 커요. $V_1 > V_2 > V_3$.

펌프가 이렇게 일할 때 에너지는 어디로 얼마나 빨리 갈까요?

### 5. 전력과 접지

- $P = iV$: 전하 운반자로 에너지가 넘어가는 비율이에요 [B p31].
- $P_r = i^2r$: 전지 **안에서** 열로 새는 비율이에요 [B p32].
- $P_{emf} = i\mathscr{E}$: 기전력 장치가 운반자와 내부 열 양쪽으로 넘기는 총 비율, 곧 전지의 화학 에너지가 바뀌는 비율이에요 [A p52].

실제 전지에서 전류가 기전력 방향으로 흐르면 $V = \mathscr{E} - ir$이니 양변에 $i$를 곱해 $iV = i\mathscr{E} - i^2r$예요. 펌프가 낸 에너지 중 일부가 내부에서 새고 나머지가 바깥으로 간다는 뜻이에요.

> 보충: 전류가 반대 방향이면 $iV = i\mathscr{E} + i^2r$이 되어, 바깥에서 들어온 에너지가 화학 에너지 저장과 내부 열로 나뉘어요 [A p36 LO16].

**접지(grounding)**는 회로의 한 점을 지면(실제로는 축축한 흙과 암석)으로 이어지는 도체에 연결하는 거예요 [A p52]. 워터파크로 치면 "이 지점의 높이를 0으로 정하자"는 약속일 뿐이라서, 각 점의 전위값은 달라져도 **전류는 바뀌지 않아요** [A p36 LO14].

그런데 길이 갈라지는 갈림길이 생기면 어떻게 될까요?

### 6. 다중 고리 회로와 접합점 규칙

길이 갈라지는 점을 **접합점(junction)**이라고 해요. 큐들은 사라지거나 새로 생기지 않으니(전하 보존)

- **접합점 규칙**: 접합점으로 들어오는 전류의 합 = 나가는 전류의 합 [B p7]

**예(그림 27.2.1)** [B p7–8]: 위쪽에 $\mathscr{E}_1$, $\mathscr{E}_2$, 세로 가지에 $R_1$($i_1$ 아래로), $R_3$($i_3$ 아래로), $R_2$($i_2$ 위로)가 있어요.
1. 접합점 $d$: $i_1 + i_3 = i_2$
2. 왼쪽 고리, $b$에서 반시계: $\mathscr{E}_1 - i_1R_1 + i_3R_3 = 0$ ($R_3$을 전류 반대로 올라가니 $+$)
3. 오른쪽 고리, $b$에서 반시계: $-i_3R_3 - i_2R_2 - \mathscr{E}_2 = 0$
4. 큰 고리: $\mathscr{E}_1 - i_1R_1 - i_2R_2 - \mathscr{E}_2 = 0$. 이 식은 2와 3을 더한 것이라 **새 정보가 없어요**. 미지수 세 개는 1, 2, 3으로 풀어요.

**단순화할 수 없는 회로의 풀이 순서** [B p6]: 고리들을 찾고 → 가지마다 전류 이름과 방향을 정하고(틀려도 답이 음수로 나올 뿐이에요) → 접합점 식과 독립인 고리 식을 세워 → 연립해서 풀어요.

갈림길에 미끄럼틀이 나란히 놓이면 어떻게 될까요?

### 7. 병렬 저항

저항 세 개가 같은 두 점 $a$, $b$ 사이에 나란히 연결되면(그림 27.2.2) 모두 **같은 전위차** $V$를 받고, 전류는 가지로 나뉘어요 [B p9]. 같은 높이의 출발대에서 같은 바닥까지 내려가는 미끄럼틀 세 개예요.

**도출** [B p10–11, R p42]
1. 각 가지: $i_1 = V/R_1$, $i_2 = V/R_2$, $i_3 = V/R_3$
2. 점 $a$에 접합점 규칙: $i = i_1 + i_2 + i_3 = V\left(\dfrac{1}{R_1}+\dfrac{1}{R_2}+\dfrac{1}{R_3}\right)$
3. 등가 회로에서는 $i = V/R_{eq}$이니 비교하면

$$\frac{1}{R_{eq}} = \sum_{j=1}^{n}\frac{1}{R_j}\quad(\text{병렬})\qquad [B\ p11]$$

> 보충: 미끄럼틀이 늘어나면 길이 넓어지는 셈이라, 병렬 등가 저항은 가장 작은 저항보다도 작아져요.

| | 직렬 | 병렬 |
|---|---|---|
| 저항 | $R_{eq} = \sum R_j$, 같은 전류 | $1/R_{eq} = \sum 1/R_j$, 같은 전위차 |
| 축전기 | $1/C_{eq} = \sum 1/C_j$, 같은 전하 | $C_{eq} = \sum C_j$, 같은 전위차 |

축전기는 저항과 공식 모양이 **뒤바뀌어** 있어요 [B p12–13].

**체크포인트 4** [B p14]: 전위차 $V$인 전지가 같은 저항 두 개에 연결되어 전류 $i$가 흘러요. (a) 직렬이면 전류가 같고 전위차가 반씩 나뉘어 각 저항은 $V/2$, $i$예요. (b) 병렬이면 전위차가 같고 전류가 반씩 나뉘어 각 저항은 $V$, $i/2$예요.

**직·병렬 혼합 회로** [B p5]: 등가 저항으로 단계적으로 줄여 전지 전류를 구한 다음, 거꾸로 되돌아가며 각 저항의 전류와 전위차를 구해요.

> 보충: 같은 실제 전지($\mathscr{E}$, $r$) $N$개를 직렬로 이으면 이상 전지 $N\mathscr{E}$와 저항 $Nr$, 병렬로 이으면 이상 전지 $\mathscr{E}$와 저항 $r/N$으로 바꿀 수 있어요. 직렬은 위 직렬 규칙을, 병렬은 위 병렬 규칙을 그대로 쓴 결과예요 [B p6 LO8–9].

이제 회로 안에서 큐가 얼마나 흐르는지, 높이 차가 얼마인지 실제로 재 보려면 어떻게 해야 할까요?

### 8. 전류계와 전압계

**전류계(ammeter)** [B p17–18]: 전류를 재려면 도선을 끊고 계기를 **직렬**로 끼워 전류가 계기를 지나가게 해요. 그러려면 계기 저항 $R_A$가 회로의 다른 저항보다 **훨씬 작아야** 해요. 아니면 계기 자체가 미끄럼틀 하나를 더한 셈이 되어 재려던 전류가 바뀌어요.

**전압계(voltmeter)** [B p19–20]: 두 점 사이 전위차를 재려면 도선을 끊지 않고 두 점에 **병렬**로 대요. 이때 계기 저항 $R_V$는 측정 소자의 저항보다 **훨씬 커야** 해요. 그래야 전압계로 새는 전류가 무시할 만큼 작아서 재려던 전위차가 바뀌지 않아요. 그림 27.3.1에서 전류계는 $a$–$b$ 사이에 끼워져 있고, 전압계는 $R_1$ 양 끝 $c$–$d$에 걸려 있어요.

이번엔 미끄럼틀 끝에 큐를 모아 두는 물탱크(축전기)를 달면 어떻게 될까요?

### 9. RC 회로: 충전

**왜 필요할까요?** 지금까지 전류는 시간이 지나도 일정했어요. 축전기가 끼면 큐가 쌓일수록 탱크 수위(축전기 전압)가 올라가 펌프를 거꾸로 밀어내기 때문에, 전류가 시간에 따라 바뀌어요.

**고리 방정식** [B p24]: 처음엔 축전기가 비어 있고, 스위치 S를 $a$에 붙이면 전지·$R$·$C$의 직렬 회로가 돼요. 전지의 − 단자에서 시계 방향으로 돌면 축전기에서 $q/C$만큼 내려가요.

$$\mathscr{E} - iR - \frac{q}{C} = 0,\quad i = \frac{dq}{dt}\;\Rightarrow\; R\frac{dq}{dt} + \frac{q}{C} = \mathscr{E}\quad(\text{충전 방정식})$$

이 식과 초기 조건 "$t=0$에서 $q=0$"을 함께 만족하는 $q(t)$를 찾아야 해요 [B p25].

**풀이** [B p29]
1. $R$로 나눠 $\dfrac{dq}{dt} + \dfrac{q}{RC} = \dfrac{\mathscr{E}}{R}$로 써요.
2. 이런 꼴의 일반해는 $q = q_p + Ke^{-at}$예요. $a = 1/RC$는 $q$의 계수, $q_p$는 특수해, $K$는 초기 조건으로 정할 상수예요.
3. 특수해: 오랜 시간 뒤 변화가 멈춘 상태를 생각해 $dq/dt = 0$으로 놓으면 $q_p = C\mathscr{E}$예요.
4. 초기 조건 $t=0$, $q=0$ 대입: $0 = C\mathscr{E} + K$, 곧 $K = -C\mathscr{E}$
5. 그래서

$$q = C\mathscr{E}\left(1 - e^{-t/RC}\right)\qquad [B\ p25]$$

$q_0 = C\mathscr{E}$는 평형(최종) 전하, $\tau = RC$는 **용량 시간 상수(capacitive time constant)**예요.

**전류와 전압** [B p26]
- 미분하면 $i = \dfrac{dq}{dt} = \left(\dfrac{\mathscr{E}}{R}\right)e^{-t/RC}$. 처음엔 축전기가 빈 탱크라 저항 하나만 있는 것처럼 $\mathscr{E}/R$가 흐르고, 가득 차면 0이 돼요.
- $V_C = \dfrac{q}{C} = \mathscr{E}\left(1 - e^{-t/RC}\right)$. $t=0$에서 0, $t\to\infty$에서 $\mathscr{E}$예요.
- 저항 전압은 $V_R = iR = \mathscr{E}e^{-t/RC}$이고, 언제나 $V_R + V_C = \mathscr{E}$예요.

그림 27.4.2(a)에서 $q$는 $C\mathscr{E}$를 향해 점점 완만하게 올라가고, (b)에서 $i$는 $\mathscr{E}/R$에서 0을 향해 떨어져요.

그런데 가득 찬 탱크에서 펌프를 떼어 내면 어떻게 될까요?

### 10. RC 회로: 방전

축전기가 $V_0 = \mathscr{E}$까지 완전히 충전된 상태에서 새로 $t=0$을 잡고 스위치를 $a$에서 $b$로 넘겨요 [B p27]. 이제 고리에 전지가 없으니 충전 방정식에서 $\mathscr{E} = 0$을 넣으면 돼요.

$$R\frac{dq}{dt} + \frac{q}{C} = 0\quad(\text{방전 방정식})$$

같은 방법으로 풀면 특수해가 0이고 $K = q_0$이라서

$$q = q_0e^{-t/RC},\quad q_0 = CV_0;\qquad i = \frac{dq}{dt} = -\left(\frac{q_0}{RC}\right)e^{-t/RC}\qquad [B\ p28]$$

전하와 전류가 모두 $\tau = RC$로 정해지는 속도로 지수 감소해요. 초기 전류의 크기는 $i_0 = q_0/\tau$예요. 음의 부호는 탱크에서 물이 **거꾸로** 빠져나가듯 충전 때와 반대 방향으로 흐른다는 뜻이에요. 축전기 전압은 $V_C = q/C = V_0e^{-t/RC}$예요.

시작과 끝을 정리하면, 충전은 $q: 0 \to C\mathscr{E}$, $V_C: 0 \to \mathscr{E}$이고, 방전은 $q: q_0 \to 0$, $V_C: V_0 \to 0$이에요.

여기까지 큐는 도선 길만 따라 움직였어요. 그런데 도선 밖, 눈에 보이지 않는 자기장 속으로 날아가면 무슨 일이 생길까요?

## Ch28 자기장

### 1. 자기장 $\vec B$의 정의와 자기력

**왜 필요할까요?** 자석 근처를 지나는 전하는 휘어요. 가만히 있는 전하는 아무 힘도 받지 않는데 움직이는 전하만 힘을 받아요. 그래서 자기장은 "움직이는 전하가 받는 힘"으로 정의해요.

**직관.** Ch28에서 쓸 비유는 **옆바람**이에요. 큐가 달리면 바람이 언제나 큐의 진행 방향에 수직으로 불어서 옆으로만 밀어요.

**정의** [B p40–41]: 속도 $\vec v$로 움직이는 전하에 힘 $\vec F_B$를 줄 때 그곳에 **자기장(magnetic field)** $\vec B$가 있다고 해요. 자기장은 크기와 방향을 가진 벡터예요. $\vec v$가 힘에 수직이 되게 쏘았을 때 힘의 크기로 $B = F_B/(\lvert q\rvert v)$라고 정해요. 이 모든 것을 한 식으로 쓰면

$$\vec F_B = q\,\vec v\times\vec B,\qquad F_B = \lvert q\rvert vB\sin\phi$$

$\phi$는 $\vec v$와 $\vec B$ 사이의 각이고, 모든 양은 같은 기준틀에서 재요.

**방향: 오른손 규칙** [B p42–43]: 오른손 손가락을 $\vec v$ 쪽에서 $\vec B$ 쪽으로 휘면 엄지가 $\vec v\times\vec B$ 방향이에요. $q > 0$이면 힘은 엄지 방향, $q < 0$이면 엄지 **반대** 방향이에요. 외적이라서 $\vec F_B$는 언제나 $\vec v$와 $\vec B$ **둘 다에 수직**이에요.

**속력은 바뀌지 않아요.** 힘이 언제나 운동 방향에 수직이니 자기력은 일을 하지 않아요. 그래서 자기력은 방향만 바꾸고 속력과 운동 에너지는 그대로예요 [B p38 LO8].

**체크포인트 1** [B p44]
- (a) 양전하, $\vec v = -\hat x$ 방향, $\vec B = -\hat y$ 방향: $(-\hat x)\times(-\hat y) = \hat x\times\hat y = +\hat z$. 양전하이니 힘은 **+z**.
- (b) 음전하, $\vec v = -\hat y$, $\vec B = -\hat z$: $(-\hat y)\times(-\hat z) = \hat y\times\hat z = +\hat x$. 음전하이니 반대인 **−x**.
- (c) $\vec v$와 $\vec B$가 반대 방향으로 나란해서 $\sin 180^\circ = 0$, 힘이 **없어요**.

> 보충: 단위벡터 표기 계산은 $\vec v = (v_x, v_y, v_z)$, $\vec B = (B_x, B_y, B_z)$를 행렬식으로 외적한 뒤 $q$를 곱하면 돼요 [B p38 LO6].

그런데 이 바람은 어떻게 생겼는지 그림으로 볼 수 없을까요?

### 2. 자기장선과 자극

전기장선처럼 **자기장선**을 그려요 [B p45]. 한 점에서 장선의 접선이 그 점의 $\vec B$ 방향이고, 장선이 촘촘한 곳일수록 $B$가 세요.

자기장선은 시작도 끝도 없는 **닫힌 곡선**이에요. 자석 바깥에서는 한쪽 끝으로 나와 다른 쪽 끝으로 들어가요. 나오는 끝이 **N극**, 들어가는 끝이 **S극**이에요(그림 28.1.5, 말굽 자석 바깥에서 N→S). 극이 둘이라 자석은 **자기 쌍극자(magnetic dipole)**예요. 다른 극끼리는 끌어당기고 같은 극끼리는 밀어내요 [B p46].

> 보충: 자기장을 만드는 자석에는 두 종류가 있어요. **전자석**은 코일에 흐르는 전류로 자기장을 만들어 세기를 조절할 수 있고, **영구자석**은 물질 자체가 자기장을 만들어요 [B p36 LO1].

이번엔 옆바람(자기장)과 앞바람(전기장)을 동시에 불게 하면 어떻게 될까요?

### 3. 교차장: 전자의 발견

**Thomson 실험** [B p49, C p3]: 필라멘트에서 나온 전자를 전위차 $V$로 가속해 편향판 사이로 보내요. 판에 전지를 연결해 위아래 전기장 $\vec E$를 만들고, 코일 전류로 지면 안쪽(× 표시) 자기장 $\vec B$를 만들어요. 두 장이 서로 수직이라 **교차장(crossed fields)**이라고 해요. 전자가 스크린에 닿는 빛점의 위치로 편향을 재고, 전자의 질량과 전하의 비를 구해요.

**두 힘이 상쇄될 때** [C p3]: 전기력과 자기력이 반대 방향이 되도록 맞추고 크기가 같으면 큐는 휘지 않고 똑바로 지나가요.

$$\lvert q\rvert E = \lvert q\rvert vB\sin 90^\circ = \lvert q\rvert vB \;\Rightarrow\; v = \frac{E}{B}$$

그래서 교차장으로 입자의 **속력을 잴** 수 있어요.

> 보충: 자기력은 $v$에 비례하고 전기력은 $v$와 무관해요. 그래서 $v > E/B$이면 자기력이 이겨 자기력 쪽으로, $v < E/B$이면 전기력이 이겨 전기력 쪽으로 휘어요 [B p48 LO].

**예제: 표본문제 22.6.1을 교차장에 적용** [C p4]: 질량 $m$, 음전하 크기 $Q$인 잉크 방울이 길이 $L$인 판 사이에 $x$축 방향 속력 $v_x$로 들어와요. 판 끝에서 수직 편향 $y$는?
1. 전기력만 있을 때 가속도: $a_y = F/m = QE/m$
2. 수평은 등속: $L = v_xt$, 수직은 등가속: $y = \frac12 a_yt^2$
3. $t = L/v_x$를 넣으면 $y = \dfrac{QEL^2}{2mv_x^2}$
4. 먼저 $\vec B$를 켜고 편향을 0으로 맞춰 $v_x = E/B$를 알아내요. 이것을 대입하면 $y = \left(\dfrac{Q}{m}\right)\dfrac{B^2L^2}{2E}$
5. $y$, $B$, $L$, $E$를 모두 재면 $Q/m$이 나와요. Thomson이 전자의 전하 대 질량 비를 구한 방법이에요.

진공 속 전자는 이렇게 휘었어요. 그렇다면 구리 도선 속을 표류하는 전자도 자기장에 휘어질까요?

### 4. 홀 효과

**왜 필요할까요?** 도선 속 전류가 양전하의 흐름인지 음전하의 흐름인지는 전류만 봐서는 알 수 없어요. **홀 효과(Hall effect)**를 쓰면 운반자의 부호와 단위 부피당 개수 $n$을 잴 수 있어요 [C p8].

**과정** [C p9–10]
1. 폭 $d$인 구리 띠에 전류 $i$가 위에서 아래로 흘러요. 운반자인 전자는 반대로 아래에서 위로 표류 속력 $v_d$로 움직여요. 띠에 수직(지면 안쪽)으로 $\vec B$를 걸어요.
2. 전자에 $\vec F_B = q\vec v_d\times\vec B$가 작용해 전자가 오른쪽으로 밀려요(옆바람!).
3. 전자가 오른쪽 가장자리에 쌓이고 왼쪽에는 보상받지 못한 양전하가 남아요. 그래서 띠를 가로지르는 전기장 $\vec E$가 생겨요.
4. 전하가 쌓일수록 $\vec E$가 커지다가, 전기력 $\vec F_E$가 자기력 $\vec F_B$와 균형을 이루면 더 쌓이지 않아요. 이 균형이 $E$의 크기를 제한해요.

**공식 유도** [C p10, p13]
1. 균형: $eE = ev_dB$
2. 전류 밀도 $J = nev_d$에서 $v_d = J/(ne)$를 넣으면 $E = \left(\dfrac{B}{ne}\right)J$, 곧 $n = \dfrac{JB}{eE}$
3. $i = JA$, $V = Ed$를 넣으면

$$n = \frac{JB}{eE} = \frac{Bid}{eVA} = \frac{Bi}{eVl},\qquad l = A/d\ (\text{띠의 두께})$$

모두 잴 수 있는 양이라 $n$을 구할 수 있어요.

$E = (B/ne)J$에는 충돌 사이 평균 시간 $\tau$가 없어요. 비저항 $\rho = m/(e^2n\tau)$가 $\tau$에 의존하는 것과 대조돼요 [C p10].

**부호 판별** [C p11]: 운반자가 양전하라고 가정해 보면, 위에서 아래로 움직이는 양전하도 오른쪽으로 밀려 오른쪽이 **높은 전위**가 돼요. 실제 구리에서는 음전하가 오른쪽에 쌓여 왼쪽이 높은 전위예요. 그래서 어느 쪽이 높은 전위인지 재면 운반자의 부호를 알 수 있어요 [C p55].

**움직이는 도체** [C p12]: 도체 자체가 균일한 $\vec B$ 속을 속력 $v$로 움직여도 같은 일이 일어나요. 표류 속력 대신 도체 속력을 쓰면 $eE = evB$이고

$$V = Ed = vBd$$

여기서 $d$는 $\vec v$와 $\vec B$ **둘 다에 수직인** 폭이에요.

홀 효과에서는 도선 벽이 큐를 붙잡아 줬어요. 벽이 없는 빈 공간이라면 옆바람을 받는 큐는 어디로 갈까요?

### 5. 자기장 속 원운동

**원이 되는 이유** [C p17]: 전자총 G에서 쏜 전자가 지면 밖을 향한 균일한 $\vec B$ 속에 들어가요. 옆바람이 언제나 진행 방향에 수직으로 부니 큐는 계속 같은 비율로 방향만 꺾여 **원**을 그려요. 사진에서 궤도가 보이는 것은 전자가 기체 원자와 부딪쳐 원자가 빛을 내기 때문이에요.

**반지름 유도** [C p18]
1. 힘의 크기는 $\lvert q\rvert vB$예요($\phi = 90^\circ$).
2. 이 힘이 구심력 역할을 하니 뉴턴 제2법칙으로 $\lvert q\rvert vB = \dfrac{mv^2}{r}$
3. $r$에 대해 풀면

$$r = \frac{mv}{\lvert q\rvert B}$$

구심가속도는 $a = v^2/r = \lvert q\rvert vB/m$예요.

**주기와 진동수** [C p19]: 한 바퀴 시간은 둘레를 속력으로 나눈 값이에요.

$$T = \frac{2\pi r}{v} = \frac{2\pi}{v}\frac{mv}{\lvert q\rvert B} = \frac{2\pi m}{\lvert q\rvert B},\qquad f = \frac1T,\qquad \omega = 2\pi f = \frac{\lvert q\rvert B}{m}$$

$v$가 지워졌어요. $T$, $f$, $\omega$는 **속력과 무관**해요. 빠른 큐는 큰 원, 느린 큐는 작은 원을 돌지만 $\lvert q\rvert/m$이 같으면 한 바퀴 시간은 똑같아요.

그림을 그릴 때는 원의 어느 점에서든 $\vec v$는 접선, $\vec F_B$는 원의 중심을 향해요. 양전하와 음전하는 같은 $\vec B$에서 반대 방향으로 돌아요.

**예제: 질량 분석기(그림 28.4.5)** [C p20–21]: 전원 S에서 나온 전하 $q$인 이온(처음엔 정지)을 전위차 $V$로 가속해, 경로에 수직인 균일 $\vec B$가 있는 분리실로 보내요. 이온은 반원을 그리고 바닥의 검출기에 부딪혀요. 질량 $m$은?
1. 출발할 때 운동 에너지 ≈ 0, 가속 후 $\frac12mv^2$
2. 양이온이 전위 변화 $-V$를 지나니 퍼텐셜 에너지 변화는 $-qV$
3. 에너지 보존: $\frac12mv^2 - qV = 0 \Rightarrow v = \sqrt{2qV/m}$
4. 반지름 공식에 대입: $r = \dfrac{mv}{\lvert q\rvert B} = \dfrac1B\sqrt{\dfrac{2mV}{q}}$
5. $r$을 재면 $m$이 나와요.

> 보충: 검출기에 닿은 위치까지 거리 $x$는 지름 $2r$이므로 $m = \dfrac{B^2qx^2}{8V}$예요.

**나선 경로** [C p22]: $\vec v$가 $\vec B$와 나란한 성분을 가지면, 수직 성분은 원을 만들고 평행 성분은 그 원을 $\vec B$ 방향으로 늘려 **나선(helix)**이 돼요. 평행 성분은 이웃한 고리 사이 거리인 **피치** $p$를, 수직 성분은 나선의 **반지름**을 정해요. 정리하면, $\vec v\parallel\vec B$이면 힘이 0이라 직선, $\vec v\perp\vec B$이면 원, 그 밖이면 나선이에요.

> 보충: $\vec v$와 $\vec B$ 사이 각이 $\phi$이면 $v_\parallel = v\cos\phi$, $v_\perp = v\sin\phi$이고, $r = \dfrac{mv_\perp}{\lvert q\rvert B}$, $p = v_\parallel T$예요 [C p16 LO6–7].

한 바퀴 시간이 속력과 무관하다는 이 성질을 이용해 큐를 아주 빠르게 만들 수는 없을까요?

### 6. 사이클로트론과 싱크로트론

**사이클로트론(cyclotron)** [C p25]: 속이 빈 D자 모양 구리 전극 두 개("디", dee)를 마주 놓고, 진동기가 두 디 사이 간극의 전위차를 번갈아 바꿔 간극 전기장의 방향이 왔다 갔다 해요. 전체는 지면 밖을 향한 큰 자기장 속에 있어요. 양성자는 디 안에서는 자기장 때문에 반원을 돌고, **간극을 지날 때마다** 전기장에 밀려 에너지를 얻어요. 빨라질수록 $r = mv/(\lvert q\rvert B)$가 커져 바깥으로 나선을 그리며 퍼져요.

**공명 조건** [C p26]: 양성자가 간극에 올 때마다 전기장이 알맞은 방향이어야 해요. 다행히 회전 진동수 $f = \lvert q\rvert B/(2\pi m)$는 속력과 무관해서 일정해요. 그래서

$$f = f_{osc}\quad(\text{공명 조건})$$

에너지를 입자의 고유 회전 진동수와 같은 진동수로 넣어 줘야 에너지가 커져요. 그네를 탄 아이를 그네 박자에 맞춰 밀어 주는 것과 같아요.

**양성자 싱크로트론** [C p27]: 사이클로트론에서는 $B$와 $f_{osc}$가 고정이지만, 싱크로트론에서는 가속하는 동안 둘을 시간에 따라 바꿔요. 그러면 (1) 양성자의 회전 진동수가 진동기와 언제나 맞고, (2) 양성자가 나선이 아니라 **원** 경로를 따라요. 그래서 자석을 그 원 경로를 따라서만 두면 돼요. 다만 높은 에너지를 얻으려면 원은 여전히 커야 해요.

지금까지는 큐 하나가 받는 힘을 봤어요. 큐들이 줄지어 흐르는 도선 전체는 어떤 힘을 받을까요?

### 7. 전류가 흐르는 도선에 작용하는 자기력

**관찰(그림 28.6.1)** [C p31]: 자석의 두 극 사이(B는 지면 밖)에 유연한 도선을 두면, (a) 전류가 없을 때는 곧고, (b) 위로 전류가 흐르면 오른쪽으로, (c) 아래로 흐르면 왼쪽으로 휘어요. 도선 속 전자 하나하나가 옆바람을 받기 때문이에요.

**유도** [C p32]
1. 길이 $L$인 도선 구간의 전도 전자는 모두 시간 $t = L/v_d$ 안에 평면 $xx$를 지나가요.
2. 그동안 지나가는 전하는 $q = it = iL/v_d$
3. 자기력: $F_B = qv_dB\sin\phi = \dfrac{iL}{v_d}v_dB\sin90^\circ = iLB$

$v_d$가 지워져 전류만 남아요. $\vec B$가 도선에 수직이 아닐 때까지 일반화하면

$$\vec F_B = i\vec L\times\vec B,\qquad F_B = iLB\sin\phi\qquad [C\ p33]$$

$\vec L$은 크기가 $L$이고 (관례적) 전류 방향을 향하는 길이 벡터예요. 방향은 오른손 규칙으로 손가락을 $\vec L$에서 $\vec B$로 휘어 정해요.

**휜 도선이나 불균일한 자기장** [C p34]: 도선을 아주 짧은 직선 조각들로 나누고, 각 조각의 힘을 구해 **벡터로 더해요**. 극한에서

$$d\vec F_B = i\,d\vec L\times\vec B$$

$d\vec L$도 전류 방향을 향해요.

그럼 도선을 네모로 접어 고리를 만들면, 네 변이 받는 힘은 어떻게 될까요?

### 8. 전류 고리의 돌림힘

**전동기의 원리** [C p37]: 자기장 속 전류 고리의 두 변이 크기가 같고 방향이 반대인 힘 $\vec F$, $-\vec F$를 받아 중심축 둘레로 돌림힘이 생겨요. **정류자(commutator)**가 반 바퀴마다 전류 방향을 뒤집어 돌림힘이 늘 같은 방향으로 작용하게 해요. 이것이 간단한 전동기예요.

**도출(그림 28.7.2)** [C p38–42]: 변 1, 3의 길이는 $a$, 변 2, 4의 길이는 $b$예요. 고리 면의 법선 벡터 $\vec n$과 $\vec B$ 사이 각을 $\theta$라 해요.
1. 변 2: $\vec L$의 크기 $b$, $\vec L$과 $\vec B$ 사이 각이 $90^\circ - \theta$이니 $F_2 = ibB\sin(90^\circ-\theta) = ibB\cos\theta$
2. 변 4: $F_4$는 $F_2$와 크기가 같고 방향이 반대예요. 작용선도 고리 중심을 지나 같으니 알짜 힘도 0, 알짜 돌림힘도 0이에요.
3. 변 1, 3: $\vec L\perp\vec B$이니 둘 다 크기 $iaB$예요. 방향이 반대라 고리를 위아래로 움직이지는 않지만 **작용선이 달라서** 돌림힘을 만들어요.
4. 각 힘의 팔 길이는 중심축에서 $(b/2)\sin\theta$이니

$$\tau' = \left(iaB\frac b2\sin\theta\right) + \left(iaB\frac b2\sin\theta\right) = iabB\sin\theta$$

5. $N$번 감은 코일이면 $\tau = N\tau' = NiabB\sin\theta$이고, $A = ab$이므로

$$\tau = (NiA)B\sin\theta\qquad [C\ p42]$$

결국 네 힘의 합은 0이라 고리는 이동하지 않고 **회전만** 해요. 돌림힘은 법선 $\vec n$을 $\vec B$ 방향으로 맞추려는 쪽으로 작용해요 [C p41, p43]. $\theta$는 고리 **면**이 아니라 **법선**과 $\vec B$ 사이 각이라는 점을 꼭 지켜요.

식 안의 $NiA$가 코일의 성질만 담고 있다면, 이것에 이름을 붙여 자석처럼 다룰 수는 없을까요?

### 9. 자기 쌍극자 모멘트

**정의** [C p51]: 전류 코일에 **자기 쌍극자 모멘트(magnetic dipole moment)** $\vec\mu$를 붙여요.

$$\mu = NiA$$

$N$은 감은 수, $A$는 한 바퀴가 둘러싼 넓이예요. 방향은 오른손 규칙으로 정한 법선 $\vec n$ 방향이에요. 오른손 손가락을 전류 방향으로 감아 쥐면 엄지가 $\vec\mu$ 방향이에요. 전류 코일은 작은 막대자석, 곧 자기 쌍극자처럼 행동해요.

**돌림힘** [C p50]: $\tau = NiAB\sin\theta$를 $\vec\mu$로 쓰면

$$\tau = \mu B\sin\theta,\qquad \vec\tau = \vec\mu\times\vec B$$

$\theta$는 $\vec\mu$와 $\vec B$ 사이 각이에요. $\theta = 90^\circ$일 때 돌림힘이 최대 $\mu B$이고, $\theta = 0^\circ$나 $180^\circ$일 때 0이에요.

> 보충: 돌림힘의 부호는 회전 방향으로 정해요. 쌍극자를 반시계 방향으로 돌리려 하면 +, 시계 방향이면 −예요 [C p46 LO5].

**전기 쌍극자와 나란히 보기** [C p49]: Ch22에서 전기 쌍극자 $\vec p$는 전기장에서 $\vec\tau = \vec p\times\vec E$, $U = -\vec p\cdot\vec E$였어요. 자기 쌍극자도 똑같은 모양이에요. 장이 주는 돌림힘은 "쌍극자 모멘트 × 장"의 외적이에요.

**방향 에너지** [C p52]

$$U(\theta) = -\vec\mu\cdot\vec B = -\mu B\cos\theta$$

에너지는 쌍극자 모멘트와 장의 내적에 음의 부호를 붙인 값이에요. $\vec\mu$가 $\vec B$와 **나란할 때** 에너지가 가장 낮고($-\mu B$), **반대일 때** 가장 높아요($+\mu B$). 그래서 $\vec\mu$는 $\vec B$와 나란해지려 해요 [C p51]. 공을 언덕에 두면 골짜기로 굴러가려는 것과 같은 이치예요.

**외부에서 돌리는 일** [C p53]: 외부 행위자가 쌍극자를 $\theta_i$에서 $\theta_f$로 돌리는데 처음과 끝에 쌍극자가 정지해 있으면, 운동 에너지 변화가 없으니 외부가 한 일이 모두 방향 에너지 변화로 가요.

$$W_a = \Delta U = U_f - U_i$$

> 보충 예: $\vec\mu$를 $\vec B$와 나란한 상태($\theta_i = 0^\circ$)에서 반대 상태($\theta_f = 180^\circ$)로 돌리면 $W_a = \mu B - (-\mu B) = 2\mu B$예요.

이렇게 큐는 회로를 도는 작은 전하에서 시작해, 자기장 속에서 휘고, 도선과 고리를 돌려 전동기까지 움직이는 존재가 됐어요. 그런데 지금까지 바람(자기장)은 늘 "이미 있는 것"이었어요. 그 바람은 어디서 생길까요? 답은 큐들 자신이에요.

## Ch29 전류에 의한 자기장

### 1. 비오-사바르 법칙: 전류 조각이 만드는 장

**직관.** Ch29의 비유는 **회오리**예요. 큐들이 줄지어 흐르면 그 둘레에 회오리바람이 일어요. 긴 직선 도선 둘레의 장선은 도선을 중심으로 한 동심원이고, 어느 점에서든 $\vec B$는 원의 접선, 곧 도선에서 그 점까지 그은 반지름선에 수직이에요(그림 29.1.2–3) [C p63].

**정의.** 전류를 아주 짧은 **전류 길이 요소** $i\,d\vec s$($d\vec s$는 전류 방향)로 나누면, 거리 $r$ 떨어진 점 P에 생기는 장은

$$dB = \frac{\mu_0}{4\pi}\frac{i\,ds\sin\theta}{r^2},\qquad d\vec B = \frac{\mu_0}{4\pi}\frac{i\,d\vec s\times\hat r}{r^2}\qquad [C\ p64,\ D\ p4]$$

$\theta$는 $d\vec s$와 $\hat r$(요소에서 P를 향하는 단위벡터) 사이 각이고, 방향은 $d\vec s\times\hat r$이에요. 이것이 **비오-사바르 법칙(Biot–Savart law)**이에요. $\mu_0 = 4\pi\times10^{-7}\ \mathrm{T\,m/A}\approx1.26\times10^{-6}\ \mathrm{T\,m/A}$는 정확히 정해 둔 **투자율 상수**예요. 요소와 일직선 위의 점은 $\sin0 = 0$이라 그 요소로부터 장을 받지 않아요.

**긴 직선 도선** [D p5–6]
1. 그림 29.1.6에서 도선 위 모든 요소의 $d\vec B$는 P에서 같은 방향(지면 안)이에요. 그래서 크기만 더하면 돼요.
2. 위쪽 절반($s = 0\sim\infty$)과 아래쪽 절반의 기여가 똑같으니 $B = 2\int_0^\infty dB = \dfrac{\mu_0 i}{2\pi}\int_0^\infty\dfrac{\sin\theta\,ds}{r^2}$
3. 그림에서 $r = \sqrt{s^2+R^2}$, $\sin\theta = R/\sqrt{s^2+R^2}$을 넣으면 $\dfrac{\mu_0 i}{2\pi}\int_0^\infty\dfrac{R\,ds}{(s^2+R^2)^{3/2}}$
4. 적분하면 $\dfrac{\mu_0 i}{2\pi R}\left[\dfrac{s}{(s^2+R^2)^{1/2}}\right]_0^\infty = \dfrac{\mu_0 i}{2\pi R}$

> 보충: 2단계의 절반만 쓰면 반무한 도선 끝 옆 점의 장 $\mu_0 i/(4\pi R)$이고, 짧은 도선은 같은 적분을 도선 양 끝까지만 하면 돼요 [C p62 LO7·9].

**방향: 굽은-직선 오른손 규칙** [D p7]: 오른손으로 도선을 쥐고 엄지를 전류 방향으로 펴면, 감기는 손가락이 장선 방향이에요.

**원호 중심** [D p7]: 반지름 $R$, 중심각 $\phi$인 원호에서는 모든 $d\vec s$가 $\hat r$에 수직이고 거리가 모두 $R$이에요. 그래서 $dB$를 호 길이 $R\phi$만큼 더하면

$$B = \frac{\mu_0}{4\pi}\frac{i(R\phi)}{R^2} = \frac{\mu_0 i\phi}{4\pi R}\quad(\phi\text{는 라디안})$$

그런데 회오리를 일으키는 도선 옆에 또 다른 도선이 있으면 어떻게 될까요?

### 2. 평행한 두 전류 사이의 힘

**절차** [D p10–12]
1. 도선 $a$가 도선 $b$ 위치(간격 $d$)에 만드는 장: $B_a = \mu_0 i_a/(2\pi d)$
2. 그 장이 $b$의 길이 $L$에 주는 힘(Ch28의 도선 공식): $\vec F_{ba} = i_b\vec L\times\vec B_a$
3. 크기: $F_{ba} = i_bLB_a\sin90^\circ = \dfrac{\mu_0 L i_a i_b}{2\pi d}$

$\vec L\times\vec B_a$의 방향을 따지면 $\vec F_{ba}$는 $a$ 쪽을 향하고, 같은 방법으로 $\vec F_{ab}$는 $b$ 쪽을 향해요. 그래서 **평행 전류는 끌어당기고**, 반평행 전류는 밀어내요 [D p13].

**레일 건** [D p14]: 두 레일에 전류를 흘리면 사이의 퓨즈가 곧 기화해 도전성 기체가 돼요. 레일 전류가 그 사이에 $\vec B$를 만들고, 전류 경로의 일부인 기체가 힘 $\vec F$를 받아 발사체를 레일 따라 밀어 내보내요.

조각마다 적분하는 일은 늘 번거로워요. 더 쉬운 길은 없을까요?

### 3. 앙페르 법칙

**왜 필요할까요?** 전하 분포가 대칭이면 가우스 법칙으로 전기장을 쉽게 구했어요. 전류도 대칭이 있으면 비오-사바르 합산 대신 **앙페르 법칙(Ampere's law)**을 쓸 수 있어요 [D p17–18]. 비오-사바르 법칙에서 유도할 수 있는 법칙이에요.

$$\oint\vec B\cdot d\vec s = \mu_0 i_{enc}\qquad [D\ p19]$$

**앙페르 고리**라는 닫힌 고리를 따라 $\vec B\cdot d\vec s$를 모두 더한 값이, 고리가 둘러싼 알짜 전류 $i_{enc}$에 $\mu_0$를 곱한 것과 같아요. 회오리를 한 바퀴 따라 잰 바람의 세기가 안에 갇힌 큐의 흐름으로 정해진다는 뜻이에요.

**부호** [D p20]: 오른손 손가락을 적분 방향으로 감았을 때 엄지 쪽으로 흐르는 전류는 +, 반대는 −예요. 그림 29.3.2에서 $\oint B\cos\theta\,ds = \mu_0(i_1 - i_2)$이고, $i_3$은 고리 **밖**이라 들어가지 않아요.

**긴 직선 도선 밖** [D p21–22]: 반지름 $r$ 원을 고리로 잡으면 $\vec B$가 어디서나 $d\vec s$와 나란하고 크기가 같아요. $B(2\pi r) = \mu_0 i$, 곧 $B = \mu_0 i/(2\pi r)$로 비오-사바르 결과와 같아요.

**도선 안(반지름 $R$, 균일 전류)** [D p23]
1. 반지름 $r<R$ 고리가 둘러싼 전류는 넓이에 비례: $i_{enc} = i\,\dfrac{\pi r^2}{\pi R^2}$ (부호 +)
2. $B(2\pi r) = \mu_0 i\dfrac{\pi r^2}{\pi R^2}$
3. $B = \left(\dfrac{\mu_0 i}{2\pi R^2}\right)r$

안에서는 $r$에 비례해 커지고, 표면 밖에서는 $1/r$로 줄어요.

도선을 용수철처럼 감으면 회오리들이 어떻게 합쳐질까요?

### 4. 솔레노이드와 토로이드

**솔레노이드** [D p27–28]: 도선을 촘촘히 감은 코일이에요. 장은 각 감김이 만든 장의 벡터 합이에요. 도선 가까이는 직선 도선처럼 동심원이지만, 이웃 감김 사이에서는 서로 상쇄되고 안쪽은 축에 나란해져요. 무한히 길고 촘촘한 **이상 솔레노이드**는 내부 장이 균일하고 축에 평행하며 바깥은 0이에요.

**앙페르 법칙 적용(그림 29.4.4)** [D p29–31]
1. 길이 $h$인 직사각형 고리 $abcda$를 잡고 $\oint$를 네 변의 합으로 나눠요.
2. ① 내부 $ab$: $Bh$ / ②④ 세로 변: $\vec B\perp d\vec s$이거나 0이라 0 / ③ 바깥: $B = 0$이라 0. 합은 $Bh$예요.
3. 단위 길이당 $n$번 감았으면 고리를 지나는 전류는 $i_{enc} = i(nh)$
4. $Bh = \mu_0 inh$, 곧 $B = \mu_0 in$ (끝에서 먼 내부)

**토로이드** [D p32–33]: 솔레노이드를 구부려 양 끝을 맞붙인 속 빈 팔찌예요. 대칭 때문에 내부 장선은 동심원이에요. 반지름 $r$ 원을 시계 방향으로 돌면 둘러싼 감김 $N$개가 모두 +라서 $B(2\pi r) = \mu_0 iN$, 곧 $B = \dfrac{\mu_0 iN}{2\pi}\dfrac1r$예요. 솔레노이드와 달리 단면에서 $B$가 일정하지 않아요.

마지막으로 감김 하나만 남긴 고리는 주변에 어떤 장을 만들까요?

### 5. 자기 쌍극자로서의 전류 코일

Ch28에서 코일은 외부 장 속에서 $\vec\tau = \vec\mu\times\vec B$($\mu = NiA$)를 받는 자기 쌍극자였어요 [D p37]. 이번엔 코일이 **만드는** 장을 봐요.

1. 중심($z = 0$): 모든 요소가 거리 $R$, $\hat r$에 수직이니 $B = \dfrac{\mu_0}{4\pi}\dfrac{i(2\pi R)}{R^2} = \dfrac{\mu_0 i}{2R}$ [D p38] (원호 공식에 $\phi = 2\pi$를 넣은 것과 같아요)
2. 중심축 위 $z$: $B(z) = \dfrac{\mu_0 iR^2}{2(R^2+z^2)^{3/2}}$ [D p39]
3. $z\gg R$이면 $B(z)\approx\dfrac{\mu_0 iR^2}{2z^3}$이고, $\pi R^2 = A$, $N$번 감으면 $B(z) = \dfrac{\mu_0}{2\pi}\dfrac{NiA}{z^3} = \dfrac{\mu_0}{2\pi}\dfrac{\mu}{z^3}$

오른손 손가락을 전류 방향으로 감으면 엄지가 $\vec\mu$ 방향이고, 장선 그림처럼 코일은 그 $\vec\mu$ 쪽이 N극인 막대자석과 같은 장을 만들어요. 큐의 작은 고리 하나가 곧 작은 자석인 셈이에요.

## 한눈에 이어 보기

- 기전력(펌프, $\mathscr{E} = dW/dq$) → 고리 규칙·저항/기전력 규칙 → $i = \mathscr{E}/(R+r)$, 단자 전압, 전력 $i\mathscr{E} = iV + i^2r$
- 직렬(같은 $i$) / 접합점 규칙 → 병렬(같은 $V$) → 혼합·다중 고리 연립 → 계기($R_A$ 작게, $R_V$ 크게) → RC 충전·방전($\tau = RC$)
- $\vec F_B = q\vec v\times\vec B$(수직, 속력 불변) → 교차장 $v = E/B$ → 홀 효과 $n = Bi/(eVl)$, $V = vBd$
- 원운동 $r = mv/\lvert q\rvert B$, $T$ 속력 무관 → 질량 분석기·나선 → 사이클로트론 $f = f_{osc}$ → 싱크로트론
- 도선 $\vec F_B = i\vec L\times\vec B$ → 고리 돌림힘 $\tau = NiAB\sin\theta$ → $\vec\mu = NiA\,\hat n$, $\vec\tau = \vec\mu\times\vec B$, $U = -\vec\mu\cdot\vec B$, $W_a = U_f - U_i$
- 비오-사바르 $d\vec B\propto i\,d\vec s\times\hat r/r^2$ → 직선 $\mu_0i/2\pi R$·원호·평행 도선 힘 → 앙페르 $\oint\vec B\cdot d\vec s = \mu_0i_{enc}$ → 도선 안팎·솔레노이드 $\mu_0in$·토로이드 → 코일 축 위 $B\propto\mu/z^3$
