# Ch27-29 회로와 자기장 정리 노트

> 범위: A p31–52, B p2–49, C p2–64, D p3–39, R p39–59 · 출처 약어: A = Phys2-260928(Ch26_Ch27).pdf, B = Phys2-260930(Ch27_Ch28).pdf, C = Phys2-261005(Ch28_Ch29).pdf, D = Phys2-261007(Ch29).pdf, R = Phys2-261021(Review).pdf(복습, 중복 생략)

## Ch27 회로

### 1. 핵심 개념
- **기전력 장치(emf device)**: 전하 운반자에 일을 해 두 단자 사이 전위차를 유지하는 "전하 펌프". 예: 전지(화학), 발전기(역학), 태양전지(태양). + 단자가 높은 전위 [A p37–38]
- emf는 옛 용어 electromotive force에서 온 이름(힘이 아님) [A p37]
- **이상 기전력 장치**: 내부 저항 0, 단자 전압 = $\mathscr{E}$ / **실제 장치**: 내부 저항 $r$(제거 불가), 전류 0일 때만 단자 전압 = $\mathscr{E}$ [A p39, p45]
- **소모(dissipation)**: 저항에서 $dt$ 동안 $i^2R\,dt$가 열에너지로 변환(도선 저항 무시) [A p40]
- **접지(grounding)**: 회로 한 점을 지면(축축한 흙·암석)으로 가는 도체 경로에 연결. 회로 전류에 영향 없음 [A p52, A p36 LO14]
- **전류계(ammeter)**: 도선을 끊고 직렬 삽입, $R_A \ll$ 회로 저항 / **전압계(voltmeter)**: 도선을 끊지 않고 두 점에 병렬 연결, $R_V \gg$ 측정 소자 저항 [B p17–20]
- **RC 회로**: 저항·축전기·전지 직렬. 스위치 S를 a에 두면 충전, b로 넘기면 방전 [B p24, p27]
- **용량 시간 상수(capacitive time constant)** $\tau = RC$ [B p25]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $\mathscr{E} = dW/dq$ | 양전하 $dq$를 −→+ 단자로 옮기는 일, V | 정의 [A p39] |
| $i = \mathscr{E}/R$ | | 이상 전지 + 저항 1개 [A p41] |
| $i = \dfrac{\mathscr{E}}{R+r}$ | $r$: 내부 저항 | 실제 전지 단일 고리 [A p45] |
| $V_b - V_a = \mathscr{E} - ir = \dfrac{\mathscr{E}R}{R+r}$ | 단자 전압 | 전류가 기전력 방향 [A p47] |
| $R_{eq} = \sum R_j$ | | 직렬 [A p49] |
| $\dfrac{1}{R_{eq}} = \sum \dfrac{1}{R_j}$ | | 병렬 [B p11] |
| $\dfrac{1}{C_{eq}} = \sum \dfrac{1}{C_j}$ / $C_{eq} = \sum C_j$ | | 축전기 직렬 / 병렬 [B p13] |
| $P = iV$ | 전하 운반자로의 에너지 전달률, W | [B p31] |
| $P_r = i^2r$ | 전지 내부 열 소모율 | [B p32] |
| $P_{emf} = i\mathscr{E}$ | 운반자+내부 열로 가는 총 전달률(화학에너지 변화율) | [A p52] |
| $R\dfrac{dq}{dt} + \dfrac{q}{C} = \mathscr{E}$ | 충전 방정식 | $t=0$에서 $q=0$ [B p24] |
| $q = C\mathscr{E}(1 - e^{-t/RC})$ | $q_0 = C\mathscr{E}$: 최종 전하 | 충전 [B p25] |
| $i = (\mathscr{E}/R)e^{-t/RC}$ | 초기 $\mathscr{E}/R$ → 0 | 충전 [B p26] |
| $V_C = \mathscr{E}(1 - e^{-t/RC})$ | $t=0$: 0, $t\to\infty$: $\mathscr{E}$ | 충전 [B p26] |
| $R\dfrac{dq}{dt} + \dfrac{q}{C} = 0$ | 방전 방정식 | $\mathscr{E}=0$, 처음 $V_0$ [B p27] |
| $q = q_0e^{-t/RC}$, $q_0 = CV_0$ | | 방전 [B p28] |
| $i = -(q_0/RC)e^{-t/RC}$ | 초기 크기 $i_0 = q_0/\tau$ | 방전 [B p28] |

> 보충: 전류가 기전력 반대 방향(전지가 충전될 때) 단자 전압 $\mathscr{E} + ir$. 방전 $V_C = V_0e^{-t/RC}$, 저항 전압 $V_R = iR$. 동일 실제 전지 $N$개 직렬 → $N\mathscr{E}$, $Nr$ / 병렬 → $\mathscr{E}$, $r/N$ [B p6 LO8–9]

### 3. 원리·결론
- **고리 규칙**: 닫힌 고리 한 바퀴 전위 변화의 대수합 = 0 [A p44]
- **저항 규칙**: 전류 방향으로 통과 $-iR$, 반대 $+iR$ [A p44]
- **기전력 규칙**: 기전력 화살표 방향 $+\mathscr{E}$, 반대 $-\mathscr{E}$ [A p44]
- **접합점 규칙**: 들어오는 전류 합 = 나가는 전류 합(전하 보존) [B p7]
- 큰 고리 방정식 = 작은 고리 방정식들의 합 → 독립 식 아님 [B p8]

| | 직렬 | 병렬 |
|---|---|---|
| 저항 공통량 | 같은 전류 $i$ | 같은 전위차 $V$ |
| 나뉘는 양 | 전위차 합 = $V$ | 전류 합 = $i$ |
| 같은 저항 2개 | 각 $V/2$, $i$ | 각 $V$, $i/2$ [B p14] |
| 축전기 공통량 | 같은 전하 | 같은 전위차 |

- 직렬에서 $R$이 클수록 전위차 큼($R_1>R_2>R_3 \Rightarrow V_1>V_2>V_3$) [A p51]
- RC: 충전 시 $q$, $V_C$는 증가해 포화, 전류는 지수 감소. 방전 시 $q$, $i$ 모두 지수 감소 [B p25–28]
- 전위 그래프(그림 27.1.4b): $V_a$ → 전지 $+\mathscr{E}$ → $r$에서 $-ir$ → $R$에서 $-iR$ → $V_a$ 복귀 [A p45]
- 그림 27.3.1: 전류계는 $a$–$b$ 사이 직렬, 전압계는 $R_1$ 양단 $c$–$d$ [B p20]

### 4. 문제 유형별 접근
- 단일 고리 전류: 전류 방향 가정 → 한 점에서 한 바퀴 → 규칙대로 합 = 0
- 두 점 전위차: 출발점에서 아무 경로로 도착점까지 전위 변화 대수합 [A p46]
- 직·병렬 혼합: 등가 저항으로 단계적 단순화 → 전지 전류 → 역순으로 각 저항 $i$, $V$ [B p5]
- 단순화 불가 다중 고리: 가지 전류 이름·방향 지정 → 접합점 식 + 독립 고리 식 → 연립 [B p6]
- RC: 충전/방전 판단 → 해당 $q(t)$ → 미분해 $i$, $q/C$로 $V_C$; $t=0$과 $t\to\infty$ 값 확인

### 5. 실수 포인트
- 부호는 **이동 방향** 기준(전류 방향으로 지날 때만 $-iR$)
- 축전기 합성식은 저항과 반대(직렬 역수합, 병렬 합)
- 방전 전류의 음수 = 충전 때와 반대 방향
- 계기 연결: 전류계 직렬·작은 저항, 전압계 병렬·큰 저항

## Ch28 자기장

### 1. 핵심 개념
- **자기장(magnetic field)** $\vec{B}$: 움직이는 전하에 힘 $\vec{F}_B$를 주는 벡터량. 크기 $B = F_B/(\lvert q\rvert v)$($\vec v$가 힘에 수직일 때) [B p40]
- **자기장선**: 접선 = $\vec B$ 방향, 촘촘할수록 강함. 닫힌 곡선, 나오는 끝 N극·들어가는 끝 S극 [B p45–46]
- **자기 쌍극자**: 두 극을 가진 자석. 다른 극 인력, 같은 극 척력 [B p46]
- **전자석 vs 영구자석**(보충): 전자석은 코일 전류로 자기장 생성(세기 조절 가능), 영구자석은 물질 자체가 자기장 생성 [B p36 LO1]
- **Thomson 장치**: 편향판 $\vec E$ + 코일 $\vec B$(지면 안쪽)의 교차장으로 전자의 질량/전하 비 측정 [B p49]
- **홀 효과(Hall effect)**: 전류 흐르는 띠에 수직 $\vec B$ → 운반자가 한쪽에 쌓여 횡 전위차 $V$. 운반자 부호와 $n$ 측정 [C p8–9]
- **사이클로트론**: D자 전극 2개 + 진동기(간극 전기장 교대) + 큰 $\vec B$. 간극에서 에너지 얻고 나선형으로 바깥 [C p25]
- **싱크로트론**: $B$, $f_{osc}$를 시간에 따라 변화 → 원 경로 유지, 자석은 경로에만 [C p27]
- **자기 쌍극자 모멘트** $\vec\mu$: 크기 $NiA$, 방향 = 오른손 규칙 법선 $\vec n$ [C p51]
- **정류자**: 반 바퀴마다 전류 반전 → 전동기 돌림힘 방향 유지 [C p37]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $\vec F_B = q\vec v\times\vec B$ | 같은 기준틀 | [B p40] |
| $F_B = \lvert q\rvert vB\sin\phi$ | $\phi$: $\vec v$와 $\vec B$ 사이 각 | [B p41] |
| $v = E/B$ | | 교차장, 두 힘 상쇄 [C p3] |
| $eE = ev_dB$, $E = \left(\dfrac{B}{ne}\right)J$ | $J = nev_d$ | 홀 평형 [C p10] |
| $n = \dfrac{JB}{eE} = \dfrac{Bi}{eVl}$ | $l = A/d$: 두께, $V = Ed$ | [C p13] |
| $V = Ed = vBd$ | $d$: $\vec v$, $\vec B$ 모두에 수직인 폭 | 움직이는 도체 [C p12] |
| $\lvert q\rvert vB = mv^2/r$, $r = \dfrac{mv}{\lvert q\rvert B}$ | | $\vec v\perp\vec B$ 원운동 [C p18] |
| $T = \dfrac{2\pi m}{\lvert q\rvert B}$, $f = 1/T$, $\omega = \dfrac{\lvert q\rvert B}{m}$ | | 속력 무관 [C p19] |
| $f = \dfrac{\lvert q\rvert B}{2\pi m}$ | 회전 진동수 | 속력 무관 [C p19, C p26] |
| $f = f_{osc}$ | 공명 조건 | 사이클로트론 [C p26] |
| $\vec F_B = i\vec L\times\vec B$ | $\vec L$: 전류 방향, 크기 $iLB\sin\phi$ | 직선 도선, 균일 $\vec B$ [C p33] |
| $d\vec F_B = i\,d\vec L\times\vec B$ | | 휜 도선·불균일 $\vec B$ [C p34] |
| $\tau = NiAB\sin\theta$ | $\theta$: $\vec B$와 $\vec n$ 사이 각 | 코일 [C p42] |
| $\mu = NiA$, $\vec\tau = \vec\mu\times\vec B$ | $\tau = \mu B\sin\theta$ | [C p50] |
| $U(\theta) = -\vec\mu\cdot\vec B$ | | 방향 에너지 [C p52] |
| $W_a = \Delta U = U_f - U_i$ | | 처음·끝 정지 [C p53] |

> 보충: 나선 $v_\parallel = v\cos\phi$, $v_\perp = v\sin\phi$, $r = mv_\perp/(\lvert q\rvert B)$, 피치 $p = v_\parallel T$ [C p16 LO6–7]

### 3. 원리·결론
- $\vec F_B$는 항상 $\vec v$, $\vec B$에 수직 → 속력·운동에너지 불변(방향만 바뀜) [B p42]
- 오른손 규칙: 손가락을 $\vec v$에서 $\vec B$로 휨 → 엄지 = $\vec v\times\vec B$. $q>0$ 엄지 방향, $q<0$ 반대 [B p43]
- 운동 형태: $\vec v\parallel\vec B$ 직선, $\vec v\perp\vec B$ 원, 그 밖 나선(평행 성분 → 피치, 수직 성분 → 반지름) [C p22]
- $T$, $f$, $\omega$는 속력 무관. 같은 $\lvert q\rvert/m$이면 같은 주기(빠르면 큰 원) [C p19]
- 교차장: $v>E/B$ 자기력 우세, $v<E/B$ 전기력 우세(보충) [B p48 LO]
- 원궤도: $\vec F_B$는 원 중심, $\vec v$는 접선. 양·음전하는 같은 $\vec B$에서 반대 방향 회전 [C p17]
- 홀(그림 28.3.1): 전류 위→아래, 전자 아래→위, $\vec B$ 지면 안 → 전자 오른쪽 축적, 왼쪽 High [C p9–10]
- 홀: $F_E = F_B$가 되면 전하 축적 멈춤(전기장 크기의 한계). 높은 전위 쪽으로 운반자 부호 판별 [C p10–11]
- 도선(그림 28.6.1, $\vec B$ 지면 밖): 전류 위쪽 → 오른쪽으로 휨, 아래쪽 → 왼쪽 [C p31]
- 홀 전기장 $E = (B/ne)J$는 충돌 시간 $\tau$와 무관(cf. $\rho = m/(e^2n\tau)$) [C p10]
- 사이클로트론: 고유 회전 진동수와 같은 진동수로 에너지 공급해야 가속 [C p26]
- 전류 고리: 알짜 힘 0, 돌림힘은 $\vec n$(=$\vec\mu$)을 $\vec B$ 방향으로 정렬 [C p41]
- 돌림힘 부호(보충): 반시계 방향 회전이면 +, 시계 방향이면 − [C p46 LO5]
- 돌림힘 최대 $\theta=90^\circ$, 0은 $\theta=0^\circ, 180^\circ$(보충) / 에너지 최저 $-\mu B$($\vec\mu\parallel\vec B$), 최고 $+\mu B$(반대) [C p51–52]
- 전기·자기 쌍극자 대응: $\vec\tau = \vec p\times\vec E \leftrightarrow \vec\mu\times\vec B$, $U = -\vec p\cdot\vec E \leftrightarrow -\vec\mu\cdot\vec B$ [C p49–52]

### 4. 문제 유형별 접근
- 자기력 방향: $\vec v\times\vec B$(오른손 또는 단위벡터 외적) → $q$ 부호 반영
- 교차장 속도 선택: $\lvert q\rvert E = \lvert q\rvert vB$ → $v = E/B$ → 편향으로 $q/m$ 측정 [C p4]
- 홀 효과: $eE = ev_dB$ → $V = Ed$ → $n = Bi/(eVl)$; 높은 전위 쪽으로 부호
- 질량 분석기: $qV = \frac12mv^2$ → $v$ → $r = mv/(\lvert q\rvert B)$ → $m$
- 도선 힘: $\vec L$을 전류 방향으로 → $i\vec L\times\vec B$; 휘면 조각 합
- 코일 돌림힘·에너지: $\mu = NiA$, 방향 오른손 → $\tau = \mu B\sin\theta$, $U = -\mu B\cos\theta$ → $W_a = U_f - U_i$

### 5. 실수 포인트
- 음전하(전자)는 엄지 **반대**
- $\theta$는 고리 면이 아니라 **법선** $\vec n$과 $\vec B$ 사이 각
- 홀 $d$는 $\vec v$와 $\vec B$ 둘 다에 수직인 폭, $l$은 두께
- 반지름은 속력에 비례, 주기는 속력과 무관

## Ch29 전류에 의한 자기장

### 1. 핵심 개념
- **전류 길이 요소** $i\,d\vec s$: 자기장을 만드는 전류의 작은 조각. $d\vec s$는 전류 방향 [C p64]
- **투자율 상수(permeability constant)** $\mu_0 = 4\pi\times10^{-7}\ \mathrm{T\,m/A} \approx 1.26\times10^{-6}\ \mathrm{T\,m/A}$(정확히 정의된 값) [C p64]
- **긴 직선 도선의 자기장선**: 도선 둘레 동심원. $\vec B$는 원의 접선 = 도선에서 그은 반지름선에 수직 [C p63]
- **굽은-직선 오른손 규칙**: 엄지 = 전류 방향, 감기는 손가락 = 장선 방향 [D p7]
- **앙페르 고리(Amperian loop)**: 앙페르 법칙의 선적분을 하는 닫힌 고리. $i_{enc}$ = 고리가 둘러싼 알짜 전류 [D p19]
- **이상 솔레노이드(solenoid)**: 무한히 길고 촘촘히 감긴 코일. 내부 $\vec B$ 균일·축에 평행, 외부 0 [D p27, p29]
- **토로이드(toroid)**: 양 끝을 맞붙게 구부린 솔레노이드(속 빈 팔찌). 내부 장선은 동심원 [D p32]
- **레일 건(rail gun)**: 레일 전류가 퓨즈를 기화 → 레일 사이 $\vec B$ → 전류 경로인 도전성 기체에 힘 → 발사체 발사 [D p14]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $dB = \dfrac{\mu_0}{4\pi}\dfrac{i\,ds\sin\theta}{r^2}$ | $\theta$: $d\vec s$와 $\hat r$ 사이 각 | 비오-사바르 법칙(크기 형태) [C p64] |
| $d\vec B = \dfrac{\mu_0}{4\pi}\dfrac{i\,d\vec s\times\hat r}{r^2}$ | $\hat r$: 요소 → 점 P | 비오-사바르 법칙 [D p4] |
| $B = \dfrac{\mu_0 i}{2\pi R}$ | $R$: 도선까지 수직 거리 | 무한히 긴 직선 도선 [D p6] |
| $B = \dfrac{\mu_0 i\phi}{4\pi R}$ | $\phi$: 중심각(라디안) | 원호 중심 [D p7] |
| $F_{ba} = i_bLB_a = \dfrac{\mu_0 L i_a i_b}{2\pi d}$ | $d$: 도선 간격 | 평행 긴 도선, $\vec F_{ba} = i_b\vec L\times\vec B_a$ [D p12] |
| $\oint\vec B\cdot d\vec s = \mu_0 i_{enc}$ | | 앙페르 법칙, 대칭 있을 때 유용 [D p19] |
| $B = \dfrac{\mu_0 i}{2\pi r}$ / $B = \left(\dfrac{\mu_0 i}{2\pi R^2}\right)r$ | $R$: 도선 반지름 | 원형 단면 긴 도선 밖 / 안(균일 전류) [D p22] |
| $B = \mu_0 in$ | $n$: 단위 길이당 감은 수 | 이상 솔레노이드, 끝에서 먼 내부 [D p31] |
| $B = \dfrac{\mu_0 iN}{2\pi}\dfrac1r$ | $N$: 전체 감은 수 | 토로이드 내부 [D p33] |
| $B = \dfrac{\mu_0 i}{2R}$ | | 원형 고리 중심 [D p38] |
| $B(z) = \dfrac{\mu_0 iR^2}{2(R^2+z^2)^{3/2}}$ | $z$: 중심축 위 거리 | 원형 고리 축 위 [D p39] |
| $B(z) = \dfrac{\mu_0}{2\pi}\dfrac{NiA}{z^3}$ | $\mu = NiA$이면 $\dfrac{\mu_0\mu}{2\pi z^3}$ | $z\gg R$, $N$회 코일 [D p39] |

> 보충: 요소와 일직선 위 점($\theta = 0$)은 $dB = 0$. 반무한 도선 끝 옆 점은 무한 도선의 절반 $B = \mu_0 i/(4\pi R)$ [C p60–62 LO3·7]

### 3. 원리·결론
- 긴 직선 도선: 모든 요소의 $d\vec B$가 P에서 같은 방향 → 크기만 적분 [D p5]
- 평행 전류는 끌어당기고, 반평행 전류는 밀어냄 [D p13]
- 앙페르 부호: 오른손을 적분 방향으로 감을 때 엄지 방향 전류 +, 반대 − [D p20]
- 고리 밖 전류는 $\oint$에 기여하지 않음(둘러싼 전류만 사용) [D p19–20]
- 앙페르 법칙은 비오-사바르 법칙에서 유도 가능, 대칭(가우스 법칙과 대응)이 있을 때 계산이 훨씬 쉬움 [D p17–19]
- 도선 안 $B\propto r$, 밖 $B\propto 1/r$ [D p22] (보충: 따라서 표면에서 최대)
- 솔레노이드: 각 감김의 장의 벡터 합. 이웃 감김 사이에서 상쇄, 내부는 축에 평행 [D p28]
- 토로이드 $B$는 단면에서 일정하지 않음($\propto 1/r$), 솔레노이드는 균일 [D p33]
- 전류 코일 = 자기 쌍극자: 외부 장에서 $\vec\tau = \vec\mu\times\vec B$를 받고, 스스로 막대자석 같은 장을 만듦. 오른손 손가락 = 전류, 엄지 = $\vec\mu$ = N극 쪽 [D p37–39]

### 4. 문제 유형별 접근
- 비오-사바르: $d\vec s$, $\hat r$, $\theta$ 표시 → $d\vec B$ 방향($d\vec s\times\hat r$) 확인 → 방향이 같으면 크기만 적분
- 평행 도선 힘: 한 도선의 $B$를 다른 도선 위치에서 구함 → $i\vec L\times\vec B$로 힘 [D p10]
- 앙페르: 대칭에 맞는 고리 선택($B$ 일정·평행 또는 수직) → $\oint$ 계산 → 부호 붙인 $i_{enc}$ → $B$
- 솔레노이드: 직사각형 고리 → 내부 변만 $Bh$ → $i_{enc} = inh$

### 5. 실수 포인트
- 원호 $\phi$는 **라디안**, 원 전체는 $\phi = 2\pi$
- 도선 **안**은 $i_{enc} = i\,r^2/R^2$만 사용
- 솔레노이드 $n$은 단위 길이당, 토로이드 $N$은 전체 감은 수
