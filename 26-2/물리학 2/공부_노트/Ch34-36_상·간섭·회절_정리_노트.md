# Ch34-36 상·간섭·회절 정리 노트

> 범위: A p21–41, B p2–49, C p2–40, D p2–35, E p3–46 · 출처 약어: A = Phys2-261109(Ch33_Ch34).pdf, B = Phys2-261111(Ch34).pdf, C = Phys2-261116(Ch35).pdf, D = Phys2-261118(Ch35_Ch36).pdf, E = Phys2-261123(Ch36_Ch37).pdf

## Ch34 상

### 1. 핵심 개념
- **상(image)**: 빛에 의한 물체의 재현. 거울·굴절면·얇은 렌즈가 광원(물체)에서 나온 광선의 방향을 바꿔 만듦 [A p24, B p45]
- **실상(real image)**: 면 위에 맺힘, 관찰자 없어도 존재 / **허상(virtual image)**: 관찰자의 시각 체계 필요, 지각된 위치에 있다고 봄 [A p24]
- **평면거울**: 반사 광선의 뒤쪽 연장선이 만나는 곳에 허상. 방향·높이 같음, 거울 뒤 같은 거리 [A p25–26]
- **구면거울**: 오목(concave, $r>0$) · 볼록(convex, $r<0$) · 평면($r=\infty$) [A p31]
- **초점(focal point)**: 축에 평행한 광선이 모이는 점. 오목거울 = 실초점($f>0$), 볼록거울 = 반사광 연장선이 모이는 허초점($f<0$) [A p34]
- **수렴 렌즈(converging lens)**: 볼록 면, 실초점 $F_2$, 반대쪽 $F_1$(얇으면 등거리), $f>0$ / **발산 렌즈(diverging lens)**: 오목 면, 연장선이 허초점, $f<0$ [B p21–24]
- **근점(near point)** $P_n \approx 25$ cm: 눈이 선명히 볼 수 있는 가장 가까운 위치 [B p35]
- **각배율(angular magnification)** $m_\theta = \theta'/\theta$: 상이 차지하는 각 ÷ 근점에 둔 물체가 차지하는 각 [B p36]

### 2. 공식
| 공식 | 기호·뜻 | 사용 조건 |
|---|---|---|
| $i = -p$ | $p>0$, 허상 $i<0$ | 평면거울 [A p25] |
| $f = \dfrac{r}{2}$ | $r$: 곡률 반지름 | 구면거울 [A p35] |
| $\dfrac1p + \dfrac1i = \dfrac1f$ | 물체·상 거리, 초점거리 | 구면거울(근축), 얇은 렌즈 [B p4, p18] |
| $\lvert m\rvert = \dfrac{h'}{h}$, $m = -\dfrac{i}{p}$ | $m>0$ 정립, $m<0$ 도립 | 거울·렌즈 횡배율; 평면거울 $m=+1$ [B p5, p27] |
| $\dfrac{n_1}{p} + \dfrac{n_2}{i} = \dfrac{n_2 - n_1}{r}$ | $n_1$: 물체 쪽, $n_2$: 반대쪽 | 구면 굴절면(근축) [B p11] |
| $\dfrac1f = (n-1)\left(\dfrac1{r_1} - \dfrac1{r_2}\right)$ | $r_1$: 물체에 가까운 면 | 공기 중 얇은 렌즈(렌즈 제작자 공식); 다른 매질이면 $n \to n/n_{medium}$ [B p19] |
| $m_\theta = \dfrac{25\ \text{cm}}{f}$ | | 확대경, 물체가 $F_1$ 바로 안 [B p36] |
| $M = m\,m_\theta = -\dfrac{s}{f_{ob}}\dfrac{25\ \text{cm}}{f_{ey}}$ | $s$: 경통 길이, $m \approx -s/f_{ob}$ | 복합 현미경 [B p40–41] |
| $m_\theta = \dfrac{\theta_{ey}}{\theta_{ob}} = -\dfrac{f_{ob}}{f_{ey}}$ | 음수 = 최종 상 도립 | 굴절 망원경 [B p44] |

### 3. 원리·결론
- 부호 규약 정리 [A p25–36, B p11, p20, p24]

| 양 | + | − |
|---|---|---|
| $i$ (거울) | 실상(거울 앞) | 허상(거울 뒤) |
| $i$ (굴절면·렌즈) | 실상(물체 반대쪽) | 허상(물체와 같은 쪽) |
| $r, f$ (거울) | 오목 | 볼록 |
| $r$ (굴절면·렌즈 면) | 물체가 보는 면이 볼록 | 물체가 보는 면이 오목 |
| $f$ (렌즈) | 수렴 | 발산 |
| $m$ | 정립 | 도립 |

- 오목거울: 물체가 초점 안 → 거울 뒤 허상·정립 / 초점 위 → 상은 무한대(지각 불가) / 초점 밖 → 실상·도립, $i>0$ [A p36]
- 오목거울(평면거울 대비): 곡률중심 C가 앞, 시야 감소, 상이 더 뒤로·확대 / 볼록: C가 뒤, 시야 증가, 상이 가깝게·축소 [A p32–33]
- 실상·허상 둘 다: 오목거울, 수렴 렌즈 / 허상만: 볼록거울, 발산 렌즈 [B p4, p27]
- 거울 특수 광선: ① 축 평행 → F 통과 ② F 통과 → 축 평행 ③ C 통과 → 제자리로 ④ 꼭짓점 c → 축 대칭 반사. 아무 두 개 교점 = 상 [A p37–39]
- 렌즈 특수 광선: ① 축 평행 → $F_2$ 통과 ② $F_1$ 통과 → 축 평행 ③ 중심 → 방향 그대로 [B p25]
- 볼록거울·발산 렌즈·초점 안 물체: 광선 대신 **뒤쪽 연장선**의 교점으로 작도 [A p39, B p26–27]
- 굴절면 6가지 배치: 광선이 축 쪽으로 꺾이면 실상((a)(b)), 축에서 멀어지면 허상(나머지 4개) [B p9]
- 렌즈는 주변 매질과 굴절률이 달라야 빛을 꺾음 [B p20]
- 현미경: 물체는 대물 $F_1$ 바로 밖($p\approx f_{ob}$), 대물이 만든 확대·도립 실상은 접안 $F_1'$ 바로 안, 접안이 확대경 역할 → 최종 허상·도립 [B p39–41]
- 망원경: 대물 $F_2$ = 접안 $F_1'$(현미경은 $s$만큼 떨어짐). 설계 요소: 집광력, 분해능, 시야, 구면·색수차 [B p43–44]
- (참고) 근시: 초점이 망막 앞 → 오목 렌즈 / 원시: 초점이 망막 뒤 → 볼록 렌즈 [B p37]

### 4. 문제 유형별 접근
- 거울·렌즈 상 찾기: 부호 정하기 → $1/p+1/i=1/f$로 $i$ → $i$ 부호로 실/허 → $m=-i/p$로 크기·방향
- 렌즈 초점거리: $r_1$(물체 쪽 면)·$r_2$ 부호 정하기 → 렌즈 제작자 공식
- 2렌즈계: ① 렌즈 2 무시, 렌즈 1의 상 $I_1$ ② 렌즈 1 무시, $I_1$을 렌즈 2의 물체로 → $I_2$(최종 상). 전체 배율 $M = m_1 m_2$ [B p29–30]
- 광선도: 특수 광선 두 개 → 교점(또는 연장선 교점) → 축에서 먼 점부터 상 작도

### 5. 실수 포인트
- 굴절면 $r$ 부호는 곡률중심 위치가 아니라 **물체가 바라보는 면 모양** 기준 [B p11]
- 2렌즈계에서 $I_1$이 렌즈 2 뒤쪽에 맺히면 $p_2 < 0$ [B p31]
- $\lvert m\rvert$는 크기 비, 방향은 $m$의 부호 [B p5]

> 보충(LO만 있음): 신기루 = 지면 근처 뜨거운 공기의 굴절률이 낮아 하늘빛이 위로 휘어 도로 위 "물웅덩이" 허상 [A p23]. 정삼각형 거울 미로 = 거울에 거울 상이 반복 반사돼 긴 복도 허상 [A p23].

## Ch35 간섭

### 1. 핵심 개념
- **하위헌스 원리(Huygens' principle)**: 파면 위 모든 점이 구면 2차 파원, 시간 $t$ 뒤 새 파면 = 2차 파들의 접면 [C p11]
- **굴절률(index of refraction)** $n = c/v$ [C p12]
- **회절(diffraction)**: 파장과 비슷한 크기의 틈을 지난 파동이 퍼짐. 틈이 좁을수록 큼 [C p19]
- **영의 실험(Young's experiment)**: 단색광 → 슬릿 $S_0$(점광원) → $S_1$, $S_2$(두 점광원) → 화면에 극대·극소 무늬 [C p20]
- **결맞음(coherent)**: 같은 파장 + 위상차가 시간에 대해 일정. 눈에 띄는 간섭의 조건 [C p28]
- **얇은 막 간섭**: 막(굴절률 $n_2$, 두께 $L$)의 앞·뒷면 반사파 간섭. $\lambda$ = 공기 중 파장 [C p36–37]
- **간섭계(interferometer)**: 간섭 무늬로 길이·길이 변화를 정밀 측정. 마이컬슨: 거울 M이 빛을 둘로 나눔 → $M_1$, $M_2$ 반사 → 재결합 → 망원경 T [D p4–5]

### 2. 공식
| 공식 | 기호·뜻 | 사용 조건 |
|---|---|---|
| $n_1\sin\theta_1 = n_2\sin\theta_2$ | 굴절 법칙 | [C p13] |
| $\lambda_n = \lambda/n$, $f_n = f$ | $\lambda$: 진공 파장 | 매질 속 [C p14] |
| $\Delta L = d\sin\theta$ | $d$: 슬릿 간격 | $D \gg d$ [C p22] |
| $d\sin\theta = m\lambda$ | $m=0,1,2,\dots$ | 이중 슬릿 밝은 무늬 [C p22] |
| $d\sin\theta = (m+\tfrac12)\lambda$ | $m=0,1,2,\dots$ | 이중 슬릿 어두운 무늬 [C p22] |
| $y_m = \dfrac{m\lambda D}{d}$, $\Delta y = \dfrac{\lambda D}{d}$ | $D$: 슬릿–화면 거리 | 작은 각, 중앙 근처 [C p24] |
| $E_1 = E_0\sin\omega t$, $E_2 = E_0\sin(\omega t+\phi)$ | 페이저 각속도 = $\omega$ | [C p30] |
| $I = 4I_0\cos^2\dfrac{\phi}{2}$, $\phi = \dfrac{2\pi d}{\lambda}\sin\theta$ | $I_0$: 한 슬릿만의 세기 | 결맞는 이중 슬릿 [C p32] |
| $2L = (m+\tfrac12)\dfrac{\lambda}{n_2}$ | $m=0,1,2,\dots$ | 공기 중 막, 밝음(반사 극대) [C p40] |
| $2L = m\dfrac{\lambda}{n_2}$ | $m=0,1,2,\dots$ | 공기 중 막, 어두움(반사 극소) [C p40] |
| 위상차(파장 수) $= \dfrac{2L}{\lambda}(n-1)$ | $L$, $n$: 삽입 물질 | 간섭계 한 경로에 물질 [D p6] |

### 3. 원리·결론
- 굴절 법칙은 하위헌스 원리와 $n=c/v$에서 나옴 [C p12]
- 이중 슬릿 무늬 이름: 중앙 극대($m=0$) → 바깥으로 첫째·둘째 옆 극대(1차·2차 …), 극소도 $m$으로 차수 표시 [C p17, p22]
- $n$ 클수록 파장 짧음 → 다른 매질을 지나면 위상차가 변함. 진동수는 불변(경계면 파동 연속) [C p14]
- 중첩: 위상 같음 → 보강, $\pi$ 어긋남 → 상쇄, 그 사이 → 중간 밝기 [C p21]
- 이중 슬릿 세기: 극대 $4I_0$(φ = 0, 2π, …), 극소 0(φ = π, 3π, …), 평균 $2I_0$; 결어긋남이면 균일 $2I_0$ [C p29]
- 페이저 합: 진폭 $E = 2E_0\cos(\phi/2)$, 위상 상수 $\beta = \phi/2$ [C p31]
- 반사 위상 변화: **작은 $n$ 쪽에서 입사**해 반사 → $\pi$ rad(반 파장), 반대는 0. 굴절은 위상 변화 없음 [C p36, p38]
- 막 간섭의 세 요소: 반사 위상 이동, 경로차 $2L$(θ≈0), 막 내부 파장 $\lambda/n_2$ [C p34, p37]
- 공기 중 막: 앞면 반사 $r_1$만 반 파장 이동, 뒷면 $r_2$는 이동 없음 [C p39]
- 매우 얇은 막($L \ll \lambda$): 경로차 ≈ 0, 반 파장 차만 남아 항상 어두움 [C p35]
- 막이 공기 아닌 매질 사이에 있으면 밝음·어두움 식이 서로 바뀔 수 있음 [C p36]
- 마이컬슨: 경로차 $2d_2 - 2d_1$, 이를 바꾸는 모든 것이 위상차를 바꿈 [D p5]
- 무지개는 광학 간섭의 예 [C p10]

### 4. 문제 유형별 접근
- 이중 슬릿 무늬 위치: 밝음/어둠 식으로 $\theta$ → $y = D\tan\theta$ (작은 각이면 $y \approx D\theta$)
- 이중 슬릿 세기: $\phi = 2\pi d\sin\theta/\lambda$ → $I = 4I_0\cos^2(\phi/2)$
- 얇은 막: 각 경계 반사 위상 이동 판단 → 두 반사파의 반 파장 이동 개수(0·2개 vs 1개) → 경로차 $2L$을 $\lambda/n_2$ 단위로 놓고 보강/상쇄 식 선택
- 다른 매질·경로의 위상차: 각 경로의 파장 수 $N = Ln/\lambda$ 차이 → 정수면 보강, 반정수면 상쇄

### 5. 실수 포인트
- 막 식의 $\lambda$는 공기 중 파장, 막 안 파장은 $\lambda/n_2$ [C p40]
- 위상 이동은 반사에서만, 굴절(투과)에선 없음 [C p36]
- 이중 슬릿 극대·극소 모두 $m$은 0부터 [C p22]

> 보충(LO만 있음): 매질 속 통과 시간 $t = L/v = nL/c$, 길이 $L$ 안 파장 수 $N = Ln/\lambda$. 무늬의 각도 한계 $\sin\theta \le 1$ → $m \le d/\lambda$; $d$ 작거나 $\lambda$ 크면 무늬 간격 넓어짐. 한 슬릿에 두께 $L$ 물질을 덮으면 위상차(파장 수) $L(n-1)/\lambda$만큼 무늬 이동. 간섭계 거울을 $\lambda/2$ 옮길 때마다 무늬 하나 이동. 투과광은 반사광과 보강·상쇄가 반대. 쐐기 막은 두께가 변하며 밝은·어두운 띠가 번갈아 나타남 [C p8–10, p18, p35, D p3]

## Ch36 회절

### 1. 핵심 개념
- **회절**: 파장과 비슷한 크기의 모서리·장애물·구멍을 만난 파동이 퍼지며 간섭. 단일 슬릿 무늬 = 중앙 극대 + 극소로 나뉜 옆 극대들 [D p17]
- **레일리 기준(Rayleigh's criterion)**: 한 물체의 중앙 극대가 다른 물체의 첫째 극소에 놓이면 겨우 분해 [E p5]
- **회절 격자(diffraction grating)**: 이중 슬릿과 비슷하나 슬릿(눈금, rulings) 수 $N$이 매우 많음(mm당 수천) [E p21]
- **선(line)**: 격자 무늬의 날카로운 밝은 극대 / **차수(order number)** $m$: $d\sin\theta = m\lambda$의 정수, 중앙선 $m=0$ [E p18, p21]
- **선의 반폭(half-width)** $\Delta\theta_{hw}$: 선 중심에서 어두워지는 곳까지 각. $N$개 광선이 서로 상쇄 [E p22]
- **분산(dispersion)** $D$: 파장 차 $\Delta\lambda$인 두 선의 각 간격 척도 / **분해능(resolving power)** $R$: 가까운 두 파장을 구별하는 능력 [E p28, p30]
- **X선**: 파장 ~1 Å = $10^{-10}$ m 전자기 복사. 가열 필라멘트의 전자를 전위차 $V$로 가속해 금속 표적에 충돌시켜 발생 [E p36]
- **단위 세포(unit cell)**: 격자를 반복해 채우는 기본 단위(여담: 삼각 격자, 관례 단위 세포) [E p37–38]
- **반사면(결정면)**: X선을 반사하는 것처럼 보이는 평행한 원자면 가족, 간격 = 면간 거리 $d$ [E p38]

### 2. 공식
| 공식 | 기호·뜻 | 사용 조건 |
|---|---|---|
| $a\sin\theta = m\lambda$ | $a$: 슬릿 폭, $m=1,2,3,\dots$ | 단일 슬릿 극소 [D p19] |
| $I(\theta) = I_m\left(\dfrac{\sin\alpha}{\alpha}\right)^2$, $\alpha = \dfrac{\pi a}{\lambda}\sin\theta$ | $I_m$: 중앙 세기, $\alpha = \phi/2$ | 단일 슬릿 세기 [D p28] |
| $\sin\theta = 1.22\dfrac{\lambda}{d}$ | $d$: 구멍 지름 | 원형 구멍 첫째 극소 [D p35] |
| $\theta_R = 1.22\dfrac{\lambda}{d}$ (rad) | | 레일리 기준, 작은 각 [E p5] |
| $I = I_m(\cos^2\beta)\left(\dfrac{\sin\alpha}{\alpha}\right)^2$, $\beta = \dfrac{\pi d}{\lambda}\sin\theta$ | $d$: 슬릿 간격, $a$: 폭 | 이중 슬릿 회절 [E p15] |
| $d\sin\theta = m\lambda$ | $m=0,1,2,\dots$ | 격자의 선(극대) [E p21] |
| $\Delta\theta_{hw} = \dfrac{\lambda}{Nd\cos\theta}$ | 중앙선은 $\lambda/Nd$ | 격자 반폭 [E p22, p24] |
| $D = \dfrac{\Delta\theta}{\Delta\lambda} = \dfrac{m}{d\cos\theta}$ | 단위 °/m, rad/m | 격자 분산 [E p28] |
| $R = \dfrac{\lambda_{avg}}{\Delta\lambda} = Nm$ | | 격자 분해능 [E p30] |
| $2d\sin\theta = m\lambda$ | $m=1,2,3,\dots$, θ는 면에서 잰 각 | 브래그 법칙 [E p39] |

### 3. 원리·결론
- 단일 슬릿 극소 = $a\sin\theta = m\lambda$인 곳(중앙 극대 양옆으로 첫째·둘째 극소…) [D p19]
- 페이저: 중앙(θ=0) 모두 같은 위상, $E_\theta = E_m$ 최대 / 첫째 극소: 사슬이 원으로 닫힘(양끝 위상차 2π, 경로차 λ), $E_\theta=0$ / 첫째 옆 극대: 사슬이 다시 감기며 코일이 줄어듦 [D p23–25]
- 슬릿이 넓을수록 중앙 극대가 좁음. $a \gg \lambda$면 옆 극대가 사라져 회절이 안 보임 [D p29]
- 원형 구멍: 중앙 극대 + 동심원 고리, 옆 극대는 훨씬 약함. 1.22는 원형 모양 때문 [D p35]
- 분해능 ∝ $1/\theta_R$ ∝ $d/\lambda$: 구멍이 크고 파장이 짧을수록 잘 구별 [E p5]
- 이중 슬릿 회절: $\cos^2\beta$ = 간섭 인자(간격 $d$), $(\sin\alpha/\alpha)^2$ = 회절 인자(폭 $a$). 회절 무늬가 포락선, 회절 극소가 일부 간섭 무늬를 없앰 [E p13, p16]
- 격자 선은 이중 슬릿 무늬보다 훨씬 좁고 날카로움. $N$ 클수록 선이 좁아 파장 구별 우수 [E p24]
- 분산: $d$ 작고 $m$ 클수록 큼, $N$과 무관 / 분해능: $N$ 클수록 큼 [E p28, p30]
- 같은 $d$ → 같은 $D$(격자 A·B), 같은 $N$·$m$ → 같은 $R$(A·C) [E p31–32]
- X선은 평행한 면 가족에서 반사되는 것처럼 회절, 인접 면 경로차 $2d\sin\theta$. 결정 방향이 바뀌면 다른 면 가족이 반사 [E p38]

### 4. 문제 유형별 접근
- 단일 슬릿 극소 위치: $a\sin\theta = m\lambda$ → $y = D\tan\theta$
- 단일 슬릿 세기: $\theta$ → $\alpha = \pi a\sin\theta/\lambda$ → $I/I_m = (\sin\alpha/\alpha)^2$
- 분해 가능 여부: $\theta_R = 1.22\lambda/d$와 두 물체의 각 간격(간격 ÷ 거리 $L$) 비교, 크면 분해
- 이중 슬릿 회절 무늬 개수: 회절 첫째 극소 $a\sin\theta=\lambda$와 간섭 극대 $d\sin\theta=m\lambda$ 비교 → 중앙 봉우리 안 $m < d/a$
- 격자: $d$ = 1/(단위 길이당 눈금 수) → $d\sin\theta = m\lambda$, 최대 차수는 $\sin\theta \le 1$에서 $m \le d/\lambda$
- 브래그: 단위 세포 그림에서 면간 거리 $d$ → $2d\sin\theta = m\lambda$

### 5. 실수 포인트
- 단일 슬릿 극소 $a\sin\theta = m\lambda$는 $m=1$부터. 이중 슬릿 **밝은** 무늬 식과 모양만 같음 [D p19, C p22]
- 원형 구멍·레일리 식의 $d$는 지름, 이중 슬릿·격자의 $d$는 간격, 브래그의 $d$는 면간 거리
- 브래그 각 $\theta$는 결정면에서 잰 각(광학처럼 법선 기준 아님) [E p38]
- 동공이 작아지면(밝은 곳) $\theta_R$ 커져 분해능 나빠짐 [E p8]

> 보충(LO만 있음): 프레넬 밝은 점 = 작은 원판 그림자 중심에 회절로 생기는 밝은 점 [D p14]. 원형 구멍 극소의 화면 위치 $y = D\tan\theta$, 두 물체 각 간격 ≈ 간격/$L$ [D p32–33]. 격자 분광기: 격자로 광원의 빛을 파장별 선으로 나눠 각도를 재어 파장 측정 [E p20].
