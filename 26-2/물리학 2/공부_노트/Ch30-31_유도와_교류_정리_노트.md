## Ch30 유도와 인덕턴스

> **30.1~30.5절 원본 강의 누락, 요약·복습 슬라이드 기준** (A p2–5, B p60–67, A p36–42 요약)

### 1. 핵심 개념
- **자기 선속(magnetic flux)** $\Phi_B$: 면을 지나는 자기장의 양. $\Phi_B=\int \vec{B}\cdot d\vec{A}$ [A p36]
- **패러데이 법칙(Faraday's law)**: 유도 emf 크기 = 고리를 지나는 자기 선속의 시간 변화율 [A p2]
- **렌츠 법칙(Lenz's law)**: 유도 전류는 자신이 만든 자기장이 **선속 변화를 방해**하는 방향. 패러데이 식의 음의 부호 [A p2, p38]
- **인덕터(inductor)**: 정해진 영역에 알려진 자기장을 만드는 장치(코일·솔레노이드·토로이드). **인덕턴스(inductance)** $L$ = 전류당 선속 연결 [B p63]
- **자체 유도(self-induction)**: 코일의 전류 변화가 그 코일 자신에 emf(자체 유도 emf)를 만드는 현상. 패러데이 법칙을 똑같이 따름 [A p3–4]
- **상호 유도(mutual induction)**: 가까운 두 코일 중 한쪽 전류 변화가 다른 쪽에 emf를 만드는 현상(코일 1개뿐인 자체 유도와 구분). Fig 30.9.1: 코일 1의 가변저항으로 $i_1$ 변화 → 전지 없는 코일 2의 계기에 전류 [A p32–33]
- **상호 인덕턴스(mutual inductance)** $M_{21}$: 코일 1 전류당 코일 2의 선속 연결 [A p34]

| (복습) $R\dfrac{dq}{dt}+\dfrac{q}{C}=\varepsilon$, $q=C\varepsilon(1-e^{-t/RC})$ | $q_0=C\varepsilon$, $\tau=RC$ | RC 충전, $t=0$에서 $q=0$ [A p10–11] |

### 3. 원리·결론
- $\varepsilon_L$ 크기는 **전류 크기와 무관**, 전류 **변화율**에만 비례 [A p5]
- RL에서 스위치를 닫으면 $\varepsilon_L$이 전류 증가를 방해 → 전지 emf와 반대 극성. 전류는 일정한 $\varepsilon$와 변하는 $\varepsilon_L$의 차이에 반응 [A p12]
- 전지를 빼도 전류는 즉시 0이 되지 않고 지수적으로 감소 [A p15]
- $V_R$: 0 → $\varepsilon$ 증가, $V_L$: $\varepsilon$ → 0 감소 (Fig 30.6.3) [A p14]
- 초기 조건: 인덕터 전류 0, $|\varepsilon_L|=\varepsilon$ / 최종 조건: 전류 $\varepsilon/R$, $\varepsilon_L=0$ [A p13–14]
- RL 회로 에너지 보존: 전원 공급 = 자기장 저장 + 저항 열 → 인덕터 에너지 $U_B=\frac12Li^2$ [A p18–19]
- 전기 쪽 대응: $U_E=q^2/2C$, $u_E=\frac12\varepsilon_0E^2$ [A p19, p29]
- 모든 자기장에는 에너지가 있음, 밀도 $u_B=B^2/2\mu_0$ [A p26–29]
- 한 코일의 유도 emf는 **다른** 코일 전류 변화율에 비례. $M_{12}=M_{21}$(원본은 이유를 질문으로만 제시) [A p35]

### 4. 문제 유형별 접근
- 유도 emf: $\Phi_B$ 식 세우기 → 시간 미분 → 크기, 방향은 렌츠 법칙
- 움직이는 고리: $\varepsilon=BLv$ → $i=\varepsilon/R$ → $F=iLB$
- 솔레노이드 $L$: $L/l=\mu_0n^2A$ 사용
- RL 시간 문제: 증가/감소 판별 → $\tau_L=L/R$ → $i(t)$에 대입 → $V_R=iR$, $V_L=\varepsilon-V_R$(증가 시)
- 에너지 비율 문제: $U_B\propto i^2$ → $U_B$ 비율을 $i$ 비율로($\sqrt{\ }$) → $e^{-t/\tau_L}$ 풀기 → $\ln$
- 에너지 밀도: $u_B=B^2/2\mu_0$ × 부피
- 상호 유도: $M=N_2\Phi_{21}/i_1$ → $\varepsilon_2=-M\,di_1/dt$

### 5. 실수 포인트
- $\tau_L=L/R$ (RC의 $RC$와 혼동 금지)
- $U_B$가 절반일 때 전류는 절반이 아니라 $1/\sqrt2$배
- 전류 감소식은 전지가 **빠진** 회로($\varepsilon=0$)
- $L/l=\mu_0n^2A$의 $n$은 총 감은 수가 아니라 **단위 길이당** 감은 수

## Ch31 전자기 진동과 교류

### 1. 핵심 개념
- **전자기 진동(electromagnetic oscillation)**: LC 회로에서 전하·전류·전위차가 지수 감소 대신 사인형으로 진동, 축전기 전기장과 인덕터 자기장 사이 에너지가 오감 [C p4]
- **LC 한 주기 8단계**: (a) 최대 전하·전류 0 → (c) 방전 끝·전류 최대 → (e) 반대 극성 최대 전하 → (g) 반대 방향 전류 최대 → (a). 사이 (b)(d)(f)(h)는 충·방전 중 [C p5–6]
- **감쇠(damping)**: RLC에서 에너지가 저항의 열로 빠져 진폭이 계속 줄어듦 [C p20]
- **교류(alternating current, ac)**: 방향·크기가 사인형으로 바뀌는 전류. 직류는 방향 일정 [C p30–31]
- **구동 각진동수(driving angular frequency)** $\omega_d$: 외부 emf(발전기 회전 각속력)의 각진동수. **고유 각진동수(natural angular frequency)** $\omega=1/\sqrt{LC}$ [C p31, p33]
- **자유 진동** = 고유 $\omega$로 진동 / **강제(구동) 진동** = 외부 교류 emf, 고유 $\omega$와 무관하게 항상 $\omega_d$로 진동 [C p33]
- **페이저(phasor)**: 원점 중심 반시계 회전 화살표. 각속력 $\omega_d$, 길이 = 진폭, 수직축 사영 = 순간값, 회전각 = 위상 [C p37]
- **리액턴스(reactance)** $X_C$, $X_L$: C, L의 "교류 저항". $\omega_d$에 따라 달라짐 [C p41, p45]
- **임피던스(impedance)** $Z$: 직렬 RLC 전체의 "교류 저항" [D p12]
- **공명(resonance)**: $\omega_d=\omega$일 때 전류 진폭 최대 [D p14]
- **rms 값(root-mean-square)**: 진폭$/\sqrt2$ [D p20]. **역률(power factor)** $\cos\phi$ [D p21]
- **변압기(transformer)**: 철심에 감은 1차(primary, 발전기 쪽)·2차(secondary, 부하 쪽) 코일. 움직이는 부분 없음, 패러데이 법칙으로 작동, 직류용 대응물 없음 [D p26]
- **등가 저항(equivalent resistance)** $R_{eq}$: 발전기가 "보는" 부하 저항 [D p29]

| $U_E=\dfrac{Q^2}{2C}\cos^2(\omega t+\phi)$, $U_B=\dfrac{Q^2}{2C}\sin^2(\omega t+\phi)$ | 합 $=Q^2/2C$ | 이상 LC [C p15] |

| $\varepsilon_m^2=V_R^2+(V_L-V_C)^2$ | | 직렬 RLC 진폭 [D p11] |
| $\tan\phi=\dfrac{V_L-V_C}{V_R}=\dfrac{X_L-X_C}{R}$ | | 직렬 RLC [D p13] |
| $\omega_d=\omega=\dfrac{1}{\sqrt{LC}}$ | | 공명 [D p14] |
| $P=i^2R=I^2R\sin^2(\omega_d t-\phi)$ | 한 주기 평균 $\overline{\sin\theta}=0$, $\overline{\sin^2\theta}=\frac12$ | 순간 전력 [D p18–19] |
| $I_{rms}=\dfrac{I}{\sqrt2}$, $V_{rms}=\dfrac{V}{\sqrt2}$, $\varepsilon_{rms}=\dfrac{\varepsilon_m}{\sqrt2}$, $I_{rms}=\dfrac{\varepsilon_{rms}}{Z}$ | | 사인형 교류 [D p20–21] |

| $R_{eq}=\left(\dfrac{N_p}{N_s}\right)^2R$ | | 발전기 쪽에서 본 부하 [D p29] |

**세 기본 회로 (표 31.3.1)** [D p4]

| 소자 | 리액턴스 | 전류 위상 | $\phi$ | 진폭 관계 |
|---|---|---|---|---|
| R | $R$ | $v_R$와 동위상 | $0°$ | $V_R=I_RR$ |

| 조건 | 성격 | $\phi$ |

| $X_L<X_C$ | 용량성 우세 | $<0$ (전류가 emf보다 앞섬) |
| $X_L=X_C$ | 공명($Z=R$ 최소, $I$ 최대) | $0$ (동위상) |

### 3. 원리·결론
- 대응(표 31.1.1): $q\leftrightarrow x$, $1/C\leftrightarrow k$, $i\leftrightarrow v$, $L\leftrightarrow m$. 축전기 ≈ 용수철, 인덕터 ≈ 블록 [C p8–9]
- 이상 LC: 저항 0 → 열 손실 없음 → $U=U_B+U_E$ 일정($dU/dt=0$) [C p11]
- $U_E$, $U_B$ 최댓값 모두 $Q^2/2C$, 한쪽 최대일 때 다른 쪽 0 [C p16]
- 감쇠: 진폭 $Qe^{-Rt/2L}$ 지수 감소, $\omega'<\omega$ 항상. $R\to0$이면 $\omega'\to\omega$ (`보충`) [C p23]
- 교류 장점: 변하는 자기장 → 패러데이 법칙 → 변압기로 전압 승·강압. 회전 기계(발전기·전동기)에 적합 [C p30]
- $\phi$는 전류가 emf에 대해 밀린 위상(그래프 평행 이동, $y=(x-x_0)^2$와 같은 원리) [C p32]
- 암기법 "ELI positively is the ICE man": L에서 E(전압)가 I보다 먼저, C에서 I가 E보다 먼저 (`보충`: 원본은 학습 목표에 이름만) [C p29]
- 직렬 RLC: 전류는 모든 소자에서 같음. 페이저 $V_R$는 $I$와 같은 각, $V_L$은 $90°$ 앞, $V_C$는 $90°$ 뒤. $\varepsilon_m$ = 세 페이저 벡터 합 [D p10–11]
- 공명 곡선($I$ vs $\omega_d/\omega$): 봉우리 $\omega_d/\omega=1$, 왼쪽($\omega_d<\omega$) 용량성, 오른쪽 유도성, $R$이 커지면 봉우리가 낮고 넓어짐 (`보충`: 원본은 학습 목표만)
- 발전기 에너지: 일부 C 전기장·L 자기장에 저장, 일부 R에서 열 [D p18]. 평균 전력 = 저항의 열 발생률 [D p21]
- 평균 전력은 R만 $I_{rms}^2R$, 이상적 L·C는 0. 정상 상태 평균 저장 에너지 일정 → 발전기 에너지는 모두 열 (`보충`)
- 변압기: 한 바퀴당 emf $d\Phi_B/dt$가 1차·2차에서 같음, 철심이 선속을 강화해 2차로 전달 [D p27]. 손실 없음 → 전력 보존 [D p28]
- $N_s>N_p$ 승압(전류↓), $N_s<N_p$ 강압(전류↑) (`보충`: $V_s$ 식의 결과)
- 송전: 같은 전력 $IV$를 높은 전압·낮은 전류로 보내면 선로 손실 $I^2R$ 감소 → 송전 쪽 승압, 사용 쪽 강압 [D p26] (손실식 `보충`)
- 임피던스 정합: 권선비로 $R_{eq}$를 조절해 발전기 쪽에 맞춤 (`보충`)

### 4. 문제 유형별 접근
- LC 에너지 나눔: 매 순간 $U_E+U_B=U_{max}$ [C p14]. 전압은 고리 규칙상 $\lvert v_L\rvert=v_C$ (C p14의 $V_C+V_L=V_{max}$는 오류 의심)
- LC 시간식: $\omega=1/\sqrt{LC}$ → $q(t)$ → 미분해 $i(t)$, $I=\omega Q$ → $U_E$, $U_B$
- 감쇠: $\omega'=\sqrt{\omega^2-(R/2L)^2}$, 진폭 비 $e^{-Rt/2L}$, 에너지 비 $e^{-Rt/L}$
- 단일 소자 교류: $X$ 계산 → $I=V/X$ → 위상은 표 31.3.1
- 직렬 RLC: $X_L$, $X_C$ → $Z$ → $I=\varepsilon_m/Z$ → $\tan\phi$ → 유도성/용량성 판정
- 공명: $\omega_d=1/\sqrt{LC}$, 이때 $I=\varepsilon_m/R$
- 전력: rms 변환($\div\sqrt2$) → $I_{rms}=\varepsilon_{rms}/Z$ → $P_{avg}=I_{rms}^2R$ 또는 $\varepsilon_{rms}I_{rms}\cos\phi$
- 변압기: 전압은 $N$에 비례, 전류는 $N$에 반비례 → $R_{eq}=(N_p/N_s)^2R$

### 5. 실수 포인트
- 축전기 $\phi=-90°$(전류 앞섬 = 먼저 최대), 인덕터 $\phi=+90°$(전류 뒤짐 = 나중에 최대) — 부호 반대로 쓰기 쉬움
- $X_C=1/\omega_dC$는 진동수가 클수록 **작아지고**, $X_L=\omega_dL$은 **커짐**
- $\varepsilon_m\neq V_R+V_L+V_C$(진폭은 벡터 합). 순간값만 $\varepsilon=v_R+v_C+v_L$
- 감쇠에서 전하 진폭은 $e^{-Rt/2L}$, 에너지는 $e^{-Rt/L}$ (지수 2배)
- 강제 진동 진동수는 $\omega_d$, 고유 $\omega$가 아님
- $P_{avg}=I_{rms}^2R$에서 $R$ 자리에 $Z$를 넣지 않음. $\cos\phi$는 $\phi$ 부호와 무관
- 원본 오기: C p41(→ 축전기), C p46·D p3(→ 인덕터), D p37 $R_{ep}$(→ $R_{eq}$)
