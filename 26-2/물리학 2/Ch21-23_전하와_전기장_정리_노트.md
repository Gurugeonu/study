## Ch21 쿨롱의 법칙

### 1. 핵심 개념
- **전기적 중성 / 대전**: 양·음전하 양이 같으면 중성, 한쪽이 남으면 그만큼이 **초과 전하(excess charge)** [A p11]
- **물질 분류(전하 이동성)** [A p19]

| 종류 | 특징 | 예 |
|---|---|---|
| 도체(conductor) | 많은 전자가 자유롭게 이동 | 금속 |
| 부도체·절연체(insulator) | 전하가 이동 못 함 | 고무, 플라스틱, 유리 |
| 반도체(semiconductor) | 도체와 절연체의 중간 | 규소, 저마늄 |
| 초전도체(superconductor) | 방해 없이 이동하는 완전 도체 | — |

- **원자 속 입자**: 양성자 $+e$, 전자 $-e$, 중성자 $0$. 양성자·중성자는 핵에 묶여 움직이지 않음 [A p20, p32]
- **전도 전자(conduction electron)**: 도체 고체에서 가장 바깥 전자가 떨어져 나와 자유 이동(뒤에 양이온). 부도체엔 거의 없음. 도체의 대전·유도 = 전도 전자의 이동 [A p20]
- **전기적 고립(electrically isolated)**: 부도체 실로 매다는 등 주변과 전하 교환 차단 [A p17] / **접지(grounding)**: 물체를 지구에 연결해 전하가 드나들게 함 (보충)
- **유도 전하(induced charge)**: 대전체 접근 → 도체 속 전도 전자 재배치 → 가까운 쪽에 반대 부호 [A p21–22]
- **전류(current)**: 한 점을 지나는 전하의 시간당 비율, $i = dq/dt$ (식은 보충) [A p15]
- **전하 양자화(quantization)**: 전하는 불연속 값만 가능 [A p30–31]
- **질량수·원자번호** (보충): 원자번호 $Z$ = 양성자 수(중성 원자면 전자 수와 같음), 질량수 $A$ = 양성자 수 + 중성자 수 [A p35]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $F = \dfrac{1}{4\pi\varepsilon_0}\dfrac{\lvert q_1\rvert\lvert q_2\rvert}{r^2}$ | $\varepsilon_0 = 8.85\times10^{-12}\ \mathrm{C^2/N\,m^2}$ (유전율 상수) | 점입자, 서로 정지(또는 느린 운동) [A p23] |
| $k = \dfrac{1}{4\pi\varepsilon_0} = 8.99\times10^{9}\ \mathrm{N\,m^2/C^2}$ | 정전기 상수(쿨롱 상수) | [A p23] |
| $\vec F = k\dfrac{q_1q_2}{r^2}\hat r$ | $\hat r$: 입자 2에서 멀어지는 방향(입자 1 위치) 단위벡터 | 부호 포함 대입 [A p24] |
| $\vec F_{1,\mathrm{net}} = \vec F_{12}+\vec F_{13}+\cdots+\vec F_{1n}$ | 중첩 | 벡터 합 [A p26] |
| $q = ne,\ n = \pm1,\pm2,\dots$ | $e = 1.602\times10^{-19}\ \mathrm C$ (기본 전하) | 모든 검출 가능한 전하 [A p30] |
| $e^-+e^+\to\gamma+\gamma$ / $\gamma\to e^-+e^+$ | 쌍소멸 / 쌍생성 | 전하 보존 [A p36] |

### 3. 원리·결론
- 같은 부호 척력, 다른 부호 인력 [A p18]
- 정전기력은 두 입자를 잇는 직선 위: 다른 부호면 상대 쪽, 같은 부호면 반대쪽 [A p25]
- 쿨롱 법칙은 점입자(또는 점으로 볼 수 있는 물체)에만 적용 [A p13]
- 크기는 전하 곱에 비례, 거리 제곱에 반비례 — 중력과 같은 $1/r^2$ 꼴. 단, 중력은 인력이라 $\vec F = -G\frac{m_1m_2}{r^2}\hat r$ (원본의 $+$는 오기) [A p24, p39]
- 전자기력: 광자 매개, 세기 1/137, $1/r^2$, 범위 ∞ (중력 $5.9\times10^{-39}$, 약력·강력은 단거리) [A p10]
- **껍질 정리 1**: 균일 대전 껍질 **밖** 입자 → 껍질 전하가 중심의 점전하인 것처럼 작용 [A p26]
- **껍질 정리 2**: 균일 대전 껍질 **안** 입자 → 껍질에 의한 알짜 힘 0. 근거: $1/r^2$ 법칙 + 구대칭 [A p26]
- 구형 도체의 초과 전하 → 바깥 표면에 균일 분포 [A p14]
- 같은 구형 도체 둘 접촉(도선 연결) → 초과 전하 똑같이 나눔 [A p14]
- 부도체 → 내부 포함 임의의 전하 분포 가능 [A p14]
- 전하 양자화: $+10e$, $-6e$ 가능, $3.57e$ 불가. $e$가 매우 작아(100 W 전구에 초당 약 $10^{19}$개 출입) 거시 현상에선 알갱이성 안 보임 (특성 길이·에너지 규모) [A p31]
- 전하 보존: 고립계의 알짜 전하 불변. 쌍소멸·쌍생성의 두 입자는 크기 같고 부호 반대 [A p36]
- 거품 상자 사진: 중성 감마선은 흔적 없음, 생성된 전자·양전자는 흔적 남김, 자기장 때문에 휨 [A p37]

### 4. 문제 유형별 접근
- 한 입자의 알짜 정전기력: 각 쌍마다 크기($k|q_1||q_2|/r^2$) → 방향(인력/척력) → 자유물체도(꼬리를 그 입자에) → 성분별 벡터 합
- 같은 도체 구 접촉: (전하 합) ÷ 2를 각각에 배분
- 껍질이 끼면: 밖의 입자 → 중심 점전하로 대체, 안의 입자 → 껍질 힘 0
- 유도 문제: 전도 전자가 어느 쪽으로 밀리는지 → 가까운 쪽 부호 → 인력 방향

### 5. 실수 포인트
- 크기 식에는 절댓값, 방향은 그림으로 따로 결정 (벡터 식은 부호 포함)
- 알짜 힘은 **벡터 합**, 크기만 더하지 않기
- 중성 도체도 대전체에 **끌린다**(유도)

## Ch22 전기장

### 1. 핵심 개념
- **전기장(electric field)** $\vec E$: 대전 입자가 주변 모든 점에 만드는 벡터량. 양의 시험 전하 $q_0$이 받는 단위 전하당 힘 [B p4, p8]
- 원격 작용 해석: 입자 2가 (진공에서도) 공간에 장을 만들고, 입자 1은 자기 위치의 장에 반응 [B p7]
- 벡터장(cf. 스칼라장: 온도장, 압력장). 장은 시험 전하와 무관하게 존재, 시험 전하를 옮겨 다니며 분포 측정 [B p9]
- **전기력선(field line)**: 접선 = $\vec E$ 방향, 밀도 ∝ $E$. 양전하에서 시작, 음전하에서 끝 [B p10–11]
- **전기 쌍극자(electric dipole)**: 크기 $q$ 같고 부호 반대인 두 입자가 작은 거리 $d$만큼 떨어진 것. **쌍극자 모멘트** $\vec p = qd\,\hat z$ (−에서 +로) [B p25, p29]
- **전하 밀도**: 선 $\lambda$ [C/m], 면 $\sigma$ [C/m²], 부피 $\rho$ [C/m³] (균일: 전하 ÷ 길이·넓이·부피) [B p31]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $\vec E = \vec F/q_0$ | N/C | 양의 시험 전하 [B p8] |
| $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{\lvert q\rvert}{r^2}$ | $r$: 입자까지 거리 | 점전하만 [B p18] |
| $\vec E = \vec E_1+\vec E_2+\cdots+\vec E_n$ | 중첩 원리 | 벡터 합 [B p19] |
| $E = \dfrac{1}{2\pi\varepsilon_0}\dfrac{qd}{z^3} = \dfrac{1}{2\pi\varepsilon_0}\dfrac{p}{z^3}$ | $z$: 쌍극자 **중심**까지 거리 | 쌍극자 축 위, $z\gg d$ [B p27] |
| $\vec E = 2k\vec p/z^3$ / $\vec E' = -k\vec p/z^3$ | | 축 위 / 수직 이등분선 위, 먼 점 [B p29] |
| $\vec E = k\dfrac{3(\vec p\cdot\hat r)\hat r-\vec p}{r^3} = -\nabla\!\left[k\dfrac{\vec p\cdot\hat r}{r^2}\right]$ | 일반 쌍극자 장 (cf. $\vec E = k\frac{Q}{r^2}\hat r = -\nabla[kQ/r]$) | 먼 점, 다중극 전개 [B p29] |
| $E = \dfrac{qz}{4\pi\varepsilon_0(z^2+R^2)^{3/2}}$ | $R$: 고리 반지름 | 균일 대전 고리, 중심축 위 [B p39] |
| $\vec E = k\dfrac{2\lambda}{r}\hat x$ | $r$: 직선까지 수직 거리 | 무한 직선 전하 [B p41] |
| $E = \dfrac{\sigma}{2\varepsilon_0}\left(1-\dfrac{z}{\sqrt{z^2+R^2}}\right)$ | $R$: 원판 반지름 | 균일 대전 원판, 중심축 위. 방향: 양전하면 원판에서 멀어짐, 음전하면 원판을 향함 [C p3, p7] |
| $E = \dfrac{\sigma}{2\varepsilon_0}$ | z와 무관(균일장) | 무한 판($R\to\infty$) [C p8] |
| $\vec F = q\vec E$ | | 외부 장 속 점전하 [C p12] |
| $\vec\tau = \vec p\times\vec E$, $\tau = pE\sin\theta$ | $\theta$: $\vec p$와 $\vec E$ 사이 각 | 균일 외부 장 [C p23–24] |
| $U = -\vec p\cdot\vec E = -pE\cos\theta$ | 기준 $U(90^\circ) = 0$ | 균일 외부 장 [C p27] |

### 3. 원리·결론
- 장 방향: 양전하 → 바깥, 음전하 → 안쪽(전하를 향함) [B p18]
- $q>0$이면 $\vec F\parallel\vec E$, $q<0$이면 $\vec F$는 $\vec E$ 반대 [C p12]
- 큰 균일 대전 판: 판에 수직인 평행 전기력선 / 점전하: 방사형 / 같은 양전하 둘: 사이가 비고 서로 밀어내는 모양 [B p10–14]
- 쌍극자 축 위: $+q$ 바깥쪽은 $+q$ 장, $-q$ 바깥쪽은 $-q$ 장이 우세 → 둘 다 $\vec p$ 방향. 두 전하 사이는 $-\vec p$ 방향 [B p28]
- 쌍극자 장 $\propto 1/z^3$ → 점전하($1/r^2$)보다 빨리 감소 [B p23]
- 연속 분포: 대칭으로 상쇄되는 성분 먼저 제거 → 고리·원판 축 위에서는 축 방향 성분만 남음 [B p33–37]
- 고리: $z\gg R$이면 $q/(4\pi\varepsilon_0z^2)$ (점전하처럼), $z=0$이면 $E=0$ [B p40]
- 원판: $z\to0$이면 $\sigma/2\varepsilon_0$, $z\to\infty$이면 $q/(4\pi\varepsilon_0z^2)$ ($q = \sigma\pi R^2$) [C p8]
- 균일 장 속 쌍극자: 양 끝 힘 $\pm q\vec E$ → **알짜 힘 0**, 토크가 $\vec p$를 $\vec E$ 쪽으로 정렬시킴. 그림 22.7.2에서 $\vec\tau$는 지면 안쪽(⊗) [C p23–24]
- 퍼텐셜 에너지: 정렬($\theta = 0$, $\vec\tau = 0$) 때 최소 $-pE$, 반대($180^\circ$) 때 최대 $+pE$. 다른 방향으로 돌리려면 외부 일 필요 [C p25]
- 토크 크기: $\theta = 90^\circ$에서 최대 $pE$, $0^\circ$·$180^\circ$에서 0 [C p20]
- 밀리컨 기름방울 실험: 기본 전하 $e = 1.60\times10^{-19}$ C 측정 [C p13]
  - 대전 방울이 판 P1 구멍으로 방 C에 들어옴
  - 스위치 S로 장을 켜고 끔 → 방울 운동 조종
  - 현미경으로 운동 시간 측정
- 잉크젯 프린터: 발생기 G의 방울이 대전 장치 C에서 전하를 받고, 편향판의 장이 휘게 함. 컴퓨터 신호가 전하량 → 착지 위치 조절 [C p15]

### 4. 문제 유형별 접근
- 점전하 여러 개의 합성 장: 각 $\vec E_i$ 크기·방향(양: 바깥, 음: 안쪽, 꼬리는 그 점에) → 성분 분해 → 벡터 합
- 쌍극자 축 위 먼 점의 장: $E = \frac{1}{2\pi\varepsilon_0}\frac{p}{z^3}$ 바로 적용 ($z$는 중심 기준, $z\gg d$), 방향은 축 바깥이면 $\vec p$ 방향
- 연속 전하 분포: $dq$($\lambda ds$, $\sigma dA$) → $dE$(점전하 식) → 대칭으로 상쇄 성분 제거 → 남은 성분 적분
- 원판: 반지름 $r$, 폭 $dr$인 고리로 쪼개 $dq = \sigma(2\pi r\,dr)$ → 고리 식 → $0\sim R$ 적분
- 장 속 대전 입자의 평형: 중력과 전기력의 크기·방향 균형 조건 → 장 방향은 전하 부호로 결정
- 장 속 대전 입자의 운동: $\vec a = q\vec E/m$ → 장 방향은 등가속, 수직 방향은 등속 (포물선 운동과 같은 방식)
- 쌍극자 토크·에너지: 크기-각 표기($pE\sin\theta$, $-pE\cos\theta$) 또는 단위벡터 표기(외적·내적 직접 계산)

### 5. 실수 포인트
- 점전하 식을 확장 물체에 그대로 쓰지 않기 [B p17]
- 쌍극자 식의 $z$는 중심까지 거리, $z\gg d$일 때만
- 고리·원판 식은 **중심축 위**에서만 성립
- $U = -\vec p\cdot\vec E$의 음부호: 정렬 상태가 최저 에너지
- 균일 장에서 쌍극자 알짜 힘은 0 (토크만 있음)

## Ch23 가우스 법칙

### 1. 핵심 개념
- **가우스 법칙(Gauss' law)**: 닫힌 곡면(**가우스 면**, 실제 또는 가상) 위 전기장과 그 면이 둘러싼 알짜 전하 $q_\mathrm{enc}$의 관계 [C p39]
- **전기 선속(electric flux)** $\Phi$: 면을 뚫고 지나가는 전기장의 양 (면에 평행한 장은 0) [C p36]
- **넓이 벡터(area vector)** $d\vec A$: 면 조각에 수직, 크기 = 조각 넓이. 닫힌 면에서는 **바깥** 방향. 임의 곡면은 평평한 작은 조각으로 분할 [C p40, p46]
- **표면 전하 밀도** $\sigma$ = 전하 ÷ 넓이(균일 분포) [D p11]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $d\Phi = \vec E\cdot d\vec A$, $\Delta\Phi = (E\cos\theta)\Delta A$ | $\theta$: $\vec E$와 넓이 벡터 사이 각 | 작은 조각 [C p40–41] |
| $\Phi = \int\vec E\cdot d\vec A$ / $\Phi = \oint\vec E\cdot d\vec A$ | 총 선속 / 닫힌 면 알짜 선속, $\mathrm{N\,m^2/C}$ | [C p42] |
| $\varepsilon_0\Phi = q_\mathrm{enc}$, $\varepsilon_0\oint\vec E\cdot d\vec A = q_\mathrm{enc}$ | | 모든 닫힌 면 [C p51] |
| $E = \dfrac{\sigma}{\varepsilon_0}$ | 면에 수직 | 도체 표면 바로 바깥 [D p16] |
| $E = \dfrac{\lambda}{2\pi\varepsilon_0 r}$ | $r$: 축까지 거리 | 무한 직선(원통) 전하 바깥 [D p22] |
| $E = \dfrac{\rho r}{2\varepsilon_0}$ (보충) | | 균일 $\rho$ 원통 부도체 내부 [D p20] |
| $E = \dfrac{\sigma}{2\varepsilon_0}$ | 방향: 양전하면 판에서 멀어짐, 음전하면 판을 향함 | 무한 부도체 판 [D p24, p27] |
| $E = \dfrac{\sigma_1}{\varepsilon_0}$, $E_\mathrm{in} = 0$ | $\sigma_1$: 각 면의 표면 전하 밀도 | 얇은 무한 도체 판(양면 대전) 바깥 / 판 속 [D p29] |
| $E = \dfrac{2\sigma_1}{\varepsilon_0} = \dfrac{\sigma}{\varepsilon_0}$ | $\sigma = 2\sigma_1$ (안쪽 면) | 평행 도체판 사이 [D p31] |
| $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r^2}$ ($r\ge R$), $E = 0$ ($r<R$) | | 균일 대전 구 껍질 [D p36] |
| $E = \left(\dfrac{q}{4\pi\varepsilon_0R^3}\right)r$ ($r\le R$) | $q$: 전체 전하, $q_\mathrm{enc} = q(r/R)^3$ | 균일 대전 구 내부 [D p37–38] |

### 3. 원리·결론
- 선속 부호: 바깥으로 뚫음 +, 안으로 뚫음 −, 스침 0 [C p43]
- $q_\mathrm{enc}>0$ → 알짜 선속 바깥(+), $q_\mathrm{enc}<0$ → 안쪽(−) (그림 23.2.1의 S1, S2) [D p6]
- 면 밖 전하는 알짜 선속에 기여 0: 장선이 들어왔다 그대로 나감 (S3, 균일장 속 원기둥), $\pm$ 같은 크기를 둘러싼 S4도 $\Phi = 0$ [C p47; D p7]
- 가우스 면을 뚫는 장선 수 ∝ 둘러싼 전하 크기, 나감/들어옴 ↔ 전하 부호 [C p39]
- 점전하에서 한 원뿔 안의 조각들은 $\vec E\cdot d\vec A$가 모두 같음 → 가우스 면 모양과 무관하게 같은 선속 [C p52]
- 가우스 법칙 → 쿨롱 법칙 재현 [D p8]
- 고립 도체 내부 $E = 0$ (아니면 전도 전자가 계속 흘러 영구 전류) → 초과 전하는 전부 표면 [D p13, p16]
- 공동 있는 도체: 공동 벽에 알짜 전하 없음, 초과 전하는 바깥 표면 [D p14]. 공동 속에 전하가 없으면 공동 안 $E = 0$ (보충)
- 구형 도체 껍질: 안쪽 벽 분포가 치우쳐도 바깥 벽 전하는 균일 [D p17]
- 직선 전하 식은 유한 직선에도 근사 적용 (끝에서 멀고, 직선 가까운 점) [D p22]
- 무한 판 식은 유한 부도체 판에도 근사 적용 (판 가까이, 가장자리에서 멀리). 가장자리에서는 가장자리 효과(fringing) [D p28]
- 도체 판 하나: 판 속 $E_\mathrm{in} = 0$ → 바깥 끝면으로만 선속 → $E = \sigma_1/\varepsilon_0$ [D p29]
- 평행 도체판: 서로 끌어 초과 전하가 모두 안쪽 면으로 이동, 판 바깥 $E = 0$ [D p31]
- 껍질 정리(Ch21)는 가우스 법칙의 결과: 껍질 밖 → 중심 점전하처럼, 껍질 안 → $E = 0$ [D p35–37]
- 균일 대전 구의 $E(r)$: $0\to R$에서 $r$에 비례해 증가, $R$에서 최대, 밖에서는 $1/r^2$로 감소 (껍질은 안에서 0, $R$에서 갑자기 생긴 뒤 $1/r^2$) [D p35, p37]

### 4. 문제 유형별 접근
- 가우스 법칙으로 $E$ 구하기: 대칭 판단(구/원통/평면) → $E$ 일정 + $\vec E\parallel d\vec A$ 또는 $\perp$인 가우스 면 선택 → $\Phi$를 $E\times$(넓이)로 → $q_\mathrm{enc}$ 계산 → $E$ 풀기

| 대칭 | 가우스 면 | 선속 | $q_\mathrm{enc}$ |
|---|---|---|---|
| 구 | 동심 구 | $E(4\pi r^2)$ | 점전하 $q$ / 구 내부 $q(r/R)^3$ |
| 원통 | 동축 원기둥(반지름 $r$, 높이 $h$) | $E(2\pi rh)$ (옆면만) | $\lambda h$ |
| 부도체 판 | 판을 관통하는 원기둥 | $2EA$ (양 끝면) | $\sigma A$ |
| 도체 표면 | 표면에 박힌 원기둥 | $EA$ (바깥 끝면만) | $\sigma A$ |

- 닫힌 면 선속 직접 계산: 면을 부분(뚜껑·옆면, 정육면체 면)으로 나눔 → 각 부분 $\int E\cos\theta\,dA$ → 부호 포함 합
- 도체 껍질 유도 전하: 도체 속 가우스 면 → $q_\mathrm{enc} = 0$ → 안쪽 벽 = −(공동 속 전하) → 바깥 벽 = 전체 − 안쪽 벽

### 5. 실수 포인트
- 도체 표면 $\sigma/\varepsilon_0$ vs 부도체 판 $\sigma/2\varepsilon_0$ 혼동 금지
- 면 밖 전하: 알짜 **선속**엔 0이지만 면 위 **전기장**에는 기여
- 닫힌 면의 $d\vec A$는 항상 바깥 → 들어오는 선속은 음수
- 평행 도체판: 안쪽 면 밀도 $\sigma = 2\sigma_1$
- 껍질 정리·$E = 0$은 **균일** 껍질에서만
