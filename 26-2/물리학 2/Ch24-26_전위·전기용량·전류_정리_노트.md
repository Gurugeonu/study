# Ch24-26 전위·전기용량·전류 정리 노트

> 범위: A p2–53, B p2–47, C p2–48, D p2–30, R p18–38(복습) · 출처 약어: A = Phys2-260916(Ch24), B = Phys2-260921(Ch24_Ch25), C = Phys2-260923(Ch25_Ch26), D = Phys2-260928(Ch26_Ch27), R = Phys2-261021(Review). Phys2-260914(Ch23) p43–47 = A p2–6

## Ch24 전위

### 1. 핵심 개념
- **전기력 = 보존력** → 전기 위치에너지 존재, 두 점 사이 전기력의 일은 경로 무관 [A p4–5]
- **전위(electric potential)** $V$: 대전체가 각 점에 만드는 스칼라, 대전체 전하 부호에 따라 양·음 [A p4]
- **등전위면(equipotential surface)**: 같은 전위인 이웃 점들의 면(가상 또는 실제), 전기장선과 항상 수직 [A p15, p18]
  - 균일장 = 평행 평면, 점전하 = 동심 구면(단면은 동심원), 쌍극자 = 두 전하를 감싸는 휜 면 [A p18]
- **영전위 기준**: 보통 무한대 $V=0$. 물리적 의미는 전위차뿐 [A p14, p19]
- **계의 전기 위치에너지**: 정지한 채 무한히 떨어진 입자들을 조립할 때 외력이 하는 일, 셋 이상이면 모든 쌍의 합 [A p48, p50]
- **고립 도체**: 과잉 전하는 표면에 분포하고 도체 전체(내부 포함)가 같은 전위. 내부 공동·공동 속 알짜 전하가 있어도 성립 [B p3, p5]

### 2. 공식

|---|---|---|

| $U = qV$ | $q$: 놓인 입자 전하 | [A p8] |

| $V = \dfrac{1}{4\pi\varepsilon_0}\dfrac{p\cos\theta}{r^2} = \dfrac{1}{4\pi\varepsilon_0}\dfrac{\vec p\cdot\hat r}{r^2}$ | $p = qd$, $\theta$: 쌍극자 축(−→+)에서 잰 각 | 쌍극자, $r \gg d$ [A p32] |
| $V = \dfrac{1}{4\pi\varepsilon_0}\displaystyle\int \dfrac{dq}{r}$ | | 연속 분포 [A p36] |

| $V = \dfrac{\sigma}{2\varepsilon_0}\left(\sqrt{z^2+R^2}-z\right)$ | $\sigma$: 면전하 밀도 | 반지름 $R$ 원판 중심축 위 $z$ [A p42] |
| $E_s = -\dfrac{\partial V}{\partial s}$, $\vec E = -\nabla V$ | $E_s$: $s$ 방향 성분 | [A p46] |
| $E = -\dfrac{\Delta V}{\Delta x}$ | | 균일장, 인접 등전위선 [A p44] |
| $U = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q_1q_2}{r}$ | 부호 포함 | 두 입자 [A p50] |
- 적분 공식: $\int \frac{dx}{\sqrt{x^2+a^2}} = \ln(\sqrt{x^2+a^2}+x)$ [A p39]
- 원판 축 위 장: $E_z = -\partial V/\partial z = \frac{\sigma}{2\varepsilon_0}\left(1-\frac{z}{\sqrt{z^2+R^2}}\right)$ [A p42]
- 쌍극자 장(복습): 축 위 $\vec E = k\frac{2\vec p}{z^3}$, 수직이등분선 $\vec E' = -k\frac{\vec p}{z^3}$, 일반 $\vec E = k\frac{3(\vec p\cdot\hat r)\hat r-\vec p}{r^3} = -\nabla\!\left[k\frac{\vec p\cdot\hat r}{r^2}\right]$ (다중극 전개) [A p33]
- 에너지 단위: $1\ \mathrm{eV} = 1.60\times10^{-19}\ \mathrm{J}$ (보충, 학습 목표 [A p5])

### 3. 원리·결론
- 같은 등전위면에서 시작·끝나는 경로: 전기장의 일 0. 같은 두 등전위면을 잇는 경로: 일이 같음 [A p16–17]
- 전기장 방향 = 전위가 감소하는 방향. 전기장 방향으로 이동하면 $V_i > V_f$ [A p21, p44]
- 양전하 → 양의 전위, 음전하 → 음의 전위 [A p27]
- 쌍극자: +q 쪽($\theta<90^\circ$) 양, −q 쪽 음, 수직이등분면($\theta=90^\circ$) 0. 감소 속도 점전하 $1/r$, 쌍극자 $1/r^2$ [A p30, p32]
- 구 껍질: 내부 $E=0$, $V$=표면값(일정). 외부는 중심 점전하처럼($E$는 표면에서 최대) [B p4–5]
- 원통 껍질: 내부 $E=0$, $V$=표면값. 외부는 중심축 선전하처럼 [B p4]
- 도체 공동 벽에는 알짜 전하 없음, 과잉 전하는 바깥 표면 [B p6]
- 비구형 도체: 뾰족한 곳에서 $\sigma$와 외부 $E$가 커져 공기 이온화 → 코로나 방전 [B p7]
- 도체 껍질 속 공동은 $E=0$ → 자동차 안이 거의 이상적 (컨버터블·플라스틱 차체 제외) [B p7]
- 음의 계 위치에너지 = 조립에 음의 일 [A p53]

### 4. 문제 유형별 접근
- $E$가 주어진 $\Delta V$: 적분이 쉬운 경로 선택 → $-\int\vec E\cdot d\vec s$. 그래프면 $E$–$x$ 아래 넓이에 − 부호
- 여러 점전하 $V$: 각 $kq_i/r_i$ (부호 포함) → 그냥 더함
- 연속 분포 $V$: $dq$($\lambda dx$, $\sigma 2\pi R'dR'$) → $dV = k\,dq/r$ → 적분 구간 설정
- $V$에서 $E$: 해당 방향으로 미분 후 − 부호. 그래프면 $V$–$x$ 기울기의 음수
- 입자 속력 변화: $\Delta K = -q\Delta V\ (+W_\text{app})$
- 입자계 $U$: 모든 쌍 $kq_iq_j/r_{ij}$ 합
- 탈출 속력: $K_i + U_i = 0$(무한대에서 정지)로 최소 속력 (보충)

### 5. 실수 포인트
- 전위 합은 스칼라 대수합, 벡터 합 아님 (같은 $V$라도 $\lvert\vec E\rvert$는 다를 수 있음) [A p27–28]
- $V = kq/r$에는 $q$ 부호를 넣음
- $\Delta V = V_f - V_i$ 순서, $W = -q\Delta V$의 − 부호
- 원판 적분 변수는 $R'$ ($z$ 아님) [A p42]

## Ch25 전기용량

### 1. 핵심 개념
- **축전기(capacitor)**: 두 고립 도체(판)에 $+q$, $-q$. 전기 에너지 저장 장치 [B p16]
- **전기용량(capacitance)** $C$: 판의 기하 구조에만 의존, $q$·$V$와 무관. 클수록 같은 $V$에 더 많은 전하 [B p17]
- **평행판**: 면적 $A$, 간격 $d$. 가운데는 균일장, 가장자리는 장이 휨(fringing) [B p18]
- **회로**: 전하가 흐르는 경로. **전지**: 내부 전기화학 반응으로 단자 사이 전위차 유지 [B p19]
- **충전**: 스위치 닫으면 판 h 전자 → 전지 + 단자(h 양전하), − 단자 → 판 l (l 음전하) [B p20]
- **등가 축전기**: 조합과 같은 용량의 단일 축전기 [B p37]
- **유전체(dielectric)**: 광유·플라스틱 같은 절연 물질. 완전히 채우면 $C \to \kappa C$, 유전 상수 $\kappa>1$ [C p5]
- **극성 유전체**: 영구 쌍극자, 외부장 없으면 무작위, 장 걸면 부분 정렬(열운동이 완전 정렬 방해) [C p8]
- **무극성 유전체**: 장이 쌍극자를 유도·정렬, 정렬된 원자의 장 $\vec E'$이 걸린 장과 반대 → 알짜 장 약화 [C p9]
- **자유 전하** $q$(판) vs **유도 전하** $q'$(유전체 표면), $q' < q$ [C p12, p14]
- **전기 변위(electric displacement)** $\vec D = \varepsilon_0\kappa\vec E$ [C p15]

### 2. 공식
| 공식 | 기호·단위 | 사용 조건 |
|---|---|---|
| $q = CV$ | $1\ \mathrm F = 1\ \mathrm{C/V}$ | $q$: 한 판 전하 크기, $V$: 판 사이 전위차 [B p16–17] |
| $C = \varepsilon_0 A/d$ | | 평행판, 가장자리 무시 [B p25] |
| $C = \dfrac{2\pi\varepsilon_0 L}{\ln(b/a)}$ | $a<b$: 반지름 | 원통, $L\gg b$ [B p27] |
| $C = 4\pi\varepsilon_0\dfrac{ab}{b-a}$ | | 구형 [B p29] |
| $C = 4\pi\varepsilon_0 R$ | | 고립 구 ($b\to\infty$) [B p30] |
| $C_\text{eq} = \sum_j C_j$ | | 병렬 [B p39] |
| $\dfrac{1}{C_\text{eq}} = \sum_j \dfrac{1}{C_j}$ | | 직렬 [B p41] |
| $U = \dfrac{q^2}{2C} = \dfrac12 CV^2$ | J | 충전 일과 같음 [B p45] |
| $u = \dfrac12\varepsilon_0E^2$ | J/m³, 평행판 $u = U/(Ad)$ | 진공, 모든 전기장 [B p46–47] |
| $E = \dfrac{E_0}{\kappa} = \dfrac{q}{\kappa\varepsilon_0 A}$, $q - q' = \dfrac{q}{\kappa}$ | | 평행판 유전체, $q$ 일정 [C p13] |
| $\varepsilon_0\oint\kappa\vec E\cdot d\vec A = q$, $\oint\vec D\cdot d\vec A = q$ | $q$: 자유 전하 | 유전체 가우스 법칙 [C p14–15] |
- 계산 도구: $\varepsilon_0\oint\vec E\cdot d\vec A = q$, $V = \int_-^+ E\,ds$ (−판→+판) [B p23–24]
- 모든 $C = \varepsilon_0\mathcal L$, $\mathcal L$은 길이 차원 (평행판 $\mathcal L = A/d$) [B p31]
- 유전체 영역: 모든 정전기 식에서 $\varepsilon_0 \to \kappa\varepsilon_0$ [C p5]

### 3. 원리·결론
- 회로도: 병렬 = 모든 축전기가 같은 두 단자에 연결, 직렬 = 한 줄로 연결 [B p34]
- 병렬: 모두 같은 $V$("par-V"), $q = q_1+q_2+\cdots$ [B p38]
- 직렬: 모두 같은 $q$("seri-q"), $V = V_1+V_2+\cdots$ [B p40]
- 충전에 든 일 = 축전기 위치에너지, 이 에너지는 판 사이 전기장에 저장 [B p44–45]
- 유전체 삽입, 전지 연결($V$ 일정): $C$↑ → $q$↑ [C p6]
- 유전체 삽입, 고립($q$ 일정): $C$↑ → $V$↓ (전위계로는 방전 안 됨) [C p7]
- 유전체는 표면 유도 전하로 판 사이 장을 $\kappa$배 약화 [C p13–14]
- 먼지 속 스파크: 대전 입자 방전 에너지가 가연성 먼지를 점화 → 폭발 위험 (보충, 학습 목표 [B p43])

### 4. 문제 유형별 접근
- $C$ 계산: $+q,-q$ 가정 → 가우스 법칙으로 $E$ → $V = \int_-^+E\,ds$ → $C = q/V$
- 혼합 회로: 병렬·직렬을 차례로 등가로 축약 → 최종 $q = C_\text{eq}V$ → 역순으로 각 $q$, $V$
- 스위치 닫을 때 한 점을 지나는 전하: 그 점 너머 축전기 판에 쌓이는 전하량 (보충)
- 충전된 $C_1$(전하 $q_0$)을 빈 $C_2$와 병렬 연결: 전하 보존 $q_0 = q_1+q_2$, 같은 $V = q_0/(C_1+C_2)$ (보충)
- 유전체 문제: 전지 연결 여부로 $V$ 고정/$q$ 고정 판단 → $C' = \kappa C$ → $q$, $V$, $U$
- 틈 있는 부분 유전체: 영역별 $E$ ($E_0 = q/\varepsilon_0A$, $E = E_0/\kappa$) → $V = \sum E_i d_i$

### 5. 실수 포인트
- 축전기 병렬은 덧셈, 직렬은 역수 덧셈
- Checkpoint 2 [B p32] (c) 슬라이드 답 "증가" ↔ 식으로는 $b$↑ → $C$↓ → $q$↓ (원본 오류 의심)
- [B p29] 구형 중간식의 $L$은 오타 (구형 식에는 $L$ 없음)

## Ch26 전류와 저항

### 1. 핵심 개념
- **전류(current)**: 면을 지나는 알짜 전하 흐름. 움직이는 전하라고 모두 전류는 아님 [C p24]
- 고립 도체 고리: 한 전위, 내부 장 없음 → 전류 없음. 전지를 넣으면 내부 장이 전하를 밀어 전류 [C p25–26]
- 전류는 보통 전기장에 끌리는 **전도 전자**의 운동 [C p22]
- 전류는 **스칼라**. 회로도 화살표는 양전하가 움직일 방향(벡터 아님) [C p28–29]
- **전류 밀도(current density)** $\vec J$: 벡터, 방향 = 양전하 속도 방향(음전하면 반대) [C p35]
- **유선(streamline)**: $\vec J$를 나타내는 선. 좁은 곳에서 전류는 같고 $J$는 큼 [C p36]
- **유동 속력(drift speed)** $v_d$: 전자는 무작위 운동 + 전기장 반대 방향으로 느린 유동. $v_d\sim10^{-5}$–$10^{-4}$ m/s, 무작위 $\sim10^6$ m/s [C p37]
- **운반자 밀도** $n$: 단위 부피당 운반자 수. $ne$ = 운반자 전하 밀도(C/m³) [C p40]
- **저항(resistance)** $R$: 같은 $V$에도 구리·유리 막대 전류가 크게 다른 원인, 물체의 성질. 저항기 = 정해진 $R$ 부품. **비저항(resistivity)** $\rho$: 물질의 성질. **전도율(conductivity)** $\sigma = 1/\rho$ [C p46–47]
- 거시량 $V, i, R$ (특정 도체 측정) ↔ 미시량 $E, J, \rho$ (물질 성질) [C p46]
- **옴의 법칙(Ohm's law)**: 전류가 전위차에 정비례, $R$이 전위차 크기·극성과 무관 [D p7]
- **자유 전자 모형**: 전도 전자가 기체 분자처럼 자유 이동, 전자끼리는 충돌 없이 원자와만 충돌 [D p11]
- **평균 자유 시간** $\tau$: 원자와의 충돌 사이 평균 시간 [D p14]
- **일률(power)**: 에너지가 한 형태에서 다른 형태로 전환되는 율 [D p16]
- **반도체**: 전도 전자 적음, 도핑으로 운반자 추가 시 도체화 [D p21]
- **초전도**: 수은은 약 4 K 이하에서 저항 0, 에너지 손실 없이 흐름(고리 전류 수년 유지). 전자가 짝을 지어 원자와 충돌하지 않는다는 설명 [D p23–24]

### 3. 원리·결론
- 정상 상태: 도체를 완전히 가르는 모든 면에서 전류 같음 (전하 보존), 도선을 구부려도 접합점 식 성립 [C p28–29]
- 금속 $\rho$–$T$: 온도↑ → $\rho$↑, 거의 직선 [C p48]
- 옴성 소자(1000 Ω 저항기): $i$–$V$가 원점 지나는 직선. pn 접합 다이오드: 양의 극성·약 1.5 V 이상에서만 전류, 비선형 [D p8–9]
- 전자는 충돌 후 이전 유동 속도를 잊고 새로 출발 [D p13]
- 금속이 옴 법칙을 따르는 이유: $\tau$가 걸린 $E$와 거의 무관 [D p14] (유효 속력은 열운동이 결정, 보충)
- 저항 속 전자: 장에서 얻은 에너지를 원자와 충돌하며 격자에 넘김 → 열에너지 (보충, 학습 목표 [D p16])
- 회로 에너지 보존: 전지가 공급하는 $iV$ = 저항이 소산하는 $i^2R$ [D p17, p20]
- 반도체: 온도↑ → $n$ 급증 → $\rho$↓ (음의 $\alpha$) [D p21]

### 4. 문제 유형별 접근
- 통과 전하량: $q = \int i\,dt$ (일정하면 $q = it$)
- 접합점 미지 전류: 들어오는 합 = 나가는 합
- $J$ 불균일: $i = \int J\,dA$ (원형 단면이면 $dA = 2\pi r\,dr$)
- 도선 저항: $R = \rho L/A$ → $i = V/R$, 온도 변화 시 $\rho(T)$ 먼저
- 옴성 판정: 여러 $V$에서 $V/i$가 일정한지 확인
- 소비 일률: 같은 $i$면 $i^2R$, 같은 $V$면 $V^2/R$

### 5. 실수 포인트
- $V = iR$은 옴의 법칙이 아니라 저항의 정의식. 옴 법칙의 핵심은 $R$이 $V$와 무관 [D p7]
- 전자는 실제로 관례 전류와 반대로 움직임 [C p38]
- 전류는 스칼라, 전류 밀도는 벡터
- 좁은 도선에서 바뀌는 것은 $J$이지 $i$가 아님
