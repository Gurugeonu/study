# Ch17-18 발산정리와 스토크스정리 정리 노트

> 범위: A p1–3, B p1–6, C p1–3, D p1–7 · 출처 약어: A = Calculus2-Note(17.1).pdf, B = Calculus2-Note(17.2).pdf, C = Calculus2-Note(18.1).pdf, D = Calculus2-Note(18.2).pdf
> 강의 자료가 빈칸 채우기 형식. 빈칸을 표준 교과 내용으로 채운 곳은 **(빈칸 보충)** 표시.

## 1. 핵심 개념
- **입체각 벡터장(solid angle vector field)**: $\mathbf A=\dfrac{\mathbf r}{|\mathbf r|^3}=\dfrac{1}{r^3}(x,y,z)$, $r=\sqrt{x^2+y^2+z^2}$, 원점 제외 정의 [B p1]
- **점 $P$ 중심 입체각 벡터장**: $\mathbf A_P=\dfrac{X-P}{|X-P|^3}$, $\operatorname{div}\mathbf A_P=0$ [B p2]
- **온입체각**: $4\pi$ (모든 방향을 다 덮는 입체각) [B p1]
- **회전장(curl)**: $\operatorname{curl}\mathbf F=\nabla\times\mathbf F=\det\begin{pmatrix}\mathbf e_1&\mathbf e_2&\mathbf e_3\\D_1&D_2&D_3\\f_1&f_2&f_3\end{pmatrix}$ [C p1]
  - 성분: $(D_2f_3-D_3f_2,\ D_3f_1-D_1f_3,\ D_1f_2-D_2f_1)$ (빈칸 보충)
- **비회전장**: $\operatorname{curl}\mathbf F\equiv\mathbf 0$인 벡터장 = 닫힌 벡터장 [C p3]
- **비압축장**: $\operatorname{div}\mathbf F\equiv0$인 벡터장 [D p5]
- **곡면의 경계 $\partial X$**: 매개곡면 $X:D\to\mathbb R^3$의 정의역을 $\partial D$로 제한한 곡선 [D p1]

## 2. 공식
| 공식 | 기호·의미 | 사용 조건 |
|---|---|---|
| $\displaystyle\iint_{\partial R}\mathbf F\cdot d\mathbf S=\iiint_R\operatorname{div}\mathbf F\,dV$ | 발산정리(정리 1.0.1) | 공간 영역 $R$, 일급 벡터장, $\partial R$ 바깥 방향 [A p1] |
| $\operatorname{vol}(R)=\displaystyle\iint_{\partial R}x\mathbf i\cdot d\mathbf S=\iint_{\partial R}y\mathbf j\cdot d\mathbf S=\iint_{\partial R}z\mathbf k\cdot d\mathbf S=\tfrac13\iint_{\partial R}\mathbf r\cdot d\mathbf S$ | $\operatorname{div}(x\mathbf i)=1$, $\operatorname{div}\mathbf r=3$ | 원본 마지막 항 $\partial D$는 $\partial R$의 오타로 보임 [A p3] |
| $\displaystyle\iint_{\partial R}\mathbf A\cdot d\mathbf S=\begin{cases}4\pi&\mathbf 0\in\operatorname{int}\partial R\\0&\mathbf 0\in\operatorname{ext}\partial R\end{cases}$ | 원점 입체각 플럭스 | 공간의 유계 닫힌 영역 $R$ [B p1] |
| $\displaystyle\iint_S\mathbf A_P\cdot d\mathbf S=\begin{cases}4\pi&P\in\operatorname{int}S\\0&P\in\operatorname{ext}S\end{cases}$ | 정리 2.1.2 | 닫힌 곡면 $S$ [B p2] |
| $\mathbf E_i(X)=\dfrac{q_i}{4\pi}\mathbf A_{P_i}(X)$ | 쿨롱 법칙, $q_i>0$ 척력, $q_i<0$ 인력 | $P_1,\dots,P_n$ 서로 다른 점 [B p6] |
| $Q=\displaystyle\iint_S\mathbf E\cdot d\mathbf S$ | 가우스 정리(2.2.1), $Q$: $S$ 안쪽 전하 총합, $\mathbf E=\sum\mathbf E_i$ | 닫힌 곡면 $S\subset\mathbb R^3-\{P_1,\dots,P_n\}$ [B p6] |
| $\operatorname{curl}(\mathbf F+\mathbf G)=\operatorname{curl}\mathbf F+\operatorname{curl}\mathbf G$ | 선형성 | [C p2] |
| $\operatorname{curl}(h\mathbf F)=(\operatorname{grad}h)\times\mathbf F+h\operatorname{curl}\mathbf F$ | $h$: 함수 | [C p2] |
| $\operatorname{curl}(P,Q,0)=(\operatorname{rot}\mathbf f)\mathbf k=(Q_x-P_y)\mathbf k$ | $\mathbf f=(P(x,y),Q(x,y))$ 평면장 | [C p2] |
| $\displaystyle\int_X\operatorname{grad}f\cdot d\mathbf s=f(X(b))-f(X(a))$ | 선적분 기본정리 | 곡선 $X:[a,b]\to\mathcal U$ (빈칸 보충) [D p1] |
| $\displaystyle\iint_D(Q_x-P_y)\,dxdy=\int_{\partial D}\mathbf F\cdot d\mathbf s$ | 그린정리 | 평면 영역 $D$ (우변 빈칸 보충) [D p1] |
| $\displaystyle\iint_X\operatorname{curl}\mathbf F\cdot d\mathbf S=\int_{\partial X}\mathbf F\cdot d\mathbf s$ | 스토크스 I | 매개곡면 $X:D\to\mathbb R^3$, 일급 $\mathbf F$ [D p1] |
| $\displaystyle\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=\int_{\partial S}\mathbf F\cdot d\mathbf s$ | 스토크스 II | 유향곡면 $S$, 일급 $\mathbf F$ [D p1] |
| $\operatorname{curl}(\operatorname{grad}f)=\mathbf 0$, $\operatorname{div}(\operatorname{curl}\mathbf G)=0$ | 혼합편미분 상쇄 | 이급 함수·벡터장 (보충) [D p5] |

## 3. 원리·결론
- 발산정리의 의미: 경계를 통과하는 양의 순간변화율(플럭스) = 영역이 벡터장을 따라 흐를 때 부피의 순간변화율 [A p1]
- 발산정리 증명: 직육면체에서 증명, 일반 영역은 교과서 부록 [A p1]
- $\operatorname{div}\mathbf A=0$ (원점 제외) (계산 빈칸 보충) [B p1]
- 입체각 벡터장이 곡면 $S$를 빠져나가는 양 = $S$의 입체각 [B p2]
- $\mathbf E_i$는 $\mathbb R^3-\{P_i\}$, $\mathbf E$는 $\mathbb R^3-\{P_1,\dots,P_n\}$에서 비압축장 [B p6]
- $\operatorname{curl}\mathbf r=\mathbf 0$, $\operatorname{curl}(h(r)\mathbf r)=\mathbf 0$, $\operatorname{curl}\mathbf A=\mathbf 0$ → $\mathbf A$는 비회전장 (빈칸 보충) [C p2–3]
- 정리 1.1.2 a) 열린 집합의 일급 벡터장이 잠재함수를 가지면 비회전장 [C p3]
- 정리 1.1.2 b) 비회전장은 국소적으로 보존장(잠재함수 존재), 푸앙카레 도움정리(13장 3.5.3) [C p3]
- 스토크스 정리 = 그린정리의 정의역 $D$를 곡면으로 바꾼 것 [D p1]
- 정리 2.0.5: 같은 경계를 갖는 유향곡면 $S_1,S_2$ → 경계 향 같으면 $\iint_{S_1}\operatorname{curl}\mathbf F\cdot d\mathbf S=\iint_{S_2}\operatorname{curl}\mathbf F\cdot d\mathbf S$, 반대면 부호 반대 [D p4]
- 정리 2.0.5(원본 번호 중복): 닫힌 곡면 $S$에서 $\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=0$ [D p4]
- 정리 2.1.1: 다른 벡터장의 회전장이면 비압축장. 역은 일반적으로 거짓 [D p5]
- 반례: $\mathbf A$는 비압축장이지만 $\mathbb R^3-\{\mathbf 0\}$에서 회전장이 아님 (단위구면 플럭스 $4\pi\neq0$) (빈칸 보충) [D p6]

## 4. 문제 유형별 접근
- 닫힌 곡면 플럭스: $\operatorname{div}\mathbf F$ 계산 → 영역 삼중적분(원기둥·구면좌표) [A p2]
- 입체각 플럭스(닫힌 곡면): 특이점 $P$가 안쪽이면 $4\pi$, 바깥이면 $0$ [B p3]
- 입체각 플럭스(열린 곡면): 곡면이 원점에서 보이는 입체각 계산, 또는 같은 경계·원점 안 지나는 곡면(반구)으로 교체; 향에 따라 부호 [B p4–5]
- 가우스 정리: $S$ 안쪽 전하만 더함, 바깥 전하 무시 [B p6]
- curl 계산: 행렬식 3행 전개, $\operatorname{curl}=\mathbf 0$이면 잠재함수 의심 [C p1–3]
- 공간 폐곡선 선적분: $\operatorname{curl}\mathbf F$ 계산 → 곡선을 경계로 갖는 간단한 곡면(평면 조각) 매개화 → $X_x\times X_y$ 향을 곡선 향에 맞춤 → 면적분 [D p3]
- $\operatorname{curl}\mathbf F=\mathbf 0$이면 폐곡선 선적분 $=0$ [D p2]
- 열린 곡면의 $\operatorname{curl}$ 플럭스: 경계 선적분 또는 같은 경계의 평면 원판으로 교체 [D p4, p7]
- 열린 곡면의 플럭스: 뚜껑을 붙여 닫고 발산정리 → 뚜껑 플럭스를 뺌 [D p7]
- 회전장이 아님 증명: 닫힌 곡면 플럭스 $\neq0$ 보이기 [D p6]

## 5. 실수 포인트
- 원점·전하 위치를 품은 영역에 발산정리 직접 적용 금지: $\iint_S\mathbf E\cdot d\mathbf S\neq\iiint_{\operatorname{int}S}\operatorname{div}\mathbf E\,dV_3$ [B p6]
- $\mathbf n\cdot\mathbf k\ge0$ 같은 향 조건이 바깥쪽인지 안쪽인지 확인 → 부호 [B p4–5]
- curl 둘째 성분 $D_3f_1-D_1f_3$ (가운데 항 부호 $-$) [C p1]
- 비회전장 ⇒ 보존장은 **국소적**으로만 성립; 비압축장 ⇏ 회전장 [C p3, D p5]
- 경계 향: $\mathbf n$ 방향을 머리로 하고 걸을 때 곡면이 왼쪽 (보충)
- 원본 오타 의심: $\sum_{i=i}$ → $i=1$ [C p1], $|X-P_i|<r$ → $r_i$ [B p6], $\partial D$ → $\partial R$ [A p3], "Pfoof" [C p3]
