# Ch13 벡터장과 선적분 정리 노트

> 범위: A p1–2, B p1–8, C p1–11, D p1–5 · 출처 약어: A = Calculus2-Note(13.1).pdf, B = Calculus2-Note(13.2).pdf, C = Calculus2-Note(13.3).pdf, D = Calculus2-Note(13.4).pdf
> (빈칸 보충) = 강의 자료의 빈칸을 표준 교과 내용으로 채운 부분

## 1. 핵심 개념

- **벡터장(vector field)**: $U\subseteq\mathbb{R}^n$의 각 점 $X$에 그 점을 시점으로 하는 벡터 $\mathbf{F}(X)$를 하나씩 대응하는 사상. $\mathbf{F}(X)=(f_1(X),\dots,f_n(X))=\sum_{i=1}^n f_i(X)\mathbf{e}_i$ [A p1]
- **연속·미분가능·일급·이급 벡터장**: 각 성분함수 $f_i$가 모두 그 성질을 가질 때 [A p1]
- **곡선을 따르는 벡터장**: 곡선 $X:[a,b]\to\mathbb{R}^n$의 각 $t$마다 $X(t)$를 시점으로 하는 $\mathbf{G}(t)\in\mathbb{R}^n$ 대응 ⟺ 사상 $\mathbf{G}:[a,b]\to\mathbb{R}^n$ (빈칸 보충) [B p1]
  - 대표 보기: 속도 $X'$, 가속도 $X''$, (정규곡선) 단위접벡터 $\mathbf{T}=X'/|X'|$ (빈칸 보충) [B p1]
  - $\mathbf{F}$의 정의역이 $X$의 상을 포함하면 $\mathbf{F}\circ X: t\mapsto\mathbf{F}(X(t))$도 $X$를 따르는 벡터장 [B p2]
- **선적분(line integral)**: 곡선을 따라 함수나 벡터장을 적분해 실수값을 얻는 것. 벡터장의 선적분 = **일(work)** [B p1–2]
- **역향곡선** $X_-$: 같은 자취를 반대 방향으로 지나는 곡선. **동향/역향 재매개화**: 향을 유지/반대로 하는 재매개화 [B p4]
- **조각적 일급 곡선**: 일급곡선 $X_1,\dots,X_k$를 이은 $X_1*\cdots*X_k$ [B p8]
- **잠재함수(potential function)** $\varphi$: $\mathbf{F}=\operatorname{grad}\varphi$인 일급함수. 이때 $\mathbf{F}$ = 기울기 벡터장 [C p1]
- **잠재함수를 가진다**: $U$ **전체에서** 정의된 $\varphi:U\to\mathbb{R}$가 있어 $\mathbf{F}=\operatorname{grad}\varphi$ [C p4]
- **닫힌 곡선**: 출발점 = 도착점 [C p3]
- **순환도(circulation)**: 닫힌 곡선 $X$를 따른 적분 $\oint_X\mathbf{F}\cdot d\mathbf{s}$ [C p3]
- **닫힌 벡터장(비회전장)**: 일급 $\mathbf{F}=(f_1,\dots,f_n)$이 $D_if_j=D_jf_i\ (1\le i,j\le n)$ 만족 [C p7]
- **볼록집합(convex set)**: 임의의 $P,Q\in U$에 대해 선분 $(1-t)P+tQ\ (0\le t\le1)$이 $U$에 속함 [C p8]
  - 예: $\mathbb{R}^n$, 원판, 반평면 $\{x>0\}$ / 아닌 예: $\mathbb{R}^2-\{(0,0)\}$, 고리 모양 (빈칸 보충)
- **미분형식(differential form)**: 벡터장 $(f_1,\dots,f_n)$ ↔ $f_1dx_1+\cdots+f_ndx_n$ [D p1]
- **전미분(total differential)**: $df:=\dfrac{\partial f}{\partial x_1}dx_1+\cdots+\dfrac{\partial f}{\partial x_n}dx_n$ ↔ $\operatorname{grad}f$. $f$ = $df$의 잠재함수 [D p2]
- **완전형식(exact differential form)**: 잠재함수를 가지는 미분형식($\omega=df$) [D p3]

## 2. 공식

| 공식 | 기호·뜻 | 사용 조건 |
|---|---|---|
| $\mathbf{r}(x,y)=(x,y)=x\mathbf{i}+y\mathbf{j}$, $r=\sqrt{x^2+y^2}$ | 위치벡터장, 원점에서 발산 | [A p1] |
| $\mathbf{u}=\dfrac{\mathbf{r}}{r}=\sum_i\dfrac{x_i}{r}\mathbf{e}_i$ | 단위벡터장(크기 항등적으로 1) | 원점 제외 [A p1] |
| $\mathbf{F}=-\dfrac{(x,y)}{x^2+y^2}=-\dfrac{\mathbf{r}}{r^2}$, $\lvert\mathbf{F}\rvert=\dfrac1r$ | 원점 향함, 거리에 반비례 | 원점 제외 [A p2] |
| $\mathbf{r}^*(x,y)=(-y,x)=-y\mathbf{i}+x\mathbf{j}$ | $\mathbf{r}$을 $90^\circ$ 회전 | [A p2] |
| $\int_X g\,ds:=\int_a^b g(t)\lvert X'(t)\rvert dt$ | 함수의 선적분 | 일급곡선 (빈칸 보충) [B p1] |
| $\int_X\mathbf{G}\cdot d\mathbf{s}:=\int_a^b\mathbf{G}(t)\cdot X'(t)\,dt$ | 벡터장의 선적분(일) | (빈칸 보충) [B p2] |
| $\int_X\mathbf{F}\cdot d\mathbf{s}:=\int_a^b\mathbf{F}(X(t))\cdot X'(t)\,dt$ | 벡터장 $\mathbf{F}$를 $X$ 따라 적분 | 상 $\subseteq$ 정의역 (빈칸 보충) [B p2] |
| $\int_X\mathbf{F}\cdot d\mathbf{s}=\int_X(\mathbf{F}\cdot\mathbf{T})\,ds$ | 벡터장 → 함수 선적분 | 정규곡선 (빈칸 보충) [B p3] |
| $\int_X\mathbf{F}\cdot d\mathbf{s}:=\sum_{i=1}^k\int_{X_i}\mathbf{F}\cdot d\mathbf{s}$ | 조각별 합 | 조각적 일급 (빈칸 보충) [B p8] |
| $\mathbf{a}=\dfrac{\mathbf{r}^*}{r^2}=\left(\dfrac{-y}{x^2+y^2},\dfrac{x}{x^2+y^2}\right)$ | 각원소 벡터장 | $\mathbb{R}^2-\{(0,0)\}$ [B p6] |
| $\int_X\mathbf{a}\cdot d\mathbf{s}=\theta(t_1)-\theta(t_0)$ | 원점에서 본 각도 변화 | $X=r(t)(\cos\theta(t),\sin\theta(t))$ (식은 빈칸 보충) [B p6] |
| 감는 수 $=\dfrac{1}{2\pi}\oint_X\mathbf{a}\cdot d\mathbf{s}$ | 원점 둘레를 감은 횟수 | 닫힌 곡선 (빈칸 보충) [B p7] |
| $\operatorname{grad}\varphi=\left(\dfrac{\partial\varphi}{\partial x_1},\dots,\dfrac{\partial\varphi}{\partial x_n}\right)$ | 기울기 벡터장 | $\varphi$ 일급 [C p1] |
| $\int_X\operatorname{grad}\varphi\cdot d\mathbf{s}=\varphi(X(b))-\varphi(X(a))$ | 선적분의 기본정리 3.1.1 | $U$ 열린집합, $\varphi$·$X$ 일급 [C p2] |
| $\mathbf{A}=\dfrac{\mathbf{r}}{r^3}=\dfrac{(x,y,z)}{(x^2+y^2+z^2)^{3/2}}$, $\lvert\mathbf{A}\rvert=\dfrac1{r^2}$, $\varphi=-\dfrac1r$ | 입체각 벡터장 | $\mathbb{R}^3-\{(0,0,0)\}$ [C p2] |
| $\int_X f_1dx_1+\cdots+f_ndx_n:=\int_X(f_1,\dots,f_n)\cdot d\mathbf{s}$ | 미분형식의 선적분 | 유향곡선 [D p1] |
| $=\int_a^b\sum_i f_i(X(t))\,x_i'(t)\,dt$ | $dx_i\to x_i'(t)dt$ 대입 | $X(t)=(x_1(t),\dots,x_n(t))$ (빈칸 보충) [D p1] |
| $\int_X df=\int_{\partial X}f$ | 기본정리의 미분형식 표현, $\partial X$ = 끝점(+)·시작점(−) | [D p3] |
| $d\theta=\dfrac{-y}{x^2+y^2}dx+\dfrac{x}{x^2+y^2}dy$ | $\theta=\arctan\frac yx$의 전미분 = $\mathbf{a}$의 형식 | 국소적 (빈칸 보충) [D p3] |

## 3. 원리·결론

**선적분과 매개화** [B p3–4]
- 속도벡터장: $\int_X X'\cdot d\mathbf{s}=\int_a^b|X'(t)|^2dt$ (일급곡선, 빈칸 보충)
- 가속도벡터장: $\int_X X''\cdot d\mathbf{s}=\tfrac12|X'(b)|^2-\tfrac12|X'(a)|^2$ (이급곡선, 빈칸 보충)
- $\mathbf{F}=\mathbf{F}_T+\mathbf{F}_\perp$ ⇒ $\int_X\mathbf{F}\cdot d\mathbf{s}=\int_X\mathbf{F}_T\cdot d\mathbf{s}$: 곡선에 접하는 성분만 적분
- 벡터장의 선적분은 **곡선의 향에 의존**, 함수의 선적분은 무관
- 정리 2.3.1 ($\mathbf{F}:U\to\mathbb{R}^n$, $X$ 일급)
  - a) 일급 $f:[\alpha,\beta]\to[a,b]$, $f(\alpha)=a,\ f(\beta)=b$ ⇒ $\int_{X\circ f}\mathbf{F}\cdot d\mathbf{s}=\int_X\mathbf{F}\cdot d\mathbf{s}$
  - b) 역향곡선 ⇒ $\int_{X_-}\mathbf{F}\cdot d\mathbf{s}=-\int_X\mathbf{F}\cdot d\mathbf{s}$
  - c) 동향재매개화 ⇒ 값 같음, 역향재매개화 ⇒ 부호 반대 (빈칸 보충)

**잠재함수와 경로 무관성** [C p1–3]
- 기울기 벡터장은 잠재함수의 등위면에 수직
- 따름정리 3.3.1: 잠재함수가 있으면 a) 출발점·도착점이 같은 두 곡선의 적분값이 같음 b) 닫힌 곡선 적분 = 0
- 잠재함수 있음 ⇒ 순환도 0 / 순환도 ≠ 0 ⇒ 잠재함수 없음
- 입체각 벡터장 $\mathbf{A}$: 원점에서 같은 거리의 두 점을 (원점을 지나지 않는) 임의의 곡선으로 이어 적분하면 $0$ ($\varphi=-\frac1r$ 값이 같음) [C p2]

**존재성 판정** [C p6–11]
- 정리 3.4.3: 열린 $U$의 일급 $\mathbf{F}$가 잠재함수를 가지면 $D_if_j=D_jf_i$ (필요조건)
- 잠재함수 있음 ⇒ 닫힌 벡터장. 역: 영역이 볼록이 아니면 성립 안 할 수 있음, 볼록이면 성립 (빈칸 보충)
- 정리 3.5.3 **푸앵카레 도움정리**: 열린 볼록집합에서 정의된 닫힌 벡터장은 잠재함수를 가짐
- 정리 3.4.3의 역: 대역적으로는 거짓, 국소적으로는 참
- 정리 3.5.5 (열린 $U$): 잠재함수 존재 ⟺ 모든 닫힌 곡선에서 $\oint\mathbf{F}\cdot d\mathbf{s}=0$ ⟺ 출발점·도착점이 같으면 적분값 같음. 이 경우 닫힌 벡터장. 닫힌 벡터장은 국소적으로 잠재함수를 가짐
- 유일성: $\varphi$가 잠재함수면 $\varphi+C$도 잠재함수. 정의역이 연결집합이면 이 밖의 잠재함수 없음

**각원소 벡터장 $\mathbf{a}$** [B p7, C p1, C p7–8, D p3]
- 닫힌 벡터장이지만 $\mathbb{R}^2-\{(0,0)\}$에서 잠재함수 없음(단위원 순환도 $2\pi$)
- $\{x>0\}$(볼록)에서는 잠재함수 $\arctan\frac yx$ 존재
- 적분값은 원점 둘레 회전각에만 의존, 반지름과 무관

**미분형식** [D p2–5]
- 대응 예: $\mathbf{a}\leftrightarrow\frac{-y}{x^2+y^2}dx+\frac{x}{x^2+y^2}dy$, $\mathbf{u}=\left(\frac{x}{x^2+y^2},\frac{y}{x^2+y^2}\right)\leftrightarrow\frac{x}{x^2+y^2}dx+\frac{y}{x^2+y^2}dy$ [D p1]
- 벡터장 ↔ 미분형식, 기울기 벡터장 ↔ 전미분, 잠재함수 가진 벡터장 ↔ 완전형식
- 도표: 함수 → 벡터장 → 벡터장 → 함수 (미분) ↕ 점 ← 곡선 ← 곡면 ← 입체 (경계)

## 4. 문제 유형별 접근

- **벡터장 선적분 계산**: 곡선 매개화 $X(t)$ → $\mathbf{F}(X(t))$ → $X'(t)$ → 내적 → $t$로 적분
- **미분형식 선적분**: $x_i=x_i(t)$, $dx_i=x_i'(t)dt$ 대입 → $t$ 적분
- **잠재함수 있는 장의 선적분**: $\varphi$ 구함 → $\varphi(\text{끝점})-\varphi(\text{시작점})$ (경로 무시)
- **조각적 곡선**: 조각별 매개화 → 각각 적분 → 합
- **잠재함수 구하기**: $D_if_j=D_jf_i$ 확인 → $f_1$을 $x$로 적분 $+h(y)$ → $y$로 미분해 $f_2$와 비교 → $h$ 결정 → $+C$
- **잠재함수 없음 보이기**: ① 닫힌 곡선 순환도 $\neq0$ ② $\varphi_x=f,\ \varphi_y=g$ 연립 시 모순 ③ $D_if_j\ne D_jf_i$
- **각원소 벡터장 적분**: 원점에서 본 각도 변화 = 감은 횟수 $\times 2\pi$

## 5. 실수 포인트

- 함수 선적분은 $|X'(t)|dt$, 벡터장 선적분은 $X'(t)dt$와 **내적**
- 방향을 거꾸로 하면 벡터장 선적분은 부호만 바뀜; 매개변수 속도만 바꾸면 값 불변
- $D_if_j=D_jf_i$는 **필요조건**: 영역에 구멍(원점 제외 등)이 있으면 닫힌 벡터장이어도 잠재함수가 없을 수 있음
- "잠재함수를 가진다" = 정의역 **전체**에서 하나의 $\varphi$. 부분 영역에서만 있으면 국소적 존재
- 잠재함수는 상수만큼 자유: 답에 $+C$
- $\mathbf{a}$의 적분값은 원의 반지름과 무관
