# Ch14 다중적분 정리 노트

> 범위: A p1–3, B p1–6, C p1–5, D p1–13 · 출처 약어: A = Calculus2-Note(14.1).pdf, B = Calculus2-Note(14.2).pdf, C = Calculus2-Note(14.3).pdf, D = Calculus2-Note(14.4).pdf
> (빈칸 보충) = 강의 자료가 빈칸이라 표준 교과 내용으로 채운 부분

## 1. 핵심 개념

### 1.1 넓이와 부피 (14.1)
- **바나흐의 측도 문제**: 다음 네 성질을 모두 만족하는 부피 함수 $\mu$가 있는가? [A p1]
  - a) 모든 유계 집합 $A$에 $\mu(A)\ge 0$ 정의 · b) $A\cap B=\phi$이면 $\mu(A\cup B)=\mu(A)+\mu(B)$ · c) 거리 보존 변환 $T$에 대해 $\mu(T(A))=\mu(A)$ · d) $\mu([0,1]^n)=1$
  - $n=1,2$: 존재(바나흐) / $n\ge3$: 존재하지 않음(하우스도르프) → **부피를 가지는 집합**만 다루기로 함
- **넓이를 가지는 집합** [A p2]: 유계 $A\subseteq[a_1,b_1]\times[a_2,b_2]$, 분할 $P$의 상자 $P_{ij}=[x_{i-1},x_i]\times[y_{j-1},y_j]$
  - $L(P,A)$: $A$에 **포함되는** 상자 넓이의 합 / $U(P,A)$: $A$와 **만나는** 상자 넓이의 합
  - 안넓이 $\sup_P L(P,A)$ = 겉넓이 $\inf_P U(P,A)$이면 그 값이 $A$의 넓이
- **부피를 가지는 집합** [A p3]: $\mathbb{R}^3$에서 상자 $P_{ijk}=[x_{i-1},x_i]\times[y_{j-1},y_j]\times[z_{k-1},z_k]$로 같은 정의. $n$차원 부피는 $\mathrm{Vol}_n(A)$ 또는 $\mathrm{Vol}(A)$
- 넓이 없는 집합의 예: $\{(x,y)\mid 0\le x,y\le1,\ x,y\in\mathbb{Q}\}$ → 안넓이 0, 겉넓이 1 (빈칸 보충) [A p2]

### 1.2 다중적분의 정의 (14.2)
- **분할의 크기** $|P|$: 일변수 $\max\Delta x_i$, 이변수 $\max\,\mathrm{diam}(P_{ij})$ [B p1–2]
- **연속함수의 정적분**: $\int_a^b f = \lim_{|P|\to0}\sum f(t_i)\Delta x_i$ (빈칸 보충) [B p1]
- **하합·상합** (빈칸 보충) [B p1–2]: $m=\inf_{\text{상자}} f$, $M=\sup_{\text{상자}} f$
  - 일변수 $L(P,f)=\sum m_i\Delta x_i$, $U(P,f)=\sum M_i\Delta x_i$
  - 이변수 $L(P,f)=\sum m_{ij}\mathrm{Vol}(P_{ij})$, $U(P,f)=\sum M_{ij}\mathrm{Vol}(P_{ij})$, $\mathrm{Vol}(P_{ij})=\Delta x_i\Delta y_j$
  - $L(f)=\sup_P L(P,f)$, $U(f)=\inf_P U(P,f)$; **$L(f)=U(f)$이면 적분가능**
- 이중적분에서 $A\subseteq[a,b]\times[c,d]$, $(x,y)\notin A$이면 $f(x,y)=0$으로 둠 [B p2]
- **표기** [B p3–4]
  - 이중: $\int_A f,\ \iint_A f,\ \iint_A f\,dV_2,\ \iint_A f(x,y)\,dxdy,\ \iint_A f(x,y)\,dV_2(x,y)$
  - 삼중: $\int_A f,\ \iiint_A f,\ \iiint_A f\,dV_3,\ \iiint_A f(x,y,z)\,dxdydz$
  - $n$중: $\int_A f(x_1,\dots,x_n)\,dV(x_1,\dots,x_n)$
- **자명한 확장** $A\subseteq\tilde A$ [B p4]: $\tilde f(X)=f(X)\ (X\in A)$, $0\ (X\in\tilde A\setminus A)$ (식 빈칸 보충)
- **특성함수** $\chi_A:\mathbb{R}^n\to\mathbb{R}$ [B p4]: $\chi_A(X)=1\ (X\in A)$, $0\ (X\notin A)$ (식 빈칸 보충). "$X$가 $A$의 원소인가"에 답하는 함수
- **영역**: 부피를 가지고 부피가 0이 아닌 집합 [B p5]
- **일급가역함수** $G:U\to W$: 일대일 대응, $G$와 $G^{-1}$ 모두 연속미분가능 (정의 빈칸 보충) [D p4]

### 1.3 질량과 중심 (14.2)
- **질량** $M(A)=\int_A\mu$ ($\mu$: 밀도함수) [B p6]
- **질량중심** $C(A,\mu)=(\bar x_1,\dots,\bar x_n)$, $\bar x_k=\dfrac{1}{M(A)}\int_A x_k\,\mu$ (식 빈칸 보충) [B p6]
- **기하학적 중심**: $\mu\equiv1$일 때, $\bar x_k=\dfrac{1}{\mathrm{Vol}(A)}\int_A x_k$ (빈칸 보충) [C p2, p4]
- **평균밀도** $\bar\mu = m/V$ [C p5, D p10]

## 2. 공식

| 공식 | 기호·뜻 | 사용 조건 |
|---|---|---|
| $\int_a^b f = \mathrm{Vol}_2(G_+(f))-\mathrm{Vol}_2(G_-(f))$ | $G_+$: $0\le y\le f(x)$, $G_-$: $f(x)\le y\le0$ | 정리 2.0.1: $f$ 적분가능 ⇔ $G_\pm$ 넓이 가짐 [B p2] |
| $\iint_A f\,dV_2=\mathrm{Vol}_3(G_+(f))-\mathrm{Vol}_3(G_-(f))$ | $G_\pm\subset\mathbb{R}^3$, $z$가 0과 $f(x,y)$ 사이 | $f$ 적분가능 ⇔ $G_\pm$ 부피 가짐 [B p3] |
| $\int_{\tilde A}\tilde f=\int_A f$ | $\tilde f$: 자명한 확장 | $A$ 부피 가짐, $f$ 적분가능 (등식 빈칸 보충) [B p4] |
| $\mathrm{Vol}(A)=\int\chi_A$ | $\chi_A$: 특성함수 | $A$ 유계: $\chi_A$ 적분가능 ⇔ $A$ 부피 가짐 [B p4] |
| $\iint_R f=\int_a^b\!\left(\int_c^d f\,dy\right)dx=\int_c^d\!\left(\int_a^b f\,dx\right)dy$ | 푸비니 정리 | $R=[a,b]\times[c,d]$에서 $f$ 적분가능, 각 $f_x$(또는 $f_y$) 적분가능 [C p1] |
| $\iint_A f=\int_a^b\int_{g(x)}^{h(x)}f\,dy\,dx$ | 세로형(보충 용어) $a\le x\le b,\ g\le y\le h$ | $g,h$ 연속, $g\le h$ (식 빈칸 보충) [C p2] |
| $\iint_{\bar A} f=\int_c^d\int_{\bar g(y)}^{\bar h(y)}f\,dx\,dy$ | 가로형(보충 용어) $\bar g\le x\le\bar h,\ c\le y\le d$ | $\bar g,\bar h$ 연속, $\bar g\le\bar h$ (식 빈칸 보충) [C p2] |
| $\iiint_{\text{상자}} f\,dV=\int_{a_1}^{b_1}\!\int_{a_2}^{b_2}\!\int_{a_3}^{b_3}f\,dz\,dy\,dx$ | 높은 차원 푸비니 | $f$ 연속, 순서 무관 (식 빈칸 보충) [C p5] |
| $\int_{[a,b]}f(y)dy=\int_{[\alpha,\beta]}f(g(x))\lvert g'(x)\rvert dx$ | 일변수 치환 | $g:[\alpha,\beta]\to[a,b]$ 일대일 대응·일급, $f$ 연속 [D p1] |
| $\int_W f(Y)\,dV(Y)=\int_U f(G(X))\,\lvert\det G'(X)\rvert\,dV(X)$ | 치환적분법(정리 4.1.1) | $G:U\to W$ 일급가역, $f$가 $W$에서 적분가능 [D p4] |
| $\mathrm{Vol}(T(U))=\lvert ad-bc\rvert\,\mathrm{Vol}(U)$ | $T(x,y)=(ax+by,\,cx+dy)$ | $ad-bc\ne0$ (빈칸 보충) [D p2] |

**좌표계별 치환 (야코비안은 빈칸 보충)**

| 좌표계 | 변환 $G$ | $\lvert\det G'\rvert$ | 부피 요소 | 범위 |
|---|---|---|---|---|
| 극좌표 [D p7] | $x=r\cos\theta,\ y=r\sin\theta$ | $r$ | $dx\,dy=r\,dr\,d\theta$ | $r\ge0,\ 0\le\theta\le2\pi$ |
| 원기둥좌표 [D p9] | $x=r\cos\theta,\ y=r\sin\theta,\ z=z$ | $r$ | $dV=r\,dr\,d\theta\,dz$ | $r\ge0,\ 0\le\theta\le2\pi$ |
| 구면좌표 [D p12] | $x=\rho\sin\varphi\cos\theta,\ y=\rho\sin\varphi\sin\theta,\ z=\rho\cos\varphi$ | $\rho^2\sin\varphi$ | $dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$ | $\rho\ge0,\ 0\le\varphi\le\pi,\ 0\le\theta\le2\pi$ |

**결과로 외울 값**
- 타원판 $\frac{u^2}{a^2}+\frac{v^2}{b^2}\le1$의 넓이 $\pi ab$ / 타원공의 부피 $\frac43\pi abc$ (빈칸 보충) [D p6]
- 가우스 적분 $\int_{-\infty}^{\infty}e^{-x^2}dx=\sqrt\pi$ [D p8]
- 회전체($y$축 회전) 부피 $2\pi\int_a^b x f(x)\,dx$ ($0<a$, $f>0$) [D p11]
- 반지름 $r$인 공 $\frac43\pi r^3$, 반공 $\frac23\pi r^3$ (빈칸 보충) [D p11–12]

## 3. 원리·결론
- 유계 연속함수는 영역에서 적분가능 (정리 2.4.1) [B p5]
- 정리 2.4.2 [B p5]: a) $\int(f+g)=\int f+\int g$, $\int cf=c\int f$ b) $f\le g$이면 $\int f\le\int g$ c) $\int_{A_1\cup A_2}f+\int_{A_1\cap A_2}f=\int_{A_1}f+\int_{A_2}f$
- 따름정리 2.4.3: $\left|\int_A f\right|\le\int_A|f|$ [B p5]
- 푸비니 정리: 다중적분은 일변수 적분의 반복(반복적분)으로 계산, 일반 차원에서도 성립 [C p1, p5]
- $\lvert\det G'(X)\rvert$ = 점 $X$ 근처 작은 상자의 부피 확대율 (빈칸 보충) [D p3–4]

## 4. 문제 유형별 접근
- 직사각형 위 적분: 푸비니로 안쪽부터 한 변수씩 적분; $f=g(x)h(y)$면 곱으로 분리
- 일반 영역: 그림 → 세로형/가로형 판단 → 바깥 변수 상수 범위, 안쪽 변수 함수 범위
- 안쪽 적분이 안 풀릴 때: 영역 부등식을 다시 써서 적분 순서 교환
- 넓이·부피: $\int_A 1$ (또는 $\int\chi_A$)
- 중심: 넓이(질량) → $\int x_k$ (또는 $\int x_k\mu$) → 나누기; 대칭축 방향 좌표는 0
- 질량·평균밀도: $m=\int\mu$, $V=\int1$, $\bar\mu=m/V$
- 원·원판 모양 → 극좌표 / 축 대칭 입체 → 원기둥좌표 / 구·원뿔 → 구면좌표
- 변환으로 단순해지는 영역(타원 등) → $G$ 설정 → $\lvert\det G'\rvert$ → 치환적분

## 5. 실수 포인트
- 치환 후 $\lvert\det G'\rvert$ 누락 금지: 극·원기둥 $r$, 구면 $\rho^2\sin\varphi$
- 일변수 치환공식의 $\lvert g'\rvert$는 절댓값 (구간 방향 무시한 형태)
- 적분 순서 교환 시 경계를 그림에서 새로 읽기 (기존 한계 그대로 바꾸면 틀림)
- 구면좌표 $\varphi$는 $z$축 양의 방향에서 잰 각, 범위 $0\le\varphi\le\pi$
- $\mathrm{Vol}(P_{ij})=\Delta x_i\Delta y_j$ (원본의 $(y_i-y_{i-1})$는 $(y_j-y_{j-1})$의 오타로 보임) [B p2]
- 반공 문제는 $z\ge0$ 조건이 함께 있어야 함 (원본 식에서 누락) [D p12]
