# Ch11-12 고계미분과 극값, 야코비행렬 정리 노트

> 범위: 11.1 p1–2, 11.2 p1–7, 11.3 p1–9, 11.4 p1–3, 11.5 p1–7, 11.6 p1–9, 12.1 p1–8 · 출처 약어: `11.k` = Calculus2-Note(11.k).pdf, `12.1` = Calculus2-Note(12.1).pdf
> 원본이 빈칸 채우기 형식이라 빈칸을 표준 교과 내용으로 채운 곳은 (빈칸 보충)으로 표시

## 1. 핵심 개념
- **두 번 미분가능**: $D_1f,\dots,D_nf$가 모두 미분가능 [11.2 p1]
- **이급함수(class $C^2$)** $f\in C^2(U)$: $D_1f,\dots,D_nf$가 모두 일급, 즉 모든 $D_iD_jf$가 존재·연속(빈칸 보충) [11.2 p1]
- **이계 편미분계수** $D_iD_jf(P)=\dfrac{\partial^2 f}{\partial x_i\partial x_j}(P)$: 모두 $n^2$개, $D_iD_if=D_i^2f$ [11.2 p1]
- **$k$급함수**: $f\in C^k(U)\iff D_1f,\dots,D_nf\in C^{k-1}(U)$ [11.2 p2]
- **방향미분작용소** $D_{\mathbf v}:=v_1D_1+\dots+v_nD_n=\sum v_iD_i$, $D_{\mathbf v}f=\mathbf v\cdot\mathrm{grad}f$ [11.2 p4]
- **$\mathbf v$방향 이계미분계수** $D_{\mathbf v}^2f(P)$: 다변수 함수의 오목·볼록성 (방향 지정 필수) [11.2 p5]
- **일차근삿값** $f(P+\mathbf v)\approx f(P)+\mathrm{grad}f(P)\cdot\mathbf v$ ($P$에서 미분가능, $|\mathbf v|$ 작음) [11.3 p1]
- **$k$차 근사값** $T_kf(P,\mathbf v):=f(P)+D_{\mathbf v}f(P)+\frac1{2!}D_{\mathbf v}^2f(P)+\dots+\frac1{k!}D_{\mathbf v}^kf(P)$; $\mathbf v=X-P$로 둔 $X\mapsto T_kf(P,X-P)$ = **$k$차 근사(다항)식** [11.3 p3]
- **$k$차 잉여항(나머지항)** $R_kf(P,\mathbf v):=f(P+\mathbf v)-T_kf(P,\mathbf v)$ [11.3 p4]
- **최대점/최소점**: 모든 $X\in U$에 $f(X)\le f(P)$ / $f(X)\ge f(P)$ (빈칸 보충) [11.4 p1]
- **극대점/극소점**: $f(P)$가 국소적으로 최대/최소인 점. 둘을 합쳐 **극점**, 그 함숫값이 **극값** [11.4 p1]
- **임계점(critical point)**: 모든 방향미분계수가 0인 점 [11.4 p3]
- **안장점(saddle point)**: 임계점이지만 극점이 아닌 점. 방향에 따라 함숫값이 증가하기도, 감소하기도 함 [11.5 p1]
- **헤세행렬(Hessian)** $f''(P):=(D_iD_jf(P))_{1\le i,j\le n}$, $n\times n$ 대칭행렬 [11.5 p2]
- **양행렬/음행렬**: 이차 대칭행렬 $A=\begin{pmatrix}a&b\\b&c\end{pmatrix}$에서 $\det A=ac-b^2>0$이고 $a>0$이면 $A>0$, $a<0$이면 $A<0$ [11.5 p3]
- **다변수 벡터함수** $F=(f_1,\dots,f_\ell):\mathbb R^n\to\mathbb R^\ell$ [12.1 p1]
- **야코비 행렬(Jacobian matrix)** $F'(P):=\dfrac{\partial(f_1,\dots,f_\ell)}{\partial(x_1,\dots,x_n)}(P)=\left(\dfrac{\partial f_i}{\partial x_j}(P)\right)_{\ell\times n}$ (행렬 꼴 빈칸 보충) [12.1 p1]
- **야코비 행렬식** $\det F'(P)$ ($F:\mathbb R^n\to\mathbb R^n$일 때) [12.1 p3]

## 2. 공식
| 공식 | 기호·의미 | 사용 조건 |
|---|---|---|
| $\dfrac{d}{dx}\displaystyle\int_c^d f(x,y)\,dy=\int_c^d \dfrac{\partial f}{\partial x}(x,y)\,dy$ (및 $y$에 대해 같은 꼴) | 라이프니츠 정리 | $f\in C^1([a,b]\times[c,d])$, 구간 상수 [11.1 p1] |
| $\dfrac{d}{dx}\displaystyle\int_{a(x)}^{b(x)}g\,dy=g(x,b(x))b'(x)-g(x,a(x))a'(x)+\int_{a(x)}^{b(x)}D_1g\,dy$ | 구간이 $x$에 따라 변함 | $a,b,g$ 일급 [11.1 p2] |
| $D_{\mathbf v}^2=\Big(\sum v_iD_i\Big)^2=\sum_{i,j}v_iv_jD_iD_j$ | $\mathbf v$방향 이계 작용소 | $f\in C^2$ [11.2 p4] |
| $D_{(a,b)}^2=a^2D_1^2+2abD_1D_2+b^2D_2^2$ | 2차원 | $C^2$ (빈칸 보충) [11.2 p4] |
| $D_{(a,b)}^3=a^3D_1^3+3a^2bD_1^2D_2+3ab^2D_1D_2^2+b^3D_2^3$ | 2차원 3계 | $C^3$ (빈칸 보충) [11.2 p7] |
| $\left.\dfrac{d^2}{dt^2}\right\rvert_0 f(P+t\mathbf v)=D_{\mathbf v}^2f(P)$ | 도움정리 2.1.1 | $f\in C^2$ [11.2 p5] |
| $f(P+\mathbf v)=\displaystyle\sum_{j=0}^{k-1}\frac1{j!}D_{\mathbf v}^jf(P)+\frac1{k!}D_{\mathbf v}^kf(P+t^*\mathbf v)$, $0<t^*<1$ | 테일러-라그랑주 3.0.3 | 열린집합 $U$, $k$번 미분가능, $[P,P+\mathbf v]\subseteq U$ [11.3 p1] |
| $f(P+\mathbf v)=f(P)+af_x(P)+bf_y(P)+\frac12(a^2f_{xx}+2abf_{xy}+b^2f_{yy})(P+t^*\mathbf v)$ | 2변수, $\mathbf v=(a,b)$ | 두 번 미분가능 (빈칸 보충) [11.3 p2] |
| $\lvert R_1f(P,\mathbf v)\rvert\le\dfrac{M_2}{2}(\lvert v_1\rvert+\dots+\lvert v_n\rvert)^2$ | $M_2=\max\lvert D_iD_jf(P+t\mathbf v)\rvert$ ($0\le t\le1$) | 이급, 선분 $\subseteq U$ (따름정리 3.1.4) [11.3 p4] |
| $R_kf(P,\mathbf v)=\dfrac1{(k+1)!}D_{\mathbf v}^{k+1}f(P^*)$, $P^*\in[P,P+\mathbf v]$ | 잉여항 표현 | $k+1$급 (따름정리 3.1.5) [11.3 p5] |
| $\lvert D_{\mathbf v}^{k+1}f(P^*)\rvert\le M_{k+1}(\sum\lvert v_i\rvert)^{k+1}$, $\lvert R_kf\rvert\le\dfrac{M_{k+1}}{(k+1)!}(\sum\lvert v_i\rvert)^{k+1}$ | $M_{k+1}=\max\lvert D_{i_0}\cdots D_{i_k}f(P+t\mathbf v)\rvert$ | $k+1$급 [11.3 p5] |
| $\mathrm{grad}f(P)=\lambda\,\mathrm{grad}g(P)$ | 라그랑즈 승수 $\lambda$ | 일급 $f,g$, $\mathrm{grad}g(P)\ne\mathbf 0$ [11.6 p2] |
| $(a_1\cdots a_n)^{1/n}\le\dfrac{a_1+\dots+a_n}{n}$ | 기하평균 $\le$ 산술평균 | $a_i\ge0$ [11.6 p6] |
| $\dfrac{a_1+\dots+a_n}{n}\le\left(\dfrac{a_1^2+\dots+a_n^2}{n}\right)^{1/2}$ | 일차평균 $\le$ 이차평균 | $a_i>0$ [11.6 p8] |
| $F(P+\mathbf v)-F(P)-F'(P)\mathbf v=o(\mathbf v)$ | 야코비 행렬 = 미분계수 (정리 1.0.5) | $F$가 $P$에서 미분가능 [12.1 p2] |
| $\dfrac{\partial z_k}{\partial x_i}=\displaystyle\sum_{j=1}^m\dfrac{\partial z_k}{\partial y_j}\dfrac{\partial y_j}{\partial x_i}$, $(G\circ F)'(P)=G'(F(P))\,F'(P)$ | 연쇄법칙 | $F,G$ 미분가능 (빈칸 보충) [12.1 p7] |

## 3. 원리·결론
- 초등함수의 원시함수가 초등함수가 아닐 수 있음(리우빌). 예: $\frac1ye^{-y^2}$. 그래도 라이프니츠 정리로 미분값은 구할 수 있음 [11.1 p1]
- 편미분 교환법칙(2.0.2): $f\in C^2\Rightarrow D_iD_jf=D_jD_if$ [11.2 p2]
- 따름정리 2.0.5: $f\in C^k$이면 $D_{i_1}\cdots D_{i_k}f$는 미분 순서와 무관 (예: $C^3$에서 $D_1D_2^2f=D_2D_1D_2f=D_2^2D_1f$) [11.2 p3]
- $D_{\mathbf v}^2f(P)>0$: $\mathbf v$방향으로 볼록(아래로 볼록) / $<0$: 오목(위로 볼록) [11.2 p6]
- 미분가능 $\iff$ i. $f(P+\mathbf v)=f(P)+\mathrm{grad}f(P)\cdot\mathbf v+R_1f(P,\mathbf v)$, ii. $R_1f=o(\lvert\mathbf v\rvert)$ $\iff\lim_{\mathbf v\to0}R_1f(P,\mathbf v)/\lvert\mathbf v\rvert=0$ (빈칸 보충) [11.3 p4]
- $k$급이면 $\mathbf v\mapsto R_kf(P,\mathbf v)$는 $o(\lvert\mathbf v\rvert^k)$ (원본 번호 3.1.5 중복) [11.3 p5]
- 도움정리 3.2.1: 차수 $\le k$ 다항식 $h$가 $h(\mathbf v)=o(\lvert\mathbf v\rvert^k)$이면 $h=0$ [11.3 p8]
- 테일러 전개의 유일성(3.2.2): $k$급 $f$에 대해 $f(P+x)=T_k(x)+R_k(x)$를 만족하는 차수 $\le k$ 다항식 $T_k$와 $o(\lvert x\rvert^k)$인 $R_k$는 유일 → 어떤 방법으로 구해도 같은 다항식 [11.3 p9]
- 최대·최소점은 없을 수도, 여러 개일 수도 있음. 최대점은 극대점, 최소점은 극소점 [11.4 p1]
- 임계점 정리(4.3.1): 열린집합에서 미분가능한 함수의 극점은 임계점. 역은 거짓(안장점) [11.4 p3, 11.5 p1]
- $f$가 미분가능하면 임계점 $\iff\mathrm{grad}f(P)=\mathbf 0\iff D_1f(P)=\dots=D_nf(P)=0$ (빈칸 보충) [11.4 p3]
- 일변수 이급함수의 임계점 $p$: $f''(p)>0\Rightarrow$ 극소, $f''(p)<0\Rightarrow$ 극대 (빈칸 보충); 다변수는 "이계미분의 음양"으로 분류 [11.5 p1]
- 헤세행렬이 대칭인 이유: 편미분 교환법칙 (빈칸 보충) [11.5 p2]
- 도움정리 5.3.2: $q(x,y)=ax^2+2bxy+cy^2$에서 $A>0$ → 원점 최소점, $A<0$ → 최대점, $\det A<0$ → 안장점 [11.5 p3]
- $\det A\ne0$이면 원점이 $q$의 유일한 임계점 [11.5 p3]
- **헤세 판정법(5.3.3)**: 열린집합의 이급 $f(x,y)$, 임계점 $P$에서 $f''(P)>0$ → 극소점, $f''(P)<0$ → 극대점, $\det f''(P)<0$ → 안장점 [11.5 p5]
- **라그랑즈 승수법(6.0.2)**: 일급 $f,g$를 $S=\{X\in U\mid g(X)=c\}$에 제한했을 때 $P$가 극점이면 a) $\mathrm{grad}f(P)$, $\mathrm{grad}g(P)$ 일차종속, b) $\mathrm{grad}g(P)\ne\mathbf 0$이면 $\mathrm{grad}f(P)=\lambda\,\mathrm{grad}g(P)$인 실수 $\lambda$ 존재 [11.6 p2]
- 제한 영역 최대값: 내부에 임계점이 없으면 경계와 $f$의 등위선이 접할 때 [11.6 p1]
- $\sum x_i=1$, $x_i\ge0$에서 $x_1\cdots x_n$의 최댓값 $\frac1{n^n}$ / $\sum x_i^2=1$, $x_i\ge0$에서 $\sum x_i$의 최댓값 $\sqrt n$; 둘 다 $x_1=\dots=x_n$에서 [11.6 p5, p7]
- 일급 $g$의 등위면 $g=c$에서 한 점까지 최단거리를 주는 점은 항상 존재 [11.6 p9]
- 벡터함수의 연속·미분가능·$C^k$ $\iff$ 모든 성분함수가 그러함 [12.1 p1]
- 선형사상 $F:\mathbb R^n\to\mathbb R^\ell$ ↔ $\ell\times n$ 행렬 $F_M=(F(\mathbf e_1)\ \cdots\ F(\mathbf e_n))$ 일대일 대응. 선형사상의 야코비 행렬은 어디서나 $F_M$ (뒷부분 빈칸 보충) [12.1 p2]
- 야코비 행렬 $F'(P)$ = 선형사상 $\mathbf v\mapsto F'(P)\mathbf v$ = 벡터함수의 미분계수 [12.1 p2]
- $\lvert\det F'(P)\rvert$ = 순간 넓이 팽창률(2차원), 국소 부피 변화율($n$차원). 선형변환은 단위부피를 $\lvert\det\rvert$배 [12.1 p4–5]
- $P$ 근방의 작은 나란히꼴 $P+\{\sum t_i\mathbf v_i\}$의 상 ≈ 나란히꼴 $F(P)+\{\sum t_iF'(P)\mathbf v_i\}$ ($0\le t_i\le1$) [12.1 p5]

## 4. 문제 유형별 접근
- 적분 속 미분: 피적분함수를 $x$로 편미분 → 적분. 구간이 $x$의 함수면 경계 항 두 개 추가
- 고계 방향미분: $D_{\mathbf v}^k=(aD_1+bD_2)^k$를 이항전개(미분 순서 교환 가능) → 편도함수 대입
- 근삿값: 기준점 $P$와 작은 $\mathbf v$로 분리 → $f(P)+\mathrm{grad}f(P)\cdot\mathbf v$
- 근사다항식: (가) 편도함수를 $P$에서 계산해 $T_k$에 대입 (나) 일변수 급수를 곱하고 차수 $\le k$만 남김(유일성 덕분에 같음)
- 잉여항 오차 한계: $M_{k+1}$ 상한 → $\frac{M_{k+1}}{(k+1)!}(\sum\lvert v_i\rvert)^{k+1}$
- 극값 분류: $\mathrm{grad}f=\mathbf 0$ 연립 → 각 임계점에서 헤세행렬 → $\det$ 부호, 그다음 $f_{xx}$ 부호
- 제약 최적화: (0) 존재성(유계 닫힌 영역 + 연속) (1) 내부 임계점 (2) 경계에서 $\mathrm{grad}f=\lambda\,\mathrm{grad}g$, $g=c$ 연립 (3) 후보 값 비교
- 부등식 증명: 정규화한 제약에서 라그랑즈로 최댓값 → $x_i=a_i/(\text{정규화 상수})$ 대입
- 점과 곡면의 거리: $f=\frac12\lvert X-P\rvert^2$ 최소화 + 라그랑즈. 초평면 $A\cdot X=c$까지 거리 $\dfrac{\lvert A\cdot P-c\rvert}{\lvert A\rvert}$ (빈칸 보충)
- 야코비 행렬: $i$행 = $f_i$의 그래디언트, $j$열 = $x_j$로 편미분. 합성은 행렬 곱 $G'(F(P))F'(P)$

## 5. 실수 포인트
- 구간이 변하는 적분 미분: 경계 항만 쓰고 $\int D_1g\,dy$ 항을 빠뜨리기 쉬움 [11.1 p2]
- 교환법칙은 $C^2$ 조건이 있어야 성립
- $D_{(a,b)}^2$의 가운데 항은 $2ab D_1D_2$ (계수 2 누락 주의), $T_k$의 $\frac1{j!}$ 누락 주의
- 테일러-라그랑주의 마지막 항은 $P$가 아니라 $P+t^*\mathbf v$에서 계산
- 헤세 판정은 임계점에서만. $\det f''(P)=0$이면 판정 불가 → 고계미분 등 다른 방법 [11.5 p5]
- 양·음행렬 판정은 $\det>0$을 먼저 확인. $\det<0$이면 $a$ 부호와 무관하게 안장점
- 라그랑즈는 경계(제약 곡면) 위 후보만 줌 → 내부 임계점과 영역의 모서리(예: $x_i=0$) 따로 확인, 최댓값 존재성 먼저 확인
- $\mathrm{grad}g(P)=\mathbf 0$인 점은 $\lambda$ 식이 안 맞아도 후보가 될 수 있음
- 야코비 행렬 크기는 $\ell\times n$(출력 개수 × 입력 개수). 부피 변화율은 $\det$의 **절댓값**
