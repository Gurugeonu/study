# Ch10 다변수함수의 미분 정리 노트

> 범위: A p1–5, B p1–5, C p1–4, D p1–6, E p1–4, F p1–3 · 출처 약어: A = Calculus2-Note(10.1).pdf, B = (10.2), C = (10.3), D = (10.4), E = (10.5), F = (10.6)
> (빈칸 보충) = 강의 자료의 빈칸을 표준 교과 내용으로 채운 항목

## 1. 핵심 개념

### 10.1 그래프와 등위면
- **이변수함수**: $f: D\subseteq\mathbb{R}^2\to\mathbb{R}$, 순서쌍 $(x,y)$에 실수 $z=f(x,y)$를 지정하는 규칙 [A p1]
- **$n$-변수함수**: $f: U\subseteq\mathbb{R}^n\to\mathbb{R}$, $X\mapsto f(X)$ [A p1]
- **그래프(graph)**: $G_f=\{(x_1,\dots,x_n,z)\in\mathbb{R}^{n+1}\mid (x_1,\dots,x_n)\in U,\ z=f(x_1,\dots,x_n)\}$ [A p1]
  - $x^2+y^2$의 그래프 = 회전포물면, $1-x-y$의 그래프 = 평면 [A p2]
- **기울기 벡터(일차함수)**: $z=ax+by+c=(a,b)\cdot(x,y)+c$의 기울기 $(a,b)=a\mathbf{i}+b\mathbf{j}$ ($x$축 방향 기울기 $a$, $y$축 방향 기울기 $b$) [A p2–3]
- **$c$-등위면(level set)**: $f^{-1}(c)=\{X\in U\mid f(X)=c\}$ [A p4]

| 함수 | 그래프 | 등위선 $f=k$ [A p5] |
|---|---|---|
| $x^2+y^2$ | 포물면 | 반지름 $\sqrt{k}$ 원, 바깥일수록 간격 좁음 |
| $\sqrt{x^2+y^2}$ | 원뿔면 | 반지름 $k$ 원, 등간격 |
| $x^2-y^2$ | 원본 표기 "쌍곡면" | 쌍곡선, $k=0$이면 직선 $y=\pm x$ |
| $x^2+y^2+z^2$ (3변수) | — | $c>0$: 반지름 $\sqrt c$ 구면 / $c=0$: $\{(0,0,0)\}$ / $c<0$: $\varnothing$ |

### 10.2 연속함수
- **연속**: $f$가 $P$에서 연속 $\iff \lim_{X\to P}f(X)=f(P)$ $\iff$ $X$가 $P$에 충분히 가까우면 $f(X)$도 $f(P)$에 가까움 [B p1] (일변수: $\lim_{x\to p}f(x)=f(p)$ (빈칸 보충))
- **연속함수**: 정의역의 모든 점에서 연속 [B p1]
- **열린 공** $\mathbb{B}^n(P,r)=\{X\in\mathbb{R}^n\mid |X-P|<r\}$, **닫힌 공** $\overline{\mathbb{B}}^n(P,r)=\{X\mid |X-P|\le r\}$ [B p5]
- **유계(bounded)**: 어떤 $r>0$에 대해 $U\subseteq\mathbb{B}^n(O,r)$ (빈칸 보충) [B p5]
- **닫힌집합(closed set)**: $U$의 점으로 된 수열이 수렴하면 극한도 $U$에 속함 (빈칸 보충) [B p5]
- **열린집합(open set)**: 각 점 $P\in U$마다 $\mathbb{B}^n(P,r)\subseteq U$인 $r>0$ 존재 (빈칸 보충) [C p1]

### 10.3 방향미분과 편미분
- **$\mathbf{v}$-방향미분계수(방향순간변화율)**: $D_{\mathbf v}f(P)=\displaystyle\lim_{t\to0}\frac{f(P+t\mathbf v)-f(P)}{t}$ [C p1]
  - $\mathbf v$ 단위벡터: 그래프를 직선 $P+t\mathbf v$ 위로 제한했을 때 $(P,f(P))$에서의 기울기
- **표준단위벡터** $\mathbf e_1=(1,0,\dots,0),\dots,\mathbf e_n=(0,\dots,0,1)$ [C p2]
- **$k$번째 편미분계수(partial derivative)**: $D_kf(P)=D_{\mathbf e_k}f(P)=\dfrac{\partial f}{\partial x_k}(P)=\displaystyle\lim_{t\to0}\frac{f(P+t\mathbf e_k)-f(P)}{t}$ (극한식 빈칸 보충) — $k$번째 성분만 변수, 나머지는 상수 [C p2]
- **$k$번째 편도함수**: 모든 점에서 편미분계수 존재 시 $D_kf: U\to\mathbb{R},\ P\mapsto D_kf(P)$ [C p2]
- **편미분가능**: 모든 편미분계수가 $P$에서 존재 [C p3]
- **기울기 벡터(gradient vector)**: $\operatorname{grad}f(P)=(D_1f(P),\dots,D_nf(P))$ [C p3]
- 일변수 접선의 기울기 $f'(p)$ ↔ 다변수 접평면의 기울기 벡터 $\operatorname{grad}f(P)$ (빈칸 보충) [C p3]

### 10.4 미분가능함수
- **일변수 미분가능**: $(p,f(p))$에서 (기울기 유한한) 접선 존재 $\iff f(x)-[f(p)+a(x-p)]=o(x-p)$ [D p1]
- **$n$변수 미분가능**: $(P,f(P))\in\mathbb{R}^{n+1}$에서 접평면 존재 $\iff f(X)-[f(P)+\mathbf a\cdot(X-P)]=o(|X-P|)$ [D p1–2]
- **정의(미분가능)**: $\exists\,\mathbf a\in\mathbb{R}^n$ s.t. $\displaystyle\lim_{\mathbf v\to\mathbf 0}\frac{f(P+\mathbf v)-f(P)-\mathbf a\cdot\mathbf v}{|\mathbf v|}=0$ … (1) / $U$의 모든 점에서 미분가능 → 미분가능 함수 [D p2]
- **미분계수**: $\operatorname{grad}f(P)$를 "점 $P$에서 $f$의 미분계수"라 하고 $f'(P)$ 또는 $Df(P)$로 씀 [D p4]
- **일급함수($C^1$ 함수)**: 열린 집합에서 정의되고 $\partial f/\partial x_1,\dots,\partial f/\partial x_n$이 모두 연속 [D p6]

## 2. 공식

| 공식 | 기호 | 사용 조건 |
|---|---|---|
| $\dfrac{\Delta y}{\Delta x}=a$ (빈칸 보충) | $y=ax+b$ | 일변수 일차함수 [A p2] |
| $i$번째 축 방향 기울기 $=\mathbf a\cdot\mathbf e_i=a_i$ | $z=\mathbf a\cdot\mathbf x+c$; $i=1$이면 $x_1z$-평면에서 본 직선의 기울기 | $n$변수 일차함수 [A p3] |
| $\mathbf v$-방향 기울기 $=\mathbf a\cdot\mathbf v=a_1v_1+\dots+a_nv_n$ | 정리 1.3.2 | 일차함수, $\mathbf v$ 단위벡터 [A p4] |
| $D_{\mathbf v}f(P)=\operatorname{grad}f(P)\cdot\mathbf v$ | $\mathbf v\in\mathbb{R}^n$ | $f$가 $P$에서 미분가능 [D p3] |
| $D_{c\mathbf v}f=cD_{\mathbf v}f,\ \ D_{\mathbf v+\mathbf w}f=D_{\mathbf v}f+D_{\mathbf w}f$ (빈칸 보충) | 방향미분의 선형성 | 미분가능 [D p4] |
| $D_{\mathbf v}f(P)=\lvert\operatorname{grad}f(P)\rvert\cos\theta$ (빈칸 보충) | $\theta$: $\mathbf v$와 grad 사이 각 | 미분가능, $\mathbf v$ 단위벡터 [D p5] |
| $(g\circ f)'(x)=g'(f(x))\,f'(x)$ (빈칸 보충) | 일변수 연쇄법칙 | $f,g$ 미분가능 [E p1] |
| $\dfrac{d}{dt}f(X(t))=\operatorname{grad}f(X(t))\cdot X'(t)=\sum_i\dfrac{\partial f}{\partial x_i}\dfrac{dx_i}{dt}$ | 정리 5.0.2 | $f$: 열린 집합 $U$에서 미분가능, $X:I\to U$ 미분가능 곡선 [E p1–2] |
| $\dfrac{\partial}{\partial s}f(X(s,t))=\sum_i\dfrac{\partial f}{\partial x_i}\dfrac{\partial x_i}{\partial s}$ ($t$도 같은 꼴) | 두 매개변수 | 위와 같음 [E p3] |
| $D_{\mathbf v}f(P)=\dfrac{d}{dt}\Big|_{t=0}f(X(t))$ (빈칸 보충) | $X(0)=P,\ X'(0)=\mathbf v$ | 미분가능 [E p2] |
| $\partial_r=\cos\theta\,\partial_x+\sin\theta\,\partial_y$, $\ \partial_\theta=r(-\sin\theta\,\partial_x+\cos\theta\,\partial_y)$ | $x=r\cos\theta,\ y=r\sin\theta$ | 극좌표 [E p3] |
| 등위면 접평면: $\operatorname{grad}F(P)\cdot(X-P)=0$ | $S=\{F=F(P)\}$ | $F$ 일급, $\operatorname{grad}F(P)\ne\mathbf 0$ [F p1–2] |

## 3. 원리·결론
- 연속함수의 합·차·곱·합성, 분모가 0이 아닌 몫은 연속 [B p1]
- $P$에서 연속을 보이려면 $P$로 수렴하는 **모든** 수열 $(X_i)$에서 $\lim f(X_i)=f(P)$ 필요 [B p2]
- **최대최소정리(정리 2.2.2)**: 유계인 닫힌 집합에서 정의된 연속함수는 최댓값·최솟값을 가짐 [B p5]
- 다변수 변화율은 변수가 변하는 **방향**을 먼저 정해야 함 [C p1]
- 변화를 조사하려면 점 근방, 즉 그 점을 포함한 **열린 집합**에서 정의되어야 함 [C p1]
- **정리 4.0.2**: $P$에서 미분가능 ⇒ (i) $P$에서 연속 (ii) 모든 방향미분계수 존재, $D_{\mathbf v}f(P)=\operatorname{grad}f(P)\cdot\mathbf v$ (iii) 식 (1)의 $\mathbf a=\operatorname{grad}f(P)$ [D p3]
- 미분가능 $\iff$ a) 편미분가능 b) $\lim_{\mathbf v\to\mathbf 0}\frac{f(P+\mathbf v)-f(P)-\operatorname{grad}f(P)\cdot\mathbf v}{|\mathbf v|}=0$ (빈칸 보충) [D p4]
- $-|\operatorname{grad}f(P)|\le D_{\mathbf v}f(P)\le|\operatorname{grad}f(P)|$: 최대 방향 $\operatorname{grad}f(P)/|\operatorname{grad}f(P)|$, 최소 방향 그 반대 (빈칸 보충) [D p5]
- $D_{\mathbf v}f(P)=0\iff\mathbf v\perp\operatorname{grad}f(P)$ (빈칸 보충) [D p5]
- **정리 4.2.2**: 열린 집합에서 정의된 일급함수는 미분가능 [D p6]
- 합성함수의 순간변화율 = 바깥 함수 순간변화율 × 안쪽 함수 순간변화율 [E p1]
- **기울기 벡터와 등위면**: 일급함수 $f$에서 $\operatorname{grad}f(P)$는 $P$가 속한 등위면 $S=\{X\in U\mid f(X)=f(P)\}$에 수직 [F p1]
- 등위면의 접평면 = $P$를 지나는 $S$ 속 곡선들의 속도벡터 $X'(0)$ 모음 [F p1]

## 4. 문제 유형별 접근
- 일차함수 방향 기울기: 기울기 벡터 $\mathbf a$ → 단위벡터 $\mathbf v$와 내적. 변위 $\mathbf w$만큼 이동 시 증가량은 $\mathbf a\cdot\mathbf w$ [A p4]
- 등위면 그리기: $f=c$로 두고 $c$의 부호·크기별로 경우 나눔 [A p5]
- 원점 극한·연속 판정(불연속): 직선 $y=mx$, $f(t,t)$, 반복극한 등 경로별 극한 비교 → 다르면 극한 없음 → 불연속 [B p2, p4]
- 원점 연속 증명: $|f(x,y)-0|\le$ (0으로 가는 식)으로 압축, 또는 극좌표 $r\to0$ [B p3]
- 방향미분계수(정의): $f(P+t\mathbf v)$를 $t$의 식으로 → 극한 [C p1]
- 편미분: 한 변수만 남기고 나머지를 상수로 보고 미분 [C p2]
- 미분가능 판정: 정의보다 먼저 일급(편도함수 연속)인지 확인 [D p6]
- 방향미분계수(미분가능 함수): grad 계산 → $\mathbf v$와 내적 (주어진 방향미분계수 몇 개로 grad 역산 가능) [D p4]
- 가장 빠른 증가 방향·최대 변화율: 방향 $\operatorname{grad}f(P)$, 크기 $|\operatorname{grad}f(P)|$ [D p5]
- 곡선 따라 변화율: 곡선이 그 점을 지나는 $t_0$ 찾기 → $\operatorname{grad}f\cdot X'(t_0)$ [E p2, p4]
- 음함수 곡선·곡면의 접선·접평면: $F$로 옮겨 쓰기 → $\operatorname{grad}F(P)$가 법선 → $\operatorname{grad}F(P)\cdot(X-P)=0$ [F p2]
- 반사 방향: 입사 방향 $\mathbf d$, 법선 $\mathbf N=\operatorname{grad}F(P)$ → $\mathbf d-2\frac{\mathbf d\cdot\mathbf N}{|\mathbf N|^2}\mathbf N$ (공식은 보충) [F p3]

## 5. 실수 포인트
- 경로 하나에서 극한이 $f(P)$와 같다고 연속이 아님 → 모든 경로(수열) 필요 [B p2]
- 편미분가능 ≠ 미분가능. 미분가능 ⇒ 연속·편미분가능 [D p3], 역은 불성립 (보충: $xy/(x^2+y^2)$는 원점에서 편미분가능하지만 불연속)
- $D_{\mathbf v}f=\operatorname{grad}f\cdot\mathbf v$는 **미분가능**할 때만 사용 [D p3]
- $|\operatorname{grad}f|\cos\theta$, 최대 변화율 $|\operatorname{grad}f|$은 $\mathbf v$가 **단위벡터**일 때의 값; 방향미분 정의 자체는 임의의 $\mathbf v$ 허용 [C p1, D p5]
- 연쇄법칙에서 $\operatorname{grad}f$는 $X(t)$에서 계산, 곡선이 그 점을 지나는 $t$값 확인 [E p1]
- 원본 [A p2] b) 좌변 분모 $\Delta x$는 $\Delta y$의 오타 / $x^2-y^2$의 표준 명칭은 쌍곡포물면(안장면) [A p5]
