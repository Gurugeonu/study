# Ch15 평면 벡터장과 그린정리 정리 노트

> 범위: A p1–4, B p1–2, C p1–6, D p1–4, E p1–2 · 출처 약어: A = Calculus2-Note(15.1).pdf, B = Calculus2-Note(15.2).pdf, C = Calculus2-Note(15.3).pdf, D = Calculus2-Note(15.4).pdf, E = Calculus2-Note(15.5).pdf
> 강의 자료가 빈칸 채우기 형식. 빈칸을 표준 교과 내용으로 채운 곳은 **(빈칸 보충)** 표시.

## 1. 핵심 개념
- **발산도·발산함수(divergence)**: 열린 집합의 일급 벡터장 $\mathbf F=(P,Q)$에 대해 $\operatorname{div}\mathbf F(X)=P_x(X)+Q_y(X)$(점 $X$의 발산도), 이를 함수로 본 것이 발산함수 [A p1]
- **n차원 발산**: $\mathbf F=(f_1,\dots,f_n)$, $\operatorname{div}\mathbf F=\dfrac{\partial f_1}{\partial x_1}+\cdots+\dfrac{\partial f_n}{\partial x_n}=D_1f_1+\cdots+D_nf_n$ [A p1]
- **발산의 의미**: 벡터장을 따라 흘러가는 작은 영역의 넓이(부피) 변화율 [A p3]
- **비압축장**: $\operatorname{div}\mathbf F\equiv0$인 벡터장 [A p4]
- **좌표평면의 향**: 양의 방향 = 시계 반대 방향, 음의 방향 = 시계 방향 (빈칸 보충) [B p1]
- **두 벡터의 향**: 일차독립인 $\mathbf v,\mathbf w$가 양으로 향함 ⇔ $\det(\mathbf v\ \mathbf w)>0$, 음으로 향함 ⇔ $\det<0$ (빈칸 보충) [B p1]
- **경계 $\partial D$의 향**: 경계를 따라 걸을 때 $D$가 왼쪽에 오는 방향. 바깥 경계는 반시계, 구멍 경계는 시계 (빈칸 보충) [B p2]
- **단위법벡터장 $\mathbf n$ 선택** [C p1]
  - 일반 곡선 $X(t)=(x,y)$: $\mathbf n=\pm(y',-x')/|X'|$ 중 하나 선택 (빈칸 보충)
  - 경계 $\partial D$: 바깥 방향(표준 단위법벡터). 양의 향 접벡터 $\mathbf t=(t_1,t_2)$에 대해 $\mathbf n=(t_2,-t_1)$ (빈칸 보충)
- **플럭스(flux)**: $\displaystyle\int_C\mathbf F\cdot\mathbf n\,ds$, $\mathbf F$가 $C$를 $\mathbf n$-방향으로 통과하는(빠져나가는) 양 [C p1]
- **2차원 입체각 벡터장**: $\mathbf A(x,y)=\dfrac{X}{|X|^2}=\dfrac{x}{x^2+y^2}\mathbf i+\dfrac{y}{x^2+y^2}\mathbf j$ [C p5]
- **회전도·회전함수**: $\operatorname{rot}\mathbf F(X)=Q_x(X)-P_y(X)$(점 $X$의 회전도), 함수로 본 것이 회전함수. 조건: 열린 집합의 일급 벡터장 [D p1]
- **회전도의 의미**: 점 주위 작은 원이 받는 회전력(torque)의 밀도 [D p2–3]
- **비회전장**: $\operatorname{rot}\mathbf F\equiv0$인 벡터장 [D p4]
- **순환도**: 경계를 따른 선적분 $\int_{\partial D}\mathbf F\cdot d\mathbf s$ [E p1]

## 2. 공식
| 공식 | 기호·의미 | 사용 조건 |
|---|---|---|
| $\displaystyle\int_{\partial D}\mathbf F\cdot\mathbf n\,ds=\iint_D\operatorname{div}\mathbf F\,dV_2$ | 발산 정리(정리 2.0.1), $\mathbf n$: 바깥 단위법벡터 | 영역 $D$에서 정의된 벡터장 $\mathbf F$ [C p1]; 일급 가정 (빈칸 보충) |
| $\displaystyle\int_{\partial D}\mathbf F\cdot d\mathbf s=\iint_D\operatorname{rot}\mathbf F\,dV_2$ | 그린 정리(정리 5.0.1) | 유계 닫힌 영역, 경계 조각적 정규곡선, $\mathbf F$ 일급 [E p1] |
| $\displaystyle\int_{\partial D}P\,dx+Q\,dy=\iint_D(Q_x-P_y)\,dV_2$ | 그린 정리의 미분형식 표현, $\mathbf F\leftrightarrow P\,dx+Q\,dy$ | 위와 같음 (빈칸 보충) [E p1] |
| $\operatorname{area}(D)=\displaystyle\int_{\partial D}x\mathbf i\cdot\mathbf n\,ds=\int_{\partial D}y\mathbf j\cdot\mathbf n\,ds=\tfrac12\int_{\partial D}(x\mathbf i+y\mathbf j)\cdot\mathbf n\,ds$ | $\operatorname{div}(x\mathbf i)=\operatorname{div}(y\mathbf j)=1$ | 발산 정리 적용 가능 영역 [C p3] |
| $\operatorname{area}(D)=\tfrac12\displaystyle\int_{\partial D}x\,dy-y\,dx=-\int_{\partial D}y\,dx=\int_{\partial D}x\,dy$ | 따름정리 5.0.4 | $\partial D$ 양의 향 [E p2] |
| $\displaystyle\int_C\mathbf A\cdot\mathbf n\,ds=\begin{cases}2\pi&(0,0)\in\operatorname{int}C\\0&(0,0)\in\operatorname{ext}C\end{cases}$ | 정리 3.1.1 (이차원 가우스 정리) | 단순폐곡선 $C\subset\mathbb R^2-\{(0,0)\}$ [C p5] |
| $\mathbf A_P(X)=\dfrac{X-P}{|X-P|^2}$, $\displaystyle\int_C\mathbf A_P\cdot\mathbf n\,ds=2\pi$ 또는 $0$ | "점 $X$가 점 $P$로부터 받는 힘", $\operatorname{div}\mathbf A_P=0$ | $C\subset\mathbb R^2-\{P\}$, $P\in\operatorname{int}C$이면 $2\pi$, $\operatorname{ext}C$이면 $0$ [C p6] |
| $\mathbf F^*=-Q\,\mathbf i+P\,\mathbf j$, $\operatorname{div}\mathbf F=\operatorname{rot}\mathbf F^*$ | $\mathbf F$를 $90^\circ$ 회전한 장 | [D p4]; $\operatorname{div}\mathbf F^*=-\operatorname{rot}\mathbf F$ (빈칸 보충) |
| $\operatorname{rot}\mathbf F(\mathbf 0)=\displaystyle\lim_{r\to0}\frac{1}{\pi r^3}\int_{C_r}r\,\mathbf F\cdot\mathbf t\,ds=\lim_{r\to0}\frac{1}{\pi r^2}\int_{C_r}\mathbf F\cdot\mathbf t\,ds$ | $C_r$: 반지름 $r$ 원, $\mathbf t=\tfrac1r(-y,x)$ | (결론 빈칸 보충) [D p2–3] |

## 3. 원리·결론
- 위치 벡터장: $\operatorname{div}(x,y)=2$, $\operatorname{div}(x,y,z)=3$; $\operatorname{rot}(x,y)=0$ (빈칸 보충) [A p1, D p1]
- 선형 벡터장 $\mathbf F_A(x_1,\dots,x_n)=\bigl(\sum_j a_{1j}x_j,\dots,\sum_j a_{nj}x_j\bigr)$: $\operatorname{div}\mathbf F_A=a_{11}+\cdots+a_{nn}=\operatorname{tr}A$ (빈칸 보충) [A p2]
- $\mathbf r$의 흐름에서 작은 원판 넓이의 $t=0$ 순간변화율(비율) $=2=\operatorname{div}\mathbf r$ (빈칸 보충). 일반 벡터장에서도 성립(부록, 자료 미포함) [A p3–4]
- 각원소 벡터장 $\mathbf a=\left(\dfrac{-y}{x^2+y^2},\dfrac{x}{x^2+y^2}\right)$: $\operatorname{div}\mathbf a=0$, $\operatorname{rot}\mathbf a=0$ ($\mathbb R^2-\{0\}$) (빈칸 보충) [A p4, D p1]
- $\mathbf A=\left(\dfrac{x}{x^2+y^2},\dfrac{y}{x^2+y^2}\right)$: $\operatorname{div}\mathbf A=0$ → 비압축장 [A p4, C p5]
- 정리 4.3.1: 열린 집합의 일급 벡터장이 잠재함수를 가지면 비회전장 [D p4]
- 역은 일반적으로 거짓: $\mathbf a$는 $\mathbb R^2-\{0\}$에서 비회전장이지만 잠재함수 없음 (빈칸 보충) [D p4]
- 그린 정리와 발산 정리는 $\mathbf F^*$로 서로 동치 (빈칸 보충) [E p1]

## 4. 문제 유형별 접근
- 발산·회전도 계산: $P,Q$ 확인 → $P_x+Q_y$ 또는 $Q_x-P_y$
- 경계 flux 계산: 발산 정리로 $\iint_D\operatorname{div}\mathbf F$로 바꿈
- 특이점이 있는 장($\mathbf A$, $\mathbf A_P$)의 flux: 특이점이 곡선 안인지 밖인지 판정 → $2\pi$ 또는 $0$
- 복잡한 폐곡선 선적분 $\oint P\,dx+Q\,dy$: 향 확인 → $Q_x-P_y$ 계산(상수가 되면 넓이 곱) → 이중적분
- 매개곡선으로 둘러싸인 넓이(타원, 싸이클로이드): 넓이 공식 선택 → 양의 향으로 경계 매개화 → 경계 조각별 선적분 합

## 5. 실수 포인트
- flux는 벡터장의 적분이 아니라 **함수 $\mathbf F\cdot\mathbf n$의 적분**(결과는 스칼라) [C p1]
- 회전도 부호: $Q_x-P_y$ (순서 바꾸면 부호 반대)
- 경계가 음의 향(시계 방향)이면 선적분 부호 반대. 구멍 있는 영역은 안쪽 경계가 시계 방향
- 특이점이 영역 안에 있으면 발산·그린 정리를 바로 쓸 수 없음 → 작은 원으로 잘라냄
- 싸이클로이드 영역: 아치는 경계로서 $t$가 감소하는 방향으로 지남
