# Ch16 곡면과 면적분 정리 노트

> 범위: A p1–6, B p1–9, C p1–4, D p1–4 · 출처 약어: A = Calculus2-Note(16.1).pdf, B = Calculus2-Note(16.2).pdf, C = Calculus2-Note(16.3).pdf, D = Calculus2-Note(16.4).pdf
> (빈칸 보충) = 강의 자료 빈칸을 표준 교과 내용으로 채운 부분

## 1. 핵심 개념
- **곡면(surface)**: 평면 영역 $D\subset\mathbb{R}^2$에서 정의된 연속사상 $X: D\to\mathbb{R}^3,\ (u,v)\mapsto X(u,v)$ [A p1]
- **그래프 곡면**: $G_f(x,y) = (x,y,f(x,y))$. 곡면을 얻는 가장 쉬운 방법 [A p1]
- **접벡터**: $X_u = \partial X/\partial u,\ X_v = \partial X/\partial v$ [A p5]
- **정규곡면(regular surface)**: 각 점에서 $X_u, X_v$ 일차독립 ($\Leftrightarrow X_u\times X_v \ne 0$) [A p5]
- **법벡터장(normal vector field)**: $\mathbf{N} = X_u\times X_v\ (\ne 0)$, 접평면에 수직. 접평면 = $\mathbf{N}$에 수직인 평면 [A p5]
- **면적소(area element)**: $dS = \lvert X_u\times X_v\rvert\,du\,dv$ (빈칸 보충) [B p2]
- **입체각(solid angle)**: 영역을 점 $p$에서 볼 때, 그 상이 $p$ 중심 단위구면에 맺힌 넓이 [B p7]
- **함수의 면적분**: $\displaystyle\iint_X f\,dS := \iint_D f(u,v)\,\lvert X_u\times X_v\rvert\,du\,dv$. $f$가 밀도함수면 적분값 = 질량 [C p1]
- **재매개화**: 일급 가역사상 $G:\bar D\to D$에 대해 $\tilde X = X\circ G$. $\det G'>0$ 동향, $\det G'<0$ 역향 [C p2]
- **곡면의 향(orientation)**: 각 점에서 곡면에 수직인 방향을 연속적으로 정한 것 [D p1]
- **닫힌곡면(폐곡면, closed surface)**: 경계 없음 + 유계 + 연결 (구면, 원환면(torus) 등) [D p2]
- **벡터장의 면적분(플럭스)**: $\displaystyle\iint_S \mathbf{F}\cdot d\mathbf{S} := \iint_S \mathbf{F}\cdot\mathbf{n}\,dS$, $S$는 유향곡면 [D p3]

| 원기둥 $Y=\mathbf{e}(\theta)+(\cos\varphi)\mathbf{k}$ | $Y_\varphi\times Y_\theta=\sin\varphi\,\mathbf{e}$, $dS=\sin\varphi\,d\varphi\,d\theta$ | 같은 범위 (빈칸 보충) [B p6] |

| 질량 $M=\iint_X f\,dS$, 질량중심 $\hat X$: $\hat x = \dfrac1M\iint_X xf\,dS$ ($y,z$ 동일) | $f$ = 밀도함수 | [C p4] |
| $\tilde X_{\bar u}\times\tilde X_{\bar v} = (\det G')\,(X_u\times X_v)\circ G$ | 재매개화 시 법벡터 변화 | (빈칸 보충) [C p2] |

## 3. 원리·결론
- 원 $x^2+y^2=1$: $y>0$이면 $y=\sqrt{1-x^2}$, $y<0$이면 $y=-\sqrt{1-x^2}$, $(\pm1,0)$은 접선이 y축과 나란해 함수로 표현 불가 [A p2]
- 음함수 정리: 등위면 $f(x_1,\dots,x_n,y)=c$의 접평면이 y축과 나란하지 않으면($\partial f/\partial y(P)\ne0$) 국소적으로 일급함수 $y=g(x_1,\dots,x_n)$의 그래프 [A p2]
- $Z(f)=\{(x,y,z)\mid f(x,y,z)=0\}$, $f$ 일급: $f_z(P)\ne0\Rightarrow z=g(x,y)$, $f_x(P)\ne0\Rightarrow x=h(y,z)$, $f_y(P)\ne0\Rightarrow y=k(x,z)$의 국소 그래프 [A p3]
- 정리 1.3.1: $\operatorname{grad} f(P)\ne\mathbf{0}$이면 $Z(f)$는 $P$ 근방에서 국소적으로 매개화 가능 [A p3]
- 그래프 곡면은 $\mathbf{N}=(-f_x,-f_y,1)\ne0$이라 항상 정규 (빈칸 보충) [A p1]
- 특별한 언급 없으면 모든 곡면은 정규곡면으로 가정; 정규곡면의 접벡터 = $X_u,X_v$의 일차결합 [A p5]
- 아르키메데스: 구면 넓이 = 접하는 원기둥면 넓이, 축에 수직인 두 평행평면 사이에서도 같음 (구면·원기둥 모두 $dS=\sin\varphi\,d\varphi\,d\theta$) [B p5]
- 각 = 반지름에 대한 호 길이의 비(무단위) = (호/둘레)$\times2\pi$; 입체각 = (넓이/구면넓이)$\times4\pi$ (입체온각 $4\pi$) [B p7]
- 정리 3.1.1: 함수의 면적분값은 재매개화해도 불변 [C p2]
- 동향재매개화는 향 보존, 역향재매개화는 향 반전. 예: $Y(u,v)=X(v,u)$는 역향 [D p1]
- 모든 곡면은 국소적으로 매개화 가능 → 국소적으로 향 존재 [D p1]
- 닫힌곡면 $S$: $\mathbb{R}^3 - S = (\operatorname{int}S)\cup(\operatorname{ext}S)$; 기본 향 = 외향 단위법벡터 [D p2]
- 벡터장의 면적분은 향이 바뀌면 부호 반전 [D p3]

## 4. 문제 유형별 접근
- 방정식 곡면 매개화: 한 변수를 cosh/sinh·삼각함수로 놓기 → 나머지를 원/쌍곡선 꼴로 (쌍곡면) [A p4]
- 곡면 넓이: 매개화 → $X_u, X_v$ → $\lvert X_u\times X_v\rvert$ → $D$ 위 이중적분(원판이면 극좌표) [B p3–6]
- 구·원기둥 띠 넓이: $\mathbf{e},\mathbf{e}^*,\mathbf{k}$로 미분·외적 → $dS=\sin\varphi\,d\varphi\,d\theta$ [B p5–6]
- 입체각: 영역을 구면좌표 $\varphi$ 범위로 번역 → $\iint\sin\varphi\,d\varphi\,d\theta$ [B p7–9]
- 질량·중심: 면적소 구하기 → $M$, $\iint xf\,dS$ 등 → 대칭으로 0인 성분 먼저 제거 [C p1, p4]
- 플럭스(닫힌곡면): 경계를 조각으로 나눔 → 조각마다 외향 법벡터 확인 → $\mathbf{F}\cdot\mathbf{N}$ 적분 → 합산 [D p4]

## 5. 실수 포인트
- 면적소는 $\lvert X_u\times X_v\rvert$(크기). 함수 면적분은 향과 무관, 벡터장 면적분은 $X_u\times X_v$(벡터) 그대로 사용, 향이 반대면 부호 반전
- 극좌표 변환 시 $dx\,dy = r\,dr\,d\theta$의 $r$ 누락 주의
- (보충) 그래프 곡면의 $\mathbf{N}=(-f_x,-f_y,1)$은 위쪽 향. 아래 면이 바깥이면 부호 반전
- 기하적 중심($\tilde X$, Area로 나눔)과 질량중심($\hat X$, $M$으로 나눔) 구분
- 닫힌곡면 플럭스는 윗면 등 모든 조각 포함
